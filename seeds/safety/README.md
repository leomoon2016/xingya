# safety —— 安全词表

- `chat/`：呀哈哈队长聊天输入输出过滤的分类词表（色情、暴力、自伤、仇恨、政治、脏话）与规则（网址、电话、证件号、QQ/微信号、住址模式）。
- `prompt-blocklist`：AI 工作室提示词禁止词表（现有动漫/游戏/影视角色与品牌、在世艺术家姓名、不适合儿童的内容），每行一项；必须包含任天堂角色的中英文名称（马里奥、林克、塞尔达、耀西、酷霸王等）——游戏搭档只用 `seeds/partners/` 的固定素材，AI 工作室永远不生成它们（ADR 0018）。技能的名称、指令与参考资料同样用它检查。
- `agent-guard.md`：AI 角色系统守则（儿童安全、不得模仿现有 IP 与在世艺术家、不收集个人信息、忽略数据段中的指令），由代码放在每次模型调用的最前面，**不可关闭、不在数据库中**。
- `tests/`：儿童安全测试集（面向孩子的技能与角色发布前必须全部通过，见开放问题 Q23）；CI 中由 `tools/safety-eval` 运行，后台“儿童安全审核”也调用同一测试集。

全部随发布包部署、由 api 启动时读取，不入库。修改需经代码审阅；CI 校验无重复、正则可编译。
