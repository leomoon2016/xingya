# 12: 邀请家长和找回密码

**What to build:** 已登录的家长在家长中心输入另一位家长的邮箱发出邀请；对方收到邮件，打开 7 天内有效的链接，设置称呼和密码后加入同一个家庭，权限与邀请者完全相同。忘记密码的家长在登录页输入邮箱，收到 30 分钟内有效、只能用一次的重置链接，设置新密码后，他在其他设备上的会话全部失效。

依据：[family 需求 §4.3.1–4.3.2、§4.3.5、验收要点](../../../docs/01-requirements/modules/family.md)、[api §5.3 family](../../../docs/03-design/api.md)。

**Blocked by:** [11 家长注册和登录](11-parent-signup-login.md)

**Status:** ready-for-agent

- [ ] 邀请：家长发出邀请后，在同一事务中生成 `invite_parent` 令牌（库中只存 SHA-256，7 天有效）并入队邀请邮件；受邀邮箱已属于任何家庭 → `409 EMAIL_IN_USE`。
- [ ] 接受邀请：令牌有效时设置称呼与密码（同 11 的密码规则）并加入邀请者的家庭、建立会话；过期或已使用的令牌被拒。用可控 Clock 测试 7 天边界。
- [ ] 受邀家长与邀请者权限相同：家长成员列表中两人都可见，任一方都能再邀请。
- [ ] 找回密码请求：`request` 无论邮箱是否存在都返回 202（不暴露邮箱是否注册），存在时入队重置邮件。
- [ ] 重置：令牌 30 分钟有效、一次性；重置后该家长的其他会话全部失效，下一次请求返回 `401`（集成测试）。用可控 Clock 测试 30 分钟边界与重复使用。
- [ ] 邀请与重置相关的写操作写审计事件。
- [ ] e2e：家长 A 邀请 B → 从 SMTP 桩取链接 → B 加入并看到同一家庭；B 找回密码 → 旧会话失效 → 用新密码登录。
