# features —— 后台功能

| 目录 | 功能 |
| --- | --- |
| `studio/` | AI 工作室总览：任务列表（排队/运行/成功/失败、预估与实际费用）、本月全站与角色预算、素材库、资料库 |
| `skills/` | 技能库（§4.10.1–4.10.2） |
| `agents/` | AI 角色（§4.10.3–4.10.4） |
| `runs/` | 任务历史、流水线、快捷任务（§4.10.5） |
| `courses/` | 词库与课程：资料、AI 分析、模板、生成、编辑、检查、试玩、审核、发布、版本历史 |
| `pets/` | 伙伴设计与档位、阶段 |
| `yahaha/` | 呀哈哈家族款式、套组、全局设置、统计 |
| `rules/` | 投放规则 |
| `families/` | 家庭：注册码签发、停用 / 恢复家庭、举报队列与处理 |
| `settings/` | 系统设置（AI 开关与模型、注册模式、伙伴 / 发现 / 工作室 / 角色参数）、装扮商店目录 |
| `audit/` | 审计记录、异常与对账、备份状态 |

每个页面顶部都有**一句话框**（默认交给该页面的 AI 角色，见系统设置 `agents.page_routes`，可 `@角色`）。AI 只写草稿，发布按钮只在人工审核界面。
