# admin/studio —— AI 工作室（仅系统管理员）

- `pets/`：伙伴设计：描述 + 风格模板 → 4 张候选 → 选定 → 阶段形象与动作关键帧 → 动效模板 → 声音与台词 → 预览 → 草稿 → 审核 → 发布；档位与阶段设置
- `yahaha/`：呀哈哈款式设计（弹出/旋转/挥手动效 + 叫声）、套组、全局开关/概率/上限、款式稀有度/上限/库存/上下架、统计
- `courses/`：课程：资料上传与抽取、AI 分析清单、选模板、预估费用、生成、表单编辑与“让 AI 重写这一题”、自动检查（红色标记）、学生视角试玩、审核、发布、版本历史
- `rules/`：投放规则：表单或一句话生成、大白话复述与影响估算、重叠提示、草稿/发布/暂停、审计记录

共用：任务列表（排队/运行/成功/失败、预估与实际费用）、本月预算、素材库。
