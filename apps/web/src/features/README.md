# features —— 按功能划分

**child/**（孩子端）
- `login/`：登录入口：头像墙 + PIN、孩子用户名密码；家长登录 / 注册 / 找回密码也从同一入口进入（登录后进入 `parent/`）
- `learn/`：学习：课程下拉与自选课程、单元冒险地图与启思大陆总览（含秘密路线、“今天还能找 N 个”）、学习卡、10 种题型作答（两步作答、逐题反馈与答后显示）、结果页（星级、隐藏奖励揭晓）、学习足迹；原型 D 外壳（六项导航、顶栏）
- `review/`：复习：今日到期数、复习作答、完成奖励
- `wordbook/`：单词本：词书与进度、每日任务、随机抽词、听写与拼读（得学习星，计入学习日）
- `companion/`：伙伴：宠物家园（营地）、领养（星星或碎片）、设为跟随伙伴、改名、摸摸 / 点心 / 玩耍、退订、赠送、成长装扮与动作
- `discovery/`：呀哈哈发现：关卡场景中的 3 个藏匿点、点开揭晓、发现动画与叫声
- `album/`：图鉴：按套组展示已找到/未找到的呀哈哈家族款式、找到次数与累计
- `shop/`：星星小铺四卡：喜欢的时光（按份兑换）、探险徽章（购买与佩戴）、累计奖励（用掉）、复习积分（换星）
- `social/`：社交：排行榜、星星伙伴列表、赠送、信件与短语消息、信箱、好友、举报与屏蔽
- `chat/`：呀哈哈队长：所有页面右下角的浮动聊天（对话只在内存；家长端同样使用）

**parent/**（家长中心）
- `dashboard/`：孩子概览与档案、家庭设备与会话、跨家庭开关与好友家庭
- `reports/`：每日报告、周汇总、学习全览与知识图谱、周报订阅、查看孩子消息
- `controls/`：时长与时段、课程开放、呀哈哈队长额度、退出排行、加时
- `approvals/`：审批收件箱（兑换、好友请求）、奖励清单、累计奖励与核销、加星与扣星

系统管理端不在本应用中，见 `apps/admin`。
