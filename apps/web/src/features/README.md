# features —— 按功能划分

**child/**（孩子端）
- `login/`：登录入口：头像墙 + PIN、孩子用户名密码；家长登录 / 注册 / 找回密码也从同一入口进入（登录后进入 `parent/`）
- `learn/`：学习：课程列表、关卡路线图（含“今天还能找 N 个”）、9 种题型作答（逐题反馈）、结果页
- `review/`：复习：今日到期数、复习作答、完成奖励
- `companion/`：学习伙伴：营地、领养（星星或碎片）、设为陪伴、成长阶段与动作、互动动画与声音
- `discovery/`：呀哈哈发现：关卡场景中的 3 个藏匿点、点开揭晓、发现动画与叫声
- `album/`：图鉴：按套组展示已找到/未找到的呀哈哈家族款式、找到次数与累计
- `shop/`：商店：装扮购买与穿戴、现实奖励申请
- `social/`：社交：排行榜、赠送、消息、好友、举报与屏蔽
- `chat/`：呀哈哈队长：所有页面右下角的浮动聊天（对话只在内存；家长端同样使用）

**parent/**（家长中心）
- `dashboard/`：孩子概览与档案、家庭设备与会话、跨家庭开关与好友家庭
- `reports/`：每日报告、周汇总、周报订阅、查看孩子消息
- `controls/`：时长与时段、课程开放、呀哈哈队长额度、退出排行、加时
- `approvals/`：审批收件箱（兑换、好友请求）、奖励清单、手动奖励

系统管理端不在本应用中，见 `apps/admin`。
