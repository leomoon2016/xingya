# features —— 按功能划分

- `login/`：登录：头像墙 + PIN、孩子用户名密码、家长登录/注册/找回密码
- `learn/`：学习：课程列表、关卡路线图、4 种题型作答、结果页
- `review/`：复习：今日到期数、复习作答、完成奖励
- `shop/`：商店：物品、购买、穿戴与陪伴宠物、现实奖励申请
- `social/`：社交：排行榜、赠送、消息、好友、举报与屏蔽
- `chat/`：呀哈哈：所有页面右下角的浮动聊天（对话只在内存）
- `parent/`：家长中心：孩子档案、管控、报告、审批收件箱、设备与会话、奖励清单、跨家庭设置
- `admin/`：系统管理端：举报处理、异常、系统设置、注册码
