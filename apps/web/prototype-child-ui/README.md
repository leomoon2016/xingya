# 原型：孩子端界面（PROTOTYPE，用完即弃）

> **这是一次性原型，不是产品代码。** 只用来回答一个问题：**孩子端长什么样？**
> 只存在于分支 `prototype/child-ui`，不合入 `main`。选定方案后，按正式规范（React 19 + CSS Modules + `packages/ui` 设计令牌）在 `apps/web/src/features/child/` 重写，然后丢掉本目录。

三套结构不同的方案，加上一套参考老系统的方案 D，放在同一个页面里，用 `?variant=A|B|C|D` 切换：

> **⚠️ 原型专用：方案 D 里的马里奥、林克是任天堂的第三方 IP（图片从老系统 `public/assets/companions/` 复制），只用来对照老系统，不能进正式版，也不能拿去对外演示或发布。**

| 键 | 名字 | 一句话 |
| --- | --- | --- |
| A | 藤蔓小路 | 地图优先：整门课程是一根一直长下去的藤蔓，关卡是藤上的花苞 |
| B | 贴纸本 | 任务优先：打开本子先看“今天做什么”，每个单元是一页贴纸格 |
| C | 伙伴小岛 | 伙伴优先：跟随伙伴站在正中，用一句话带孩子出发，一次只看一个单元小岛 |

## 运行

```bash
node apps/web/prototype-child-ui/serve.mjs
# 打开 http://localhost:5180/?variant=A
```

- 没有构建、没有依赖：纯静态 HTML/CSS/JS；`serve.mjs` 只用 Node 自带的 `http` 模块，并按主站 CSP（`default-src 'self'`，无内联脚本、无第三方源）返回响应头，原型里不能偷偷用到第三方资源。
- 屏幕底部正中的黑色药丸是原型切换器：左右箭头或键盘 `←` / `→` 切换方案（输入框有焦点时不响应）；“状态”按钮展开当前内存状态与几个原型捷径（家长解锁、重置）。切换方案不丢状态。
- 所有数据都是内存里的假数据，刷新即重置。PIN：小米 `3816`、豆豆 `4729`；阿宝已被锁定（演示锁定状态），可在“状态”里模拟家长解锁。
- 发音按钮用浏览器 `speechSynthesis`（仅原型；正式版用发布时生成的 Piper 音频）。

## 原型范围

1. 头像墙 + PIN：3 个孩子、PIN 错误（剩余次数）、5 次错误锁定 15 分钟（“请 15 分钟后再试或请家长帮忙”）。
2. 学习主页 / 关卡地图：当前课程“一年级上册”，5 个单元（Unit 1–2 已完成、Unit 3 Animals 进行中、Unit 4–5 未解锁），关卡的完成/当前/未解锁与星级；跟随伙伴、星星余额、今日复习数、呀哈哈队长浮动入口。
3. 闯关答题：Unit 3 第 3 关，6 道计分题，三种题型——看图选词（`pick_image`）、听音选词（`listen_choose`）、排序（`order`，词块排成句子）。逐题反馈只记第一次作答；没有全部作答之前“完成这一关”不可用；结算按 learning 需求 §4.1.4 计算星级、星星、碎片、伙伴经验，并打开 3 个藏匿点。

内容是真实的一年级英语：cat、dog、duck、fish、bird、rabbit，以及句子 *This is a duck.*。插图全部是原型里手写的简单 SVG 形状（原创，非素材库、非 emoji）。

## 设计计划（先写计划，再动手）

共同的出发点：使用者是 6–7 岁、刚开始认英文字母的孩子，在家里的平板/电脑上自己学；家长不在旁边。品牌是“星芽”——一颗会发芽、长大、开出星星的种子；孩子收集星星、碎片、伙伴与呀哈哈家族。所有方案共用：中文做指令和导航，英文只出现在学习内容里；英文学习内容用一款**为初学读者设计**的字体（单层 a 和 g，与孩子手写一致）；中文用系统字体栈（CSP 禁止第三方字体源，英文字体为本地自托管 woff 子集，见 `fonts/`）。

### A 藤蔓小路（地图优先）

- **概念**：整门课程画成一根连续的藤蔓，从 Unit 1 长到 Unit 5；学过的部分是绿色实线，没学的是泥土色虚线，当前关卡是藤尖上鼓起的花苞——孩子一眼看到“我长到哪儿了”。
- **颜色**
  - 晨空 `#E3F2FA`：底色（清晨窗边的天空，不是米黄纸）
  - 嫩芽 `#8CCB5E`：已长出的藤与叶
  - 深叶 `#24734A`：主按钮、当前花苞（白字对比 5.8:1）
  - 泥土 `#6E4B2A`：没长出的路、未解锁
  - 向日葵 `#FFC93C`：星级与星星
  - 墨绿 `#173A2A`：正文（对晨空 11:1）
- **字体**
  - 英文学习内容：**Andika**（SIL 为初学读者设计的字体，单层 a/g，字母形状与课本手写一致），自托管。
  - 中文：系统黑体栈 `"HarmonyOS Sans SC", "PingFang SC", "MiSans", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif`。
  - 字号（1.25 比例）：14 / 17 / 21 / 26 / 33 / 41 / 64（题目单词），行高中文 1.6、英文单词 1.1。
- **版式**：横屏下地图占满整屏，顶部只有一条很薄的状态条；手机竖屏把藤蔓转成从上往下长。内容左对齐，藤蔓本身居中摆动。

├──────────────────────────────────────────┤   │ 一年级上册        │

- **最大胆的一处**：那根贯穿所有单元、会“长”的 SVG 藤蔓（通关后实线向前长一节）。

### B 贴纸本（任务优先）

- **概念**：一本摊开的贴纸本。左页是“今天”：一个大按钮告诉孩子下一步做什么、还有几个词要复习；右页按单元分页，右边缘是单元索引签，每页是这一单元的贴纸格，过一关就贴上一张模切贴纸。
- **颜色**
  - 葡萄 `#4B32C3`：封面、索引签、主按钮（白字 8.3:1）
  - 纸页 `#F6F4FF`：内页（偏冷的淡紫白，不是米黄）
  - 泡泡糖 `#FF5C9A`：当前关卡、提示
  - 薄荷 `#22B88A`：答对
  - 柠檬 `#FFE04A`：星级印章
  - 墨紫 `#251D4F`：正文（对纸页 14:1）
- **字体**
  - 英文学习内容与少量标题数字：**Playpen Sans**（为书写教学设计的手写体），自托管 500/700 两个静态字重。
  - 中文标题：楷体栈 `"Kaiti SC", "STKaiti", "KaiTi", "LXGW WenKai"`，取小学课本、田字格的感觉；中文正文退回系统黑体栈（楷体在小字号下不够清楚）。
  - 字号（1.2 比例，偏紧凑以便两页并排）：14 / 16 / 19 / 23 / 28 / 34 / 56。
- **版式**：横屏是左右两页（约 38% / 62%），手机竖屏两页上下叠放，索引签变成页顶一排。左页内容左对齐，贴纸格网格居中。

```
横屏 1024×768                                   手机 360×800
┌───────────────┬──────────────────────────┬┐  ┌──────────────────┐
│ 今天           │ Unit 3 Animals  已贴 2/5  │1│  │(头)小米   ★128   │
│ (伙伴)         │ ┌───┐ ┌───┐ ┌ ─ ┐        │2│  │[继续：Unit 3 第3关]│
│ [继续：Unit 3  │ │cat│ │dog│ │ 3 │ 当前   │3│  │ 复习 6 个词       │
│   第 3 关]     │ └───┘ └───┘ └ ─ ┘        │4│  │[1][2][3][4][5] 签 │
│ 复习 6 个词    │ ┌ ─ ┐ ┌ ─ ┐              │5│  │ 贴纸格 2 列        │
│ ★128  换人     │ │ 4 │ │ 5 │ 未解锁        │ │  │                  │

```

- **原则**：先回答“现在做什么”，地图退到第二层；页面质感来自纸和贴纸本身，不用阴影卡片；只有贴纸可以歪一点。
- **最大胆的一处**：白边模切贴纸——每张贴纸是该关的动物图，带白色描边、轻微旋转，星级像印章盖在贴纸角上；没贴的是虚线格。

### C 伙伴小岛（伙伴优先）

- **概念**：孩子的跟随伙伴是主角，站在屏幕正中的小岛上，用一句话带路（“今天去 Unit 3 第 3 关吧！”）；单元是一座座小岛，一次只看一座，关卡是岛上的踏脚石。答题时也是伙伴在问、在反应。
- **颜色**
  - 暮蓝 `#24408E`：天空底色（是有颜色的深蓝，不是近黑）
  - 云白 `#F3F7FF`：对话气泡、选项（墨蓝字 14:1）
  - 沙滩 `#FFE3A3`：小岛、强调文字（对暮蓝 7.6:1）
  - 潟湖 `#3FB8C6`：海水、次要按钮
  - 星金 `#FFC21A`：星级、星星、主按钮
  - 莓红 `#C2365F`：答错提示（白字 5.3:1）
  - 墨蓝 `#13224F`：浅底上的正文
- **字体**
  - 英文学习内容：**Lexend**（为改善阅读流畅度设计的宽字距无衬线体），自托管可变字重。
  - 中文：圆体栈 `"Yuanti SC", "YouYuan", "HarmonyOS Sans SC", "PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC"`（有圆体的设备上显示圆体）。
  - 字号（1.333 比例，气泡里的句子要大）：14 / 18 / 24 / 32 / 42 / 56。
- **版式**：横屏左边是伙伴与对话气泡（主入口），右边是一座单元小岛和前后切换；手机竖屏伙伴在上、气泡在中、小岛在下。气泡与小岛内容居中。

- **最大胆的一处**：大号、会变表情的跟随伙伴和它的对话气泡（主操作按钮长在气泡里）。

## 文档缺口与待确认的问题

1. **题型与年级冲突**：需求说 1–2 年级课程不得出拼写题（learning §4.1.3），而本次原型需求提到“拼写/排字母”。原型按文档执行，第三种题型用“排序（词块排成句子）”，没有做拼写。
2. **没有“听音选图”**：9 种题型里，听音选词与看图选词都是“选词”。一年级刚入学的孩子可能还不认得单词，是否需要“听音选图”（`listen_pick_image`）？如需要，要改 learning 需求与课程模型。
3. **头像墙的家长入口、换人、锁定提示**只有一句文字规定（family §4.3），没有线框图；`docs/04-ui-design/wireframes/child/` 与 `flows/child/` 目前只有 README。
4. **复习入口在主页上的形态**未定义（只规定了“今日到期数”）。原型只做了入口按钮，复习页未做。
5. **跟随伙伴在主页的位置与大小**没有规定；三套方案给出了三种答案（A 站在当前关卡旁、B 在左页角落、C 是主角）。
6. **藏匿点的呈现**：需求只说“关卡场景里打开 3 个藏匿点”，没有说孩子是点开还是自动揭晓；原型做成逐个点开（A 叶子堆、B 页角、C 沙堆）。
7. **结算未通过时**（0 星级）给孩子看什么、是否显示答错的题，没有文档；原型只显示“答对 N 题就能过关”和“再玩一次”。
8. **字体**：设计令牌（`tokens/design-tokens.json`）尚未提交，没有指定字体。英文字体建议从 Andika / Playpen Sans / Lexend 中定一个并自托管（都是 OFL 许可）；中文楷体、圆体只能依赖系统字体（本机截图环境没有楷体、圆体，截图里显示的是黑体回退）。
9. **2 星级永远拿不到**：星级规则是全对 3 星级、`C×100 ≥ S×90` 2 星级、`C×100 ≥ S×80` 1 星级（learning §4.1.4），而每关计分题 `S` 是 4–8 道。要满足 `S×0.9 ≤ C < S` 至少需要 10 道计分题，所以在 4–8 题的关卡里只会出现 0、1、3 星级（例：6 题对 5 题 = 83%，1 星级；8 题对 7 题 = 87%，1 星级，文档自己的例子也是这样）。需要确认是否改阈值（例如“错 1 题 = 2 星级”）。

### 哪些对孩子有用、值得留

1. **“我在地图上哪一站”一眼可见**：小路、木章、名牌、星级小牌这套组合，孩子不用读字就知道哪关做完了、做到第几颗星、下一关在哪。
2. **三种状态各有一个固定颜色**，并配了图例：现在出发是青、已完成是金、等待解锁是灰加锁。
3. **左栏只有一个主动作**：“继续闯关”，大按钮放在单元卡里。复习入口单独做成一张小卡，不和主动作抢位置。
4. **搭档在答题时“陪着走”**：检查点小路每答一题前进一格，给孩子很实在的进度感。
5. **选项是大卡片加独立喇叭**：不认识的词可以先听一遍再选。
6. **答错的语气温和**：“再认识它一次”加一句解释，没有红叉，也没有扣分音。
7. **颜色安静、自然**：大面积浅草地和纸白，饱和色只用在状态和主按钮上，长时间看不累。

### 老系统的积分规则（只读看过的文件）

老仓库 `/workspace/learning-platform`，HEAD `81b4aa9`，只读。下面的路径都相对 `code/`。

**记账方式**

- 积分按 0.01 分记整数（`points_balances.balance_units`），每笔进出写进只追加的 `points_ledger`（`server/community.mjs`）。
- 积分和星星是两种钱。星星记在另一套钱包里，积分可以换星星，反过来不行。

**怎么挣**

| --- | --- | --- | --- |

**怎么花**

- 只有一种用法：**10 积分换 1 颗星星**，一次可换 1–1000 星（`server/community.mjs` `convertPoints`，175 行起；钱包流水类型 `points_exchange`）。

**顶栏**：一排“口袋”：

### 加回这些以后，和新文档的冲突

1. **两种货币**：新文档只有星星（加碎片）。积分是第二种钱，10 积分换 1 星，等于给星星开了一个后门，星星会通胀，“星星 = 学会了多少”的意义被稀释。
2. **被动行为发奖励**：新文档写明“被动行为不发任何奖励”。听读 +0.1 正是被动行为，而且闯关里**没有每日上限**，重开同一关又能领。一关 6 题、每题 2–4 个喇叭，刷一轮 1 分左右，换算成星星虽然慢，但会鼓励“乱点喇叭”而不是答题。
3. **复习给积分不给星星**：新文档是复习完成给星星。
4. **伙伴附赠和星级挂钩**：附赠按“新增星星 × 等级系数”算，会给跟随伙伴引入“等级越高送得越多”的养成数值，新文档的跟随伙伴没有这一层。
5. **兑换、星星小铺**：积分唯一的用处是换星星，再去小铺花。新文档首发没有小铺，积分在 D 里攒着没地方用。
6. **第三方 IP**：马里奥、林克和新文档“禁止第三方 IP、跟随伙伴是原创种子团子”直接冲突。主页搭档卡从团团换成了马里奥，跟随伙伴在主页上看不到了。
7. **呀哈哈 N / 1000**：老系统的呀哈哈收藏上限 1000、全局计数，新文档里呀哈哈是结算时 3 个藏匿点、找到给碎片，没有收藏上限，也没有顶栏计数。D 两个都保留了，含义会让人混淆。
8. **顶栏积分计数**：老系统也没有，是这次新加的。它把积分放在和星星同级的位置，进一步强化了第 1 条。
