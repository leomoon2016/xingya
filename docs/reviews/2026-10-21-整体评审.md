## 6. 建议

1. **W0 立即提交 ICP 备案**（主域名与 CDN 子域名），并同时开通 OSS、CDN 与 RAM 子账号，这是路线图里唯一的外部阻塞。
2. 实现 learning 时先写“选项令牌映射”和“锁顺序”的集成测试（并发结算 + 赠送 + 领养），再写业务代码。
3. 资料上传与抽取在 W15 之前用压缩炸弹、超大 PDF、含宏文件做一次专项测试。
4. 进度不足时严格按削减顺序执行（全站榜 → 跨家庭消息 → 好友家庭 → AI 一句话规则 → AI 生成课程 → 呀哈哈队长），不要削减碎片账本、藏匿点的服务端判定与工作室预算。
5. 一旦有任何环境执行过 `0001_init.sql`，之后的结构变更只能追加新迁移；建议在 W1–2 部署前再跑一次 `db/verify`。
6. 每个里程碑结束时复跑本次的链接检查与过期术语检索，下一次整体评审放在 W10（学习完成后）。
