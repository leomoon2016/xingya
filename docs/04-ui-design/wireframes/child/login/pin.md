# 线框：PIN 输入

## 目的

验证孩子身份；错误计数与锁定规则同家庭账号需求。

## 主画框 1024×768

```
┌────────────────────────────────────────────────────────────┐
│ [芽] 星芽学园                              [家长入口]      │
├────────────────────────────────────────────────────────────┤
│  ┌────────────── 白卡片 两栏 ──────────────┐               │
│  │ (←换人)                                 │               │
│  │  左：大头像环 + 昵称 + 状态文案          │ 右：•••• 点   │
│  │      （错：橙底；锁：黄底木边）          │    1 2 3     │
│  │                                         │    4 5 6     │
│  │                                         │    7 8 9     │
│  │                                         │      0  ⌫    │
│  └─────────────────────────────────────────┘               │
└────────────────────────────────────────────────────────────┘
```

## 手机 360×800

单列：上头像与文案，下数字键盘；返回钮左上。

## 关键状态

| 状态 | 表现 |
| --- | --- |
| 输入中 | 圆点逐个点亮（wood/gold） |
| 错误 | 文案 + 键盘轻抖；剩余次数 |
| 锁定 | 无键盘；「请 N 分钟后再试或请家长帮忙」 |
| 成功 | 进入外壳「我的学习」 |

## 空态 / 错误

网络失败：保留已输入长度提示，给「重试」；不 Cleared PIN 静默失败。

## 无障碍

状态区 `role="alert"`；键盘键 ≥ 44×44（原型 76×68）；减少动画时关闭 shake。
