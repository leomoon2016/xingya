# 线框：头像墙（谁来学习？）

## 目的

家庭设备上家长已登录后，孩子点自己的头像进入 PIN；也是「换人」的落地页。

## 主画框 1024×768

```
┌────────────────────────────────────────────────────────────┐
│ [芽] 星芽学园                              [家长入口]      │
├────────────────────────────────────────────────────────────┤
│                                                            │
│              ┌──────── 白卡片（max≈860）────────┐           │
│              │     谁来学习？                    │           │
│              │     点一点自己的头像 🌿            │           │
│              │  ┌────┐  ┌────┐  ┌────┐         │           │
│              │  │头像│  │头像│  │锁头│         │           │
│              │  │小米│  │豆豆│  │阿宝│         │           │
│              │  │★128│  │★40 │  │锁住│         │           │
│              │  └────┘  └────┘  └────┘         │           │
│              └─────────────────────────────────┘           │
└────────────────────────────────────────────────────────────┘
```

- 孩子卡：金环头像 120、昵称、星星数；锁定态灰环 + 灰度头像 +「锁住了」。
- 无六项导航（未入孩子会话）。

## 手机 360×800

孩子卡改为横向满宽列表（头像 64 + 名 + 星），减少折行。

## 关键状态

| 状态 | 表现 |
| --- | --- |
| 正常 | 可点进入 PIN |
| 锁定中 | 不可进 PIN；文案引导找家长 |
| 仅 1 个孩子 | 仍显示墙（不自动跳过，避免误入） |

## 空态 / 错误

- 家庭无孩子：卡片内「请家长先添加孩子」。
- 加载失败：重试按钮 ≥ 44×44。

## 无障碍

每张孩子按钮 `aria-label` 含昵称与锁定状态；键盘可焦点顺序从左到右。
