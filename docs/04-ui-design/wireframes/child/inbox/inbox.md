# 线框：信箱

## 目的

信件 + 系统通知（兑换、核销、加减星、伙伴赠送/退订、扩建等）；顶栏未读入口。

## 主画框 1024×768

```
┌─ 从头像旁 ✉ 进入（非 Tab）────────────────────────────────┐
│ 信箱  未读 3                    [全部标已读]              │
│ ┌未读● 家长批准了「玩游戏机」…      今天 21:00┐           │
│ ├ 豆豆：主题…（信件）                    昨天 ┤           │
│ └ 系统：营地扩建成功 …                       ┘           │
│ 点开：正文 ≤500；信件可回复入口（社交）                   │
└───────────────────────────────────────────────────────────┘
```

## 手机 360×800

全屏列表；详情二级。

## 关键状态

空信箱插画；仅系统通知时无「回复」。

## 空态 / 错误

加载失败重试。

## 无障碍

未读不只靠圆点颜色（加「未读」文字或加粗）。
