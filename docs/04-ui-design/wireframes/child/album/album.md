# 线框：呀哈哈图鉴

## 目的

套组集齐进度 + 全部合计「已找到款式数 / 款式总数」；与顶栏「森林口袋 N/1000」（累计找到次数/收藏上限）区分。

## 主画框 1024×768

```
┌─ 可从头像旁呀哈哈胶囊进入 ───────────────────────────────┐
│ 森林口袋 12/1000（收藏上限）                              │
│ 图鉴集齐  48/120 款 · 套组进度                            │
│ ┌套组A 6/10┐ ┌套组B 2/8┐ ┌套组C 0/12 雾┐                 │
│ │ (款式格)  │ │         │ │             │                 │
│ └──────────┘ └─────────┘ └─────────────┘                 │
│ 点款式：已获得详情 / 未获得剪影                           │
└───────────────────────────────────────────────────────────┘
```

## 手机 360×800

套组手风琴列表。

## 关键状态

未获得剪影；限定/下架标记。

## 空态 / 错误

0 款：引导去闯关翻藏匿点。

## 无障碍

进度数字可读；剪影不依赖纯颜色区分（加「未获得」文字）。
