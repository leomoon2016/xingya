# 线框：呀哈哈队长聊天

## 目的

全页右下 FAB 打开的聊天面板（非六项 Tab）；儿童安全过滤与配额。

## 主画框 1024×768

```
                          ┌─面板 max360×460─┐
                          │ (脸) 呀哈哈队长 [×]│
                          │ 气泡对话…         │
                          │ [快捷芯片…]       │
                          │ [输入____] [发送] │
                          │ 今日余量提示      │
                          └───────────────────┘
                                    (FAB 64)
```

## 手机 360×800

面板近全宽；FAB 避开底 Tab（上移）。

## 关键状态

| 状态 | 表现 |
| --- | --- |
| AI 关闭 | FAB 可说明原因，面板不可发 |
| 考试中 | 「交卷后再聊」 |
| 配额尽 | 输入禁用 |

## 空态 / 错误

网络失败可重送；违规提示友善不暴露内部规则细节。

## 无障碍

关闭钮 44；对话 `aria-live=polite`；减少动画无气泡入场。
