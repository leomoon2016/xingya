# 线框：复习小站

## 目的

间隔复习作答；答对 +1 积分（每天 ≤30）；入口来自「我的学习」复习卡与小铺「复习积分」卡。

## 主画框 1024×768

```
┌─ 外壳（可高亮我的学习）───────────────────────────────────┐
│ 复习小站 · 今日到期 6 · 今日积分 12/30                     │
│ ┌────────────────────────────────────────────────────┐    │
│ │ 题干区（词/句） + 喇叭                              │    │
│ │ 选项或拼写（按年级规则）                            │    │
│ │ 进度 3/6                                            │    │
│ └────────────────────────────────────────────────────┘    │
│ [稍后再说]                              [下一题]           │
└───────────────────────────────────────────────────────────┘
```

完成当日： Congrats + 碎片（规则内）+ 回学习。

## 手机 360×800

单卡作答；顶显示到期数与积分额度。

## 关键状态

| 状态 | 表现 |
| --- | --- |
| 今日无到期 | 空态「今天没有要复习的词」+ 去闯关 |
| 积分已满 30 | 喇叭/作答仍可，提示不再加积分 |
| 全部完成 | 完成页 |

## 空态 / 错误

出题失败：列出原因；回首页。

## 无障碍

与闯关相同的触控与对比度；不强制限时。
