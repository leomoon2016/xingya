# 线框：我的设置

## 目的

头像菜单进入；昵称自改、声音、减少动画、设备与安全提示（只读）。

## 主画框 1024×768

```
│ ← 我的设置                                                │
│ 头像（展示）  昵称 [________] [保存]  1–24 字             │
│ 声音        (开/关)  本地+服务端 pref_sound               │
│ 减少动画    (开/关)  pref_reduced_motion                  │
│ 当前课程    （只读跳转顶栏说明）                           │
│ 佩戴徽章    跳转小铺徽章                                   │
│ ── 账号 ──                                                │
│ 换人 / 锁定说明（PIN）只读帮助                             │
```

## 手机 360×800

分组列表；开关行高 ≥ 44。

## 关键状态

昵称冲突/个人信息拦截；保存成功 Toast。

## 空态 / 错误

保存失败保留草稿。

## 无障碍

开关需可读名称；减少动画立即作用于本页过渡。
