# 线框：隐藏奖励揭晓

## 目的

每单元 ≤ 2 关配置；结算时首次揭晓：星星翻倍或宝箱 +20；每人每关一次。

## 主画框 1024×768

嵌在 [settlement](settlement.md) 内的高亮条/模态：

```
┌─ ✨ 隐藏奖励 ─────────────────────────┐
│  这一关藏着惊喜！                      │
│  本次新得星星 ×2  /  宝箱打开 ★+20     │
│  [好的]                                │
└────────────────────────────────────────┘
```

地图上可选：关卡名牌角标「？」仅在未领且已配置时给家长/孩子弱提示（勿剧透具体类型）——产品可选用，线框标注为可选。

## 手机 360×800

全宽模态；主按钮 ≥ 44。

## 关键状态

已领取：结算不再出现；重玩无重复发放。

## 空态 / 错误

发放失败：记录 claim 幂等键，回地图后信箱可补通知。

## 无障碍

模态陷阱焦点；Esc/关闭按钮明确。
