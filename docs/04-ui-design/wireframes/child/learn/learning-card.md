# 线框：学习卡（闯关前）

## 目的

进入关卡作答前展示本关学习卡（1–50 张）；首次展示可发学习卡碎片（ADR 0020）。

## 主画框 1024×768

```
┌─ 无底 Tab（沉浸）─────────────────────────────────────────┐
│ ← 回地图    Unit 3 · 第 3 关 · 站点名「果园」   卡 2/6    │
│ ┌──────────────────┐  ┌──────────────────────────────┐   │
│ │                  │  │ 标题 / 英文词（Andika）       │   │
│ │   大图 / 字母卡   │  │ 中文说明                      │   │
│ │                  │  │ [喇叭]  短语/例句              │   │
│ └──────────────────┘  └──────────────────────────────┘   │
│          [上一张]              [下一张 / 开始闯关]         │
│  （末张后主按钮变为「开始闯关」）                           │
└───────────────────────────────────────────────────────────┘
```

## 手机 360×800

上图下文；底栏固定翻页；字号不小于 base。

## 关键状态

| 状态 | 表现 |
| --- | --- |
| 首次翻完 | Toast 或角标「碎片 +N」（规则内） |
| 已看过 | 不再发碎片 |
| 无学习卡 | 跳过本页直接进 quiz（若课程允许） |

## 空态 / 错误

素材缺失：占位图 +「图片还在路上」；仍可继续。

## 无障碍

喇叭旁有文字对应；减少动画时无翻页过渡。
