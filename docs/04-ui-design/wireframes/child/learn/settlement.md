# 线框：关卡结算

## 目的

完成关卡后展示**至少 1 星级**、星星/碎片/积分/伙伴经验、藏匿点；可回地图或再玩。

## 主画框 1024×768

```
┌─ 外壳可保留顶栏 ──────────────────────────────────────────┐
│ ┌──────────────── 结算卡 ────────────────────────────┐    │
│ │ [搭档卡]  闯过第 N 关啦！                          │    │
│ │           Unit x 第 N 关 · 答对 C/S                │    │
│ │           ★ ★ ★（1–3，按错题数）                   │    │
│ │  收益：星星 +a  碎片 +b  积分 +p  伙伴经验 +e      │    │
│ │  听读本轮 …；伙伴附赠说明                          │    │
│ │  ┌隐藏奖励揭晓（若本关有且首次）────────────────┐  │    │
│ │  │ 本次星星翻倍 / 宝箱 +20 星                    │  │    │
│ │  └──────────────────────────────────────────────┘  │    │
│ │  藏匿点： [灌木][灌木][灌木] 三点取一翻开           │    │
│ │  [回到地图]  [再玩一次]                             │    │
│ └────────────────────────────────────────────────────┘    │
└───────────────────────────────────────────────────────────┘
```

**注意**：关卡**没有**「差一点点再来一次」的未通过页（ADR 0020）；未通过样式只用于秘密路线失败。

## 手机 360×800

纵排：搭档卡居中缩小；收益换行；藏匿点三等分；主按钮全宽。

## 关键状态

| 状态 | 表现 |
| --- | --- |
| 首次通关 | 满收益 + 藏匿点 |
| 重玩无新星 | 说明「以前拿过同样星级，不再加星星」仍可有听读积分 |
| 隐藏奖励已领 | 不重复揭晓 |
| 呀哈哈满仓 | 藏匿点找到后提示放不下/路上 |

## 空态 / 错误

结算 API 失败：显示「成绩已记下，奖励稍后到账」+ 回地图；禁止重复点完成刷奖（幂等）。

## 无障碍

星级 `role="img" aria-label="k 星级"`；藏匿点按钮打开后状态更新给读屏。
