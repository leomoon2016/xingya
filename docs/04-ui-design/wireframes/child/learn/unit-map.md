# 线框：单元冒险地图（闯关地图）

## 目的

展示当前课程某一单元的关卡路径、星级、锁定雾；进入关卡 / 秘密路线入口。

## 主画框 1024×768

```
┌─ 外壳（当前：闯关地图）───────────────────────────────────┐
│ [启思大陆总览]  Unit 3 Animals 果园    已完成 2/5          │
│ ┌Unit1┐┌Unit2┐┌Unit3·on┐┌Unit4锁┐┌Unit5锁┐               │
│ │                                                         │
│ │   (远空/草地/溪桥 SVG 场景)                              │
│ │        ①──②──(③当前)──④锁──⑤锁                          │
│ │         ★★★  ★★☆  现在出发                               │
│ │   ◇金币小径?  ◇赛车捷径?  ◇月亮秘境?   ← 条件满足时出现   │
│ │                                                         │
│ │ 图例：现在出发 | 已完成 | 等待解锁                        │
└───────────────────────────────────────────────────────────┘
```

- 关卡节点：木牌圆章 + 白名牌 + 星级小牌；当前关 teal 发光环。
- 未解锁单元：场景雾化 + 中央提示「完成 Unit N-1 才能来这里」。
- 秘密路线：地图上独立入口徽章（金币/赛车/月亮），点入确认入场费。

## 手机 360×800

地图改用竖向小路坐标（原型 tall 500×820 比例）；单元 Tab 可横向滑动；节点略缩小但仍 ≥ 44 触控热区。

## 关键状态

| 状态 | 表现 |
| --- | --- |
| done / current / locked | 奖牌色与锁标 |
| 秘密路线未发现 | 不渲染入口 |
| 秘密路线已进入未通过 | 入口可点，提示重试免费 |
| 减少动画 | 关闭当前关呼吸光 |

## 空态 / 错误

课程无单元：罕见，显示「课程内容准备中」。

## 无障碍

每个节点 `aria-label`：「第 n 关 标题，k 星级 / 现在出发 / 等待解锁」；秘密路线标明入场星数。
