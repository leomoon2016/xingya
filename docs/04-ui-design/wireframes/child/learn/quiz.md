# 线框：闯关作答（Play / Quiz）

## 目的

逐题作答；题号 + 冒险进度轨道（游戏搭档主题）+ 选项/排序；全部作答前不可完成。

## 主画框 1024×768

```
┌────────────────────────────────────────────────────────────┐
│ ←退出   Level title（Andika）              [还差 N 题]     │
│ ┌──────────────────────────────────────────────────────┐   │
│ │ 第 3/6 题   ====●====旅行者====○====○====   金币跳跃 │   │
│ │ 提示：听一听再选…                                     │   │
│ │ ┌─问区──────────┐  ┌─答区─────────────────────────┐ │   │
│ │ │ 指令 / 大图    │  │ A 选项词  [喇叭]              │ │   │
│ │ │ 或大喇叭听音   │  │ B …                          │ │   │
│ │ │ 听读 +0.1 提示 │  │ C …                          │ │   │
│ │ └───────────────┘  └──────────────────────────────┘ │   │
│ │ ┌反馈：答对了！/ 再认识它一次──── [下一题]─────────┐ │   │
│ └──────────────────────────────────────────────────────┘   │
└────────────────────────────────────────────────────────────┘
```

星级规则（结算用，作答中不预告失败）：错 0→3 / 错 1→2 / 错≥2→1；**无未通过**。

## 手机 360×800

问区在上、答区在下；底反馈栏全宽；进度轨道折到第二行；页底 padding 避开误触。

## 关键状态

| 状态 | 表现 |
| --- | --- |
| 未答 | 选项可点 |
| 答对 | mint 底；可下一题 |
| 答错 | 橙底；显示解释；可下一题 |
| 全部作答 | 「完成这一关」亮起 |
| 听读已领 | 喇叭 `is-claimed` 描边 |

## 空态 / 错误

断线：本地保留作答进度，提示重试提交；退出确认是否离开（进行中 play 可恢复）。

## 无障碍

进度条 `role="progressbar"`；选项字母 + 单词可读名称；听音题必须有文字指令；焦点管理到反馈主按钮。
