# 线框：我的学习（首页）

## 目的

登录后默认落地：招呼、游戏搭档卡、继续闯关、复习小站；右侧（横屏）可同屏展示当前单元地图摘要，或仅左栏 + 引导去「闯关地图」。

正式版六项导航下，「我的学习」与「闯关地图」分 Tab；横屏仍可采用原型 D 的**左栏 + 右地图**同屏组合（左栏属本页，右图可嵌入或深链到闯关地图）。

## 手机 360×800

单列：左栏内容在上，地图卡在下（或「去闯关地图」大按钮代替嵌入地图，避免双滚动过深）。

## 关键状态

| 状态 | 表现 |
| --- | --- |
| 有当前关 | 显示继续闯关卡 |
| 全书完成 | 「这本书全部过关啦！」+ 引导复习 / 启思大陆 |
| 复习到期 >0 | 复习小站显示数量 |
| 无开放课程 | 空态引导家长 |

## 空态 / 错误

地图加载失败：右栏占位「地图暂时看不到，点重试」；左栏仍可用。

## 无障碍

主按钮「继续闯关」autofocus；搭档图有 alt；复习区说明含今日积分规则摘要（答对 +1，每天最多 30）。
