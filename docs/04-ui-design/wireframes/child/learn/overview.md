# 线框：启思大陆总览

## 目的

一门课程全部单元的大地图总览（雾化预览未解锁单元）；从闯关地图顶左进入。

## 主画框 1024×768

```
┌─ 外壳（闯关地图）─────────────────────────────────────────┐
│ ← 返回单元地图     启思大陆 · 一年级上册                   │
│ ┌─────────────────────────────────────────────────────┐   │
│ │  [U1 绿地]──[U2]──[U3 亮]──[U4 雾]──[U5 雾]         │   │
│ │   ★12/15      ★15/15   ★6/15    ？       ？          │   │
│ │                                                     │   │
│ │  点已解锁单元 → 进入该单元冒险地图                   │   │
│ └─────────────────────────────────────────────────────┘   │
└───────────────────────────────────────────────────────────┘
```

## 手机 360×800

纵向卷轴大陆：单元块上下排列，雾区显示锁与解锁条件一句话。

## 关键状态

| 状态 | 表现 |
| --- | --- |
| 单元完成 | 亮色 + 星级合计 |
| 进行中 | 高亮边 |
| 未解锁 | 雾 + 不可进 |

## 空态 / 错误

加载失败：整页重试。

## 无障碍

单元块为按钮；雾区 `aria-disabled` 并朗读解锁条件。
