# 线框：秘密路线（入口与失败再试）

## 目的

金币小径 / 赛车捷径 / 月亮秘境：确认入场费 → 3 题全对通过 → 2 倍入场奖励；失败可免费重试。

## 主画框 1024×768

```
┌─ 对话框 / 全页卡 ─────────────────────────────────────────┐
│  ◇ 金币小径                                              │
│  入场 2 星（首次）· 通过奖励 4 星（学习星）               │
│  题目：本单元第 1 关前 3 题 · 须 3/3 全对                 │
│  [花星进入]  [取消]                                      │
│                                                          │
│  —— 若已付过费 ——                                        │
│  [免费再试]  [取消]                                      │
└──────────────────────────────────────────────────────────┘
```

作答 UI 复用 quiz 精简版（仅 3 题）。失败结算：

```
│  还差一点点（秘密路线）                                   │
│  答对 x/3 · 需要全对才能过关                              │
│  [再试一次]  [回到地图]                                   │
```

## 手机 360×800

入场确认为底部 sheet；按钮全宽。

## 关键状态

| 状态 | 表现 |
| --- | --- |
| 未发现 | 地图无入口 |
| 星不足 | `INSUFFICIENT_STARS` 友善文案 |
| 通过 | 走成功结算（含附赠积分） |

## 空态 / 错误

价格变更：提示后刷新 expectedFee。

## 无障碍

费用与「须全对」在确认页明文；失败页不使用关卡通用失败（避免与「关卡无未通过」混淆）。
