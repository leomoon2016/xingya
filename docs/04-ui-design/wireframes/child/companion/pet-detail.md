# 线框：伙伴详情（改名 / 亲密度 / 赠送 / 退订）

## 目的

单只伙伴：形象与阶段、经验条、改名、摸摸/点心/玩耍、设为跟随、赠送、退订。

## 主画框 1024×768

```
│ ←营地    团团 · 熊宝宝          [设为跟随] │
│      [大形象动画帧]                        │
│      Lv12  经验 ▓▓▓░░  亲密度 78/100       │
│ 名字 [________] [保存]                     │
│ [摸摸] [点心] [玩耍]  （今日已用完则禁用） │
│ ── 危险区 ──                               │
│ [赠送给同学…]  [退订（返还一半）]           │
│ 受赠标记：受赠伙伴不显示退订 / 禁用+说明   │
│ 唯一档角标：全站唯一                       │
```

## 手机 360×800

形象置顶；操作按钮两列；危险区折叠在「更多」。

## 关键状态

| 状态 | 表现 |
| --- | --- |
| 今日互动已用 | 按钮 disabled +「明天再来」 |
| 亲密度 100 | 显示满格，不再 + |
| 受赠 | 无退订 |
| 退订确认 | 明示返还币种与数量 |

## 空态 / 错误

`TEXT_BLOCKED` 改名；`PET_NOT_REFUNDABLE`；跨家庭赠送条件失败。

## 无障碍

危险操作二次确认；减少动画时静态帧。
