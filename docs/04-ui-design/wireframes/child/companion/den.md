# 线框：宠物家园 · 营地（Den）

## 目的

六项导航「宠物家园」：展示营地格、已领养伙伴、扩建、去图鉴式领养列表。

## 主画框 1024×768

```
┌─ 外壳（当前：宠物家园）───────────────────────────────────┐
│ 我的营地  3/5 格占用          碎片 12  ★128  [扩建]       │
│ ┌格1 跟随★┐ ┌格2┐ ┌格3┐ ┌空┐ ┌空┐                       │
│ │ 团团 Lv12│ │… │ │… │ │+ │ │+ │                       │
│ │ 亲密度78 │ └─┘ └─┘ └─┘ └─┘                           │
│ └──────────┘                                              │
│ [浏览可领养伙伴]   唯一档「已有主人」灰态示意               │
└───────────────────────────────────────────────────────────┘
```

## 手机 360×800

营地格 2 列网格；扩建与领养主按钮置顶。

## 关键状态

| 状态 | 表现 |
| --- | --- |
| 满营 | 空格消失；领养入口提示先扩建/退订 |
| 唯一档已占 | 卡上「已有主人」 |
| 跟随中 | 格上星标「跟随」 |

## 空态 / 错误

无伙伴：大空态 + 领养 CTA。`DEN_FULL` / `THRESHOLD_NOT_MET` 友善文案。

## 无障碍

格为按钮；空格 `aria-label="空营地，去领养"`。
