# 线框：星星伙伴（社交列表）

## 目的

六项导航「星星伙伴」：家庭内 / 跨家庭伙伴列表、排行入口、赠星、写信入口。

## 主画框 1024×768

```
┌─ 外壳（当前：星星伙伴）───────────────────────────────────┐
│ [家庭内] [跨家庭] [周榜·学习星]                            │
│ ┌头像 昵称  ★周学习星  [赠星] [写信]┐                     │
│ └────────────────────────────────────┘ 重复列表            │
│ 跨家庭：仅好友家庭且双方开启；否则空态说明                 │
└───────────────────────────────────────────────────────────┘
```

## 手机 360×800

分段控件 + 单列；赠星/写信进二级页。

## 关键状态

赠星每日上限 20；达上限禁用。屏蔽/举报入口在详情。

## 空态 / 错误

无跨家庭好友：引导「请家长添加好友家庭」。

## 无障碍

列表项操作按钮独立可聚焦，不靠整行双义。
