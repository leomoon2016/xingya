# 线框：添加 / 编辑词条

## 目的

维护单词字段；可 AI 生成解释（预览后保存）。

## 主画框 1024×768

右侧抽屉（宽 ≈ 420）：

```
│ 添加单词                              [×] │
│ 单词* [____________] [喇叭]               │
│ 中文解释*                                 │
│ 英文解释                                  │
│ 短语 (0/10) [+ ]                          │
│ 例句 (0/10)                               │
│ 我的备注                                  │
│ □ 这个单词我已经熟悉                      │
│ [AI 生成解释]（关闭 AI 时置灰+原因）       │
│              [删除…]  [保存]              │
```

## 手机 360×800

全屏页；底栏保存。

## 关键状态

AI 预览卡：保存到词条 / 取消；改词后需重新生成。冲突：提示重新载入。

## 空态 / 错误

个人信息拦截；满 2000；删除确认「学习记录会保留」。

## 无障碍

抽屉 `role="dialog"`；删除需确认，焦点回列表项。
