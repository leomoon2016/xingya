# 线框：单词本 · 考试

## 目的

10 词 20 题；题号格跳题；题间不对错；交卷确认。

## 主画框 1024×768

```
│ 考试中 · 已答 12/20          [交卷]       │
│ [1][2]…[20]  已答格标蓝                    │
│ ┌题干───────────────────────────────────┐ │
│ │ … 选项 …（无对错色）                   │ │
│ └───────────────────────────────────────┘ │
│ 队长 FAB：「考试中，交卷后再聊」           │
```

列表页考试中只读词形；编辑/AI 关闭。

## 手机 360×800

题号格两行；交卷底栏。

## 关键状态

未答交卷：确认「还有 N 题没答」。恢复：进单词本直达当前位置。

## 空态 / 错误

同流程错误表。

## 无障碍
