# 线框：单词本首页（我的单词）

对齐 [flows/child/wordbook.md](../../../flows/child/wordbook.md)、ADR 0019。

## 目的

学习区三模式入口 + 词条列表；导航「我的单词」。

## 主画框 1024×768

```
┌─ 外壳（当前：我的单词）───────────────────────────────────┐
│ ┌─学习区 ≈1/3────────┐  ┌─词条列表 ≈2/3─────────────────┐ │
│ │ 单词探险手账        │  │ [搜索……]  筛选:全部▾  [添加] │ │
│ │ [立即学习] 5词      │  │ apple  苹果   已掌握   更新…  │ │
│ │ [单词闯关] 5词10题  │  │ … 每页 20 条                 │ │
│ │ [单词考试] 10词20题 │  │                              │ │
│ │ 自己选词 (1–50)     │  │                              │ │
│ │ 学会进度 x/5        │  │                              │ │
│ │ 闯关星 x/5 考试星…  │  │                              │ │
│ └────────────────────┘  └──────────────────────────────┘ │
└───────────────────────────────────────────────────────────┘
```

考试进行中：Tab 角标「考试中」；进页直接恢复考试。

## 手机 360×800

学习区折成一行按钮 + 进度条；下列表。

## 关键状态

词不够出题 / 已满 2000 / 考试中列表只读词形——见流程文档状态表。

## 空态 / 错误

无词条：插画 +「添加第一个单词」主按钮。

## 无障碍

三模式按钮 min-height 56；筛选与搜索有标签。
