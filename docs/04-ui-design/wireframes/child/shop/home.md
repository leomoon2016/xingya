# 线框：星星小铺（四卡）

## 目的

导航「星星小铺」：喜欢的时光 / 探险徽章 / 累计奖励 / 复习积分。

## 主画框 1024×768

```
┌─ 外壳（当前：星星小铺）───────────────────────────────────┐
│ 我的 ★128 · 积分 23.4                                      │
│ ┌────────────┐ ┌────────────┐ ┌────────────┐ ┌──────────┐ │
│ │喜欢的时光  │ │探险徽章    │ │累计奖励    │ │复习积分  │ │
│ │现实奖励目录│ │徽章网格    │ │余额列表    │ │分 23.4   │ │
│ │按份兑换    │ │购买/佩戴   │ │用掉        │ │今日复12/30│ │
│ │待审批 ≤3   │ │只佩戴一枚  │ │流水入口    │ │[换星][去复│ │
│ └────────────┘ └────────────┘ └────────────┘ └习]───────┘ │
└───────────────────────────────────────────────────────────┘
```

点卡进入子页（可同目录续文件或本页展开）。兑换：冻结 → 等家长审批（孩子可见「审批中」）。

## 手机 360×800

四卡 2×2；进入子页全屏。

## 关键状态

| 卡 | 关键态 |
| --- | --- |
| 时光 | 待审批角标；星不足 |
| 徽章 | 已拥有/佩戴中 |
| 累计 | 余额 0 空态 |
| 积分 | 额度满；换星确认 10 分=1 星 |

## 空态 / 错误

家庭无奖励项：时光卡说明「请家长添加奖励」。`REWARD_BALANCE_INSUFFICIENT`。

## 无障碍

四卡标题清晰；审批状态不只靠颜色。
