# 孩子端外壳（Shell）—— 原型 D

依据 [ADR 0020](../../../adr/0020-revert-to-old-system.md) A3–A5、[界面设计 README](../../README.md)。布局区域取自原型 D，**六项导航以 ADR 为准**（原型 D 当时只演示了三项，正式版扩为六项）。

## 目的

所有已登录孩子页共用的顶栏 + 主导航 + 头像菜单 + 呀哈哈队长 FAB，保证横屏平板与手机竖屏同一信息架构。

## 主画框 1024×768（横屏）

```
┌──────────────────────────────────────────────────────────────────────────┐
│ [芽标] 星芽学园   [课程▾ 一年级上册]   呀哈哈 12/1000  ★128  ✉3  (头像●) │ ← 顶栏
├──────────────────────────────────────────────────────────────────────────┤
│  我的学习 │ 闯关地图 │ 星星小铺 │ 星星伙伴 │ 宠物家园 │ 我的单词          │ ← 顶下导航
│     ▬▬                                                                   │   （当前项木牌黄短线）
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│                         （各功能主内容区）                                 │
│                                                                          │
│                                                              (队长 FAB)  │
└──────────────────────────────────────────────────────────────────────────┘
```

### 顶栏区域

| 区域 | 内容 | 行为 |
| --- | --- | --- |
| 品牌 | Logo +「星芽学园」 | 不可点或回「我的学习」 |
| 课程下拉 | 当前课程名 | 仅列出家长已开放课程；切换写 `children.current_course_id` |
| 呀哈哈 | `N / 1000`（分母=`discovery.collection_cap`） | 进图鉴/发现摘要；满仓仍显示上限 |
| 星星 | 余额 | 可进星星流水摘要或小铺 |
| 信箱 | 未读角标 | 进信箱；0 时无角标 |
| 头像 | 圆头像 + 佩戴徽章角标 | 打开头像菜单 |

### 六项导航（横屏在顶栏下方居中）

1. **我的学习** — `learn` 首页（招呼、继续闯关、复习小站入口）
2. **闯关地图** — 单元冒险地图 / 启思大陆总览
3. **星星小铺** — 四卡
4. **星星伙伴** — 社交伙伴列表（家庭内 / 跨家庭）
5. **宠物家园** — 营地与伙伴
6. **我的单词** — 单词本；考试中显示「考试中」角标，点入恢复本轮

当前项：字色 `forest`，下方木牌黄短线（`wood`）。

### 头像菜单（桌面/平板：下拉；手机：半屏抽屉）

- 学习足迹
- 我的设置
- 换人（回头像墙，不退家长会话）
- （可选）积分口袋入口说明：积分主入口在小铺「复习积分」卡

### 呀哈哈队长 FAB

右下角固定 64×64；打开聊天面板。考试进行中显示「考试中，交卷后再聊」且不可发消息。

## 手机 360×800

```
┌────────────────────┐
│ 芽  [课▾]  ✉3 (头) │  ← 顶栏压缩：课程+头像+信箱优先
│ 呀哈哈12/1000 ★128 │  ← 第二行余额条
├────────────────────┤
│                    │
│   主内容           │
│                    │
│            (队长)  │
├────────────────────┤
│学│图│铺│伴│宠│词   │  ← 底部六项 Tab（可两行图标+短标签）
└────────────────────┘
```

- 导航移到**底部 Tab**；「我的设置」「学习足迹」只从头像菜单进。
- 触控目标 ≥ 44×44；Tab 项 min-height 48。
- 主内容底部留出 Tab + FAB 避让。

## 关键状态

| 状态 | 表现 |
| --- | --- |
| 未读信箱 | 红角标数字 |
| 单词本考试中 | 「我的单词」Tab 角标「考试中」 |
| 复习到期 | 「我的学习」内复习小站有数量；不强制 Tab 角标 |
| 减少动画 | 关闭导航短线过渡与 FAB 入场动画 |

## 空态 / 错误

- 课程列表为空：下拉显示「请家长先开放课程」。
- 顶栏接口失败：余额显示「—」，不阻断导航。

## 无障碍

- 顶栏按钮均有 `aria-label`（含「呀哈哈森林口袋，已找到 N 位，共 1000 位」）。
- 导航 `aria-current="page"`；焦点环用令牌 `neutral.focus`（≥ 3px）。
- 对比度：`teal` 上白字、`forest` 上 `mint`/`paper` ≥ 4.5:1。
- 200% 字号：顶栏可折行，不遮挡 Tab。
