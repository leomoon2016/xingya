- `parent/`：dashboard、overview、reports、controls、approvals、rewards、settings、inbox；另含 [shell.md](parent/shell.md)。**已填**（2026-10-24）。见 [parent/README.md](parent/README.md)。对应 `apps/web/src/features/parent/`。
