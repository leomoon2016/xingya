# 线框：家庭与注册码

## 目的

家庭列表、停用/恢复；签发注册码（可绑邮箱）；不看学习明细（隐私 R9）。

## 桌面 ≥1280

```
│ 家庭                         [签发注册码]                  │
│ 名称  家长数  孩子数  状态  创建  [停用/恢复]             │
│ 注册码：码 · 有效期 14 天 · 绑定邮箱? · 已用/未用          │
│ ⚠ 无学习全览/星星入口（家长中心负责）                      │
```

## 关键状态

已停用家庭；码过期。

## 空态 / 错误

`LAST` 类不适用；停用确认。

## 无障碍

停用影响说明完整。
