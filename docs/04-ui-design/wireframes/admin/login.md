# 线框：后台登录（TOTP）

## 目的

用户名 + 密码 + TOTP；5 次失败锁 15 分钟；独立子域。

## 桌面 ≥1280

```
│            ┌登录卡─────────────┐                           │
│            │ 星芽系统管理       │                           │
│            │ 用户名             │                           │
│            │ 密码               │                           │
│            │ TOTP 6 位          │                           │
│            │ [登录]             │                           │
│            │ 锁定提示 / 改密无自助（运维 reset-totp）      │
│            └────────────────────┘                           │
```

## 关键状态

锁定倒计时；TOTP 错。

## 空态 / 错误

—

## 无障碍

三字段标签完整；锁定 `role=alert`。
