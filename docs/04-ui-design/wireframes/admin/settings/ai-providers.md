# 线框：模型配置（ADR 0022）

## 目的

聊天 / 视觉 / 图像三类可分别配置；≤20 条；Key 只写不读（末 4 位）；测试连接；用途默认。

## 桌面 ≥1280

```
│ 设置 · 模型配置                                            │
│ 用途默认：聊天 [百炼-qwen▾] 视觉 […] 图像 […]  [保存默认] │
│ 配置列表（≤20）                                            │
│ 名称  用途  厂商  模型  Key ****abcd  启用  [测] [改]     │
│ 新建/编辑：用途 · base URL · 模型名 · API Key（密码框）    │
│          启用 · 孩子可选?（聊天）                          │
│ 测试连接 → 成功/失败详情（无 Key 回显）                    │
```

## 关键状态

`PROVIDER_LIMIT` / `PROVIDER_IN_USE` 不能停用；乐观锁默认。

## 空态 / 错误

无默认用途时工作室阻断并引导。

## 无障碍

Key 字段 `autocomplete=new-password`；测试结果 `aria-live`。
