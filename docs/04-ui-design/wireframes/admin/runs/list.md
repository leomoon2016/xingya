# 线框：运行与流水线

## 目的

任务队列、步骤时间线（≤20 步）、克隆重跑、取消。

## 桌面 ≥1280

```
│ 运行                                    筛选：状态/角色    │
│ ID  角色  状态  步数  费用  创建         [打开]          │
│ 详情：步骤列表 tool/输入摘要/输出摘要/错误 · [克隆重跑]   │
```

## 关键状态

running / succeeded / failed / cancelled；超时标记。

## 空态 / 错误

失败步骤展开错误码；链到预算与模型配置。

## 无障碍

状态文字 + 图标双编码。
