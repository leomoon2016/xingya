# 线框：AI 工作室首页

## 目的

一句话框、`@角色`、快捷任务、流水线入口；生成只写草稿。

## 桌面 ≥1280

```
│ 工作室                                                     │
│ ┌一句话──────────────────────────────────────────────┐    │
│ │ 帮我给一年级上 Unit 3 生成 5 关草稿…  @课程设计师   │    │
│ │ [估算费用] [开始]                                    │    │
│ └────────────────────────────────────────────────────┘    │
│ 快捷任务：[整课生成] [伙伴设计] [呀哈哈款式] [投放规则]   │
│ 最近运行  状态  费用  [打开]                               │
│ 月度预算进度 ▓▓▓░░  ¥120 / ¥500                            │
```

## 关键状态

预算将尽警告；AI 全站关；费用预估失败。

## 空态 / 错误

无运行记录；`PROVIDER_*` 错误链到模型配置。

## 无障碍

费用数字与货币符号可读；主按钮明确「开始生成草稿」。
