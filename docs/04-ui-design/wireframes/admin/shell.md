# 系统管理后台外壳（Shell）

依据 [nfr §8.4](../../../01-requirements/nfr.md)（仅桌面 ≥1280，无手机变体）、[ADR 0015](../../../adr/0015-admin-app-and-seeds.md)。色板 `color.neutral`；密度高于家长中心。

## 目的

`apps/admin` 独立站点共用侧栏 + 顶栏；与孩子/家长 Cookie 隔离。

## 桌面 ≥1280

```
┌──────────┬────────────────────────────────────────────────────────────┐
│ 星芽后台  │  面包屑 · 工作室 / 课程          [搜]  admin@… ▾ TOTP会话 │
│          │───────────────────────────────────────────────────────────│
│ 工作室   │                                                            │
│  技能    │                     主内容（表格/表单）                     │
│  角色    │                                                            │
│  运行    │                                                            │
│ 课程     │                                                            │
│ 伙伴     │                                                            │
│ 呀哈哈   │                                                            │
│ 投放规则 │                                                            │
│ 家庭     │                                                            │
│ 设置     │                                                            │
│ 审计     │                                                            │
└──────────┴────────────────────────────────────────────────────────────┘
```

导航对应 `apps/admin/src/features/`：studio（入口可含一句话框）、skills、agents、runs、courses、pets、yahaha、rules、families、settings、audit。

## 关键状态

| 状态 | 表现 |
| --- | --- |
| 无 TOTP / 会话将过期 | 顶栏警告条 |
| 全站 AI 关闭 | 工作室入口灰显 + 原因 |

## 空态 / 错误

401 → 登录页；403 功能无权限（若细分角色暂无则全管理员）。

## 无障碍

侧栏 `aria-current`；表格排序按钮可读名称；对比度 ≥ 4.5:1。
