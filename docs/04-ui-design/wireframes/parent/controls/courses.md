# 线框：课程开放

## 目的

按年级列出英语课程，对当前孩子设：默认 / 额外开放 / 关闭 / 未开放。整册为单位。

## 桌面 ≥1280

```
│ 管控 · 小米 · 课程开放                    version 锁隐式   │
│ 一年级                                                  │
│  · 上册 en-g1-a   [默认开放▾]  → 默认开放/关闭/恢复默认  │
│  · 下册 …                                                │
│ 二年级                                                  │
│  · 上册 …         [未开放▾] → 可「额外开放」             │
```

## 手机 360×800

年级手风琴；每课一行下拉。

## 关键状态

`VERSION_CONFLICT`；保存成功 Toast。孩子顶栏课程下拉只含已开放。

## 空态 / 错误

无课程种子：罕见，显示「课程清单加载中/失败」。

## 无障碍

状态下拉每项有说明短句。
