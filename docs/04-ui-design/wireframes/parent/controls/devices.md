# 线框：设备与会话

## 目的

查看孩子近 30 天登录设备；远程下线会话或撤销家庭设备。

## 桌面 ≥1280

```
│ 管控 · 小米 · 设备                                         │
│ 家庭设备「客厅平板」 最近 10-24 09:00  [撤销本设备]        │
│ 浏览器 Chrome · 手机  最近 …        [下线此会话]           │
│ 说明：撤销家庭设备会使该设备上孩子会话全部失效             │
```

## 手机 360×800

列表卡。

## 关键状态

当前家长会话不可误撤自己到无法操作（若在家庭设备家长会话，文案区分）。

## 空态 / 错误

无记录：「近 30 天没有登录」。

## 无障碍

撤销确认说明影响范围。
