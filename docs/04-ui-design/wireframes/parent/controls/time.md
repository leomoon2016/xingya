# 线框：时长与时段 · 加时

## 目的

为当前孩子设置每日分钟上限、允许时段；一键「再玩 15 分钟」（每天最多 120）。

## 桌面 ≥1280

```
│ 管控 · 小米     [时长] [课程] [设备] [跨家庭]               │
│ 今日已用 28 分 · 上限 40 · 加时已用 0/120                   │
│ 每日上限  [ 40 ] 分钟（10–300）                             │
│ 允许时段  [07:00] – [21:00]（不跨午夜，家庭时区）           │
│ [保存]                                                      │
│ ┌快捷──────────────────────────────────────────┐           │
│ │ [再玩 15 分钟]  同时延长时长与时段窗口         │           │
│ │ 今日加时累计 0 / 120                          │           │
│ └──────────────────────────────────────────────┘           │
│ 家庭时区：Asia/Shanghai（到设置修改；次日生效）             │
```

## 手机 360×800

分段顶栏切换管控子页；加时大按钮置顶。

## 关键状态

| 状态 | 表现 |
| --- | --- |
| 加时达上限 | 按钮 disabled「今日加时已满」 |
| 乐观锁冲突 | 刷新后重填 |
| 孩子休息中 | 首页卡同步状态 |

## 空态 / 错误

非法时段（开始≥结束）前端拦截。

## 无障碍

时间输入可键盘操作；加时后果明文。
