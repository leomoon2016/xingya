# 线框：好友家庭与跨家庭开关

## 目的

开关跨家庭功能、查看/重置好友码、发起请求、解除好友；待处理请求在审批收件箱。

## 桌面 ≥1280

```
│ 管控 · 家庭级（不随孩子切换）                              │
│ 跨家庭功能  (开/关)  乐观锁                                │
│ 本家好友码  AB12CD  [复制] [重置码]                        │
│ 添加好友家庭  输入对方码 [发送请求]                        │
│ 已是好友                                                   │
│  · 林家  active  [解除]                                    │
│  · 陈家  pending（我方发起）等待对方                       │
```

## 手机 360×800

单列；重置/解除需确认。

## 关键状态

关闭跨家庭后排行「好友」范围不可用；进行中请求仍可在收件箱处理。

## 空态 / 错误

无效码；重复请求。

## 无障碍

开关与危险操作确认。
