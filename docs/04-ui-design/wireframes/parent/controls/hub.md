# 线框：管控入口总览

## 目的

「管控」导航落地：按孩子（时长/课程/设备）与按家庭（好友）分组入口。

## 桌面 ≥1280

```
│ 管控                                                       │
│ 当前孩子 [小米▾]                                           │
│ ┌时长与加时┐ ┌课程开放┐ ┌登录设备┐                        │
│ └─────────┘ └────────┘ └────────┘                        │
│ 家庭                                                       │
│ ┌好友家庭与跨家庭┐                                         │
│ └────────────────┘                                         │
```

## 手机 360×800

入口列表行。

## 关键状态

孩子锁定时时长卡带「解锁」捷径。

## 空态 / 错误

无孩子：禁用孩子级入口。

## 无障碍

卡片标题即链接名。
