# 线框：审批收件箱（待处理）

依据 [controls §4.4.3](../../../../01-requirements/modules/controls.md)、[ADR 0020 R17](../../../../adr/0020-revert-to-old-system.md)。与孩子端小铺「喜欢的时光」闭环：孩子按份申请 → 冻结 → 本页批准/拒绝；批准后入累计奖励余额。

## 目的

集中处理：① 现实奖励兑换申请；② 好友家庭请求。核销**不在**此页（见 [rewards/writeoff](../rewards/writeoff.md)）。

## 桌面 ≥1280

```
┌─ 外壳（当前：待处理）●2 ──────────────────────────────────┐
│ Tab：[兑换申请 1] [好友请求 1]                              │
│                                                            │
│ ┌兑换 · 小米───────────────────────────────────────────┐  │
│ │ 「玩游戏机」× 3 份                                     │  │

│ └────────────────────────────────────────────────────────┘  │
│ ┌好友请求 · 林家───────────────────────────────────────┐  │
│ │ 对方家庭码摘要 · 发起家长                               │  │
│ │              [拒绝]  [批准成为好友家庭]                 │  │
│ └────────────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────────┘
```

批准兑换后：扣星（已冻结转 debit）、`reward_balances` 入账、双方信箱通知；条目离开列表。

## 手机 360×800

单列卡片；批准/拒绝全宽；Tab 顶部分段。

## 关键状态

| 状态 | 表现 |
| --- | --- |
| 已处理竞态 | `ALREADY_DECIDED` → 刷新列表 |
| 孩子已撤回 | 条目消失或显示「已撤回」 |
| 无待办 | 空态插画「都处理完了」 |

## 空态 / 错误

版本冲突：提示刷新。网络失败保留按钮可重试（幂等决策）。

## 无障碍

批准后果（累计入账分钟/金额）在按钮旁明文；对话框确认。
