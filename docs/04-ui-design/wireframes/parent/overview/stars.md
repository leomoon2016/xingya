# 线框：加减星与星星/积分流水

## 目的

家长对本家庭孩子加星（1–1000000，原因可选）或扣星（原因必填 ≤300）；查看流水（含积分）。闭环孩子信箱通知。

## 桌面 ≥1280

```
│ ← 小米 · 星星                    可用 120 · 冻结 8         │
│ ┌加星────────────────┐  ┌扣星（须原因）───────────────┐  │
│ │ 数量 [____] 1–1e6  │  │ 数量 [____]                 │  │
│ │ 备注（可选）       │  │ 原因* [______________]      │  │
│ │ [确认加星]         │  │ [确认扣星]                  │  │
│ └────────────────────┘  └─────────────────────────────┘  │
│ 流水 Tab：星星 | 碎片 | 积分                               │
│ 时间 · kind · 数额 · 备注                                  │
```

## 手机 360×800

加减星上下排列；流水独立二级页。

## 关键状态

| 状态 | 表现 |
| --- | --- |
| 扣星无原因 | 按钮 disabled + 校验 |
| 扣到冻结 | `409 INSUFFICIENT_STARS` 说明「先处理兑换或等孩子撤回」 |
| 成功 | Toast + 信箱将通知孩子 |

## 空态 / 错误

流水空：「还没有记录」。

## 无障碍

扣星确认对话框复述数量与原因；数字输入可访问。
