# 线框：知识图谱

## 目的

按单元列出义项与句型掌握：已掌握 / 复习中 / 未学。`GET /children/:id/knowledge-graph`。

## 桌面 ≥1280

```
│ ← 小米 · 知识图谱   课程 [一年级上册 ▾]                    │
│ Unit 3 · 词                                        筛选▾   │
│ ● cat 已掌握   ◐ dog 复习中(3盒)   ○ elephant 未学         │
│ Unit 3 · 句型                                              │
│ ● This is a … 已掌握                                       │
│ 图例：已掌握 / 复习中 / 未学                               │
```

## 手机 360×800

单元列表 → 词条列表；图例置顶。

## 关键状态

空课程；筛选仅某一状态。

## 空态 / 错误

尚无复习数据：引导「孩子多闯关后会出现」。

## 无障碍

状态不只靠圆点颜色（文字标签必备）。
