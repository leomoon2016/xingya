# 线框：孩子列表

## 目的

「孩子」导航落地：本家庭孩子卡片入口（全览、管控、加减星、累计奖励、设备）。

## 桌面 ≥1280

```
│ 孩子                          [+ 添加孩子]                 │
│ ┌头像 小米 一年级  ★128  可用120 冻结8 ┐                  │
│ │ [学习全览] [知识图谱] [加减星] [累计奖励] [管控]        │ │
│ └──────────────────────────────────────┘                  │
│ ┌头像 豆豆 … 锁定中────────────────────┐                  │
│ │ [解锁] …                              │                  │
│ └──────────────────────────────────────┘                  │
│ □ 显示已归档                                               │
```

## 手机 360×800

单列卡；操作收进「更多」菜单。

## 关键状态

归档孩子灰底「已归档」+「恢复」；锁定显示倒计时。

## 空态 / 错误

无孩子引导添加。跨家庭 id 不出现。

## 无障碍

每卡标题为孩子名；操作菜单项可读。
