# 家长中心外壳（Shell）

依据 [nfr §8.4](../../../01-requirements/nfr.md#84-设备与屏幕)、[界面设计 README](../../README.md)。色板用令牌 `color.neutral`（非孩子端冒险绿为主）。与孩子端四卡小铺闭环：[approvals/inbox](approvals/inbox.md)、[rewards/writeoff](rewards/writeoff.md)。

## 目的

家长登录后共用的顶栏、主导航、孩子切换器与信箱入口；桌面侧栏 + 手机单列底栏/抽屉。

### 顶栏

- 家庭名（可点进家庭设置）
- 信箱未读 → [inbox/inbox](inbox/inbox.md)
- 家长菜单：账号与安全、邀请家长、退出登录

### 孩子切换（多孩家庭）

多数子页顶有横向孩子芯片（头像+昵称）；当前孩子高亮。归档孩子默认不出现（设置里可「显示已归档」）。


- 窄屏**单列**，无左右分栏。
- 触控 ≥ 44×44；侧栏改为抽屉（☰）。

## 关键状态

| 状态 | 表现 |
| --- | --- |
| 有待处理 | 「待处理」红角标数字 |
| 家庭设备会话 | 顶栏可提示「家庭设备 · 15 分钟无操作将退回头像墙」 |
| 减少动画 | 遵从系统 `prefers-reduced-motion`（家长无单独 pref 也可跟系统） |

## 空态 / 错误

无孩子：首页与孩子页引导「添加第一个孩子」。会话过期：回登录，不丢草稿提示。

## 无障碍

导航 `aria-current`；角标有文字等价「N 条待处理」；对比度用 neutral ink on bg ≥ 4.5:1；焦点环 `neutral.focus`。
