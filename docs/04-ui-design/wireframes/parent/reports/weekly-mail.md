# 线框：周报邮件订阅

## 目的

查看订阅状态、一键退订后的重新订阅；邮箱未验证时引导验证。

## 桌面 / 手机

```
│ 周报邮件                                                   │
│ 收件：parent@…  已验证 ✓ / 未验证 → [重发验证]            │
│ 订阅状态：开 (每周日 20:00 家庭时区)                       │
│ [退订] 或已退订时 [重新订阅]                               │
│ 最近发送：成功 / 退信提示（若有）                          │
```

## 关键状态

未验证不可订阅成功态；退信显示友善说明。

## 空态 / 错误

无邮箱：引导绑定（若流程支持）。

## 无障碍

退订/订阅按钮名明确。
