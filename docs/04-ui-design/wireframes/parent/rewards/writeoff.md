# 线框：累计奖励 · 核销

## 目的

查看某孩子各项累计余额与流水；家长「核销」须写说明（已兑现记录）。孩子「用掉」不需审批。闭环小铺「累计奖励」卡。

## 桌面 ≥1280

```
│ ← 小米 · 累计奖励                                          │
│ ┌玩游戏机 剩余 30 分钟────────────┐                       │
│ │ [核销…]  流水：获批+30 / 孩子用掉-10 / 核销-10          │ │
│ └─────────────────────────────────┘                       │
│ ┌玩具额度 剩余 ¥12 ────────────────┐                      │
│ └──────────────────────────────────┘                      │
│ 核销对话框：数量* · 说明* ≤300 · [确认核销]                │
```

`POST /children/:id/rewards/:optionId/writeoffs`；不足 → `REWARD_BALANCE_INSUFFICIENT`。

## 手机 360×800

余额卡列表；核销底 sheet。

## 关键状态

余额 0：隐藏核销或 disabled。成功：通知孩子信箱。

## 空态 / 错误

无任何余额：「批准兑换后会出现在这里」+ 链到待处理/清单。

## 无障碍

核销确认复述数量与奖励名；原因必填提示明确。
