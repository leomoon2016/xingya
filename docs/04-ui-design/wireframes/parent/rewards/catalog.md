# 线框：奖励清单（家庭维护）

## 目的

家长维护本家庭现实奖励目录（R17：非全站管理员目录）。默认三项可改可停用。孩子小铺「喜欢的时光」读此目录。

## 桌面 ≥1280

```
│ 奖励清单                              [+ 添加奖励]         │
│ 标题            单位     每份数量   每份星价   状态  操作  │
│ 玩游戏机        分钟        10         20      启用  编辑  │
│ 玩具额度        金额(分)     100         1      启用  编辑  │
│ 家庭游戏        次数         1          5      停用  编辑  │
│                                                            │
│ 编辑抽屉：标题≤40 · 说明 · 单位 · 每份数量1–100000        │
│           每份星价1–2000 · 启用 · 乐观锁 version           │
```

说明：已申请单据保留申请时快照价，改价不影响在途单。

## 手机 360×800

列表卡；添加/编辑全屏表单。

## 关键状态

停用后孩子端不可新申请；在途单仍可审批。`VERSION_CONFLICT` 展示最新值。

## 空态 / 错误

删光启用项：孩子时光卡显示「请家长添加奖励」（与孩子线框一致）。

## 无障碍

单位用文字「分钟/元/次」；金额分与展示元换算注明。
