# 线框：家长首页（Dashboard）

## 目的

一眼看到各孩子今日学习、时长余量、待审批与快捷加时；入口到全览与报告。

│ │ ★今日 +6  学习 28分  │  │ ★今日 +2  学习 12分  │         │
│ │ 时长 28/40 · 加时 0  │  │ 时段内 · 未锁定       │         │

│ │ [再玩15分钟] [全览]  │  │ [立即解锁] [全览]     │         │
│ └─────────────────────┘  └─────────────────────┘         │

## 手机 360×800

孩子卡纵向堆叠；待处理置顶条；加时按钮全宽。

## 关键状态

| 状态 | 表现 |
| --- | --- |
| 时长将尽 | 进度条警告色 |
| 时段外 | 「休息中」+ 下次可学时间 |
| 无待处理 | 待处理区空态隐藏或「没有待办」 |

## 空态 / 错误

无孩子：大 CTA「添加孩子」。数据加载失败：卡片级重试。

## 无障碍

加时与解锁为明确按钮名；状态不只靠颜色（附文字）。
