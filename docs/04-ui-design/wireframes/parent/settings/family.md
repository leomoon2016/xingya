# 线框：家庭设置（名称与时区）

任务单 17 范围：家庭名称、时区（次日生效）。

## 目的

`GET·PATCH /family`；乐观锁。

## 桌面 ≥1280

```
│ 设置 · 家庭                                                │
│ 家庭名称  [王家学习屋________]                             │
│ 时区      [Asia/Shanghai ▾]  IANA                          │
│ 提示：时区改动从**下一个本地日**生效；今日学习日仍用旧时区 │
│ [保存]                                                     │
```

## 手机 360×800

同单列表单。

## 关键状态

`VERSION_CONFLICT` 展示服务器值并合并。非法时区 400。

## 空态 / 错误

保存失败保留输入。

## 无障碍

时区列表可搜索；提示不藏在 tooltip-only。
