# 线框：账号与安全 · 家长成员

任务单 17：改密码、停用另一家长；另含邀请家长入口。

## 目的

`PUT /me/password`；`GET /family/parents`；`POST /family/parents/:id/disable`；邀请链接。

## 桌面 ≥1280

```
│ 设置 · 账号                                                │
│ ── 我的密码 ──                                             │
│ 当前密码* [____]  新密码* [____]  确认* [____]             │
│ [修改密码]  成功后其他会话失效                             │
│ ── 家长成员 ──                                             │
│ 妈妈（我）有效                                             │
│ 爸爸 有效  [停用]                                          │
│ 最后一位有效家长时：停用按钮 disabled +「不能停用最后一位」│
│ [邀请家长] 邮箱 → 7 天链接                                 │
```

## 手机 360×800

分两段屏：密码 / 成员。

## 关键状态

| 状态 | 表现 |
| --- | --- |
| 旧密码错 | 401 文案 |
| `LAST_PARENT` | 禁用停用 |
| 停用成功 | 对方立即无法登录 |

## 空态 / 错误

弱密码拒绝表提示。

## 无障碍

停用二次确认；密码字段可显示/隐藏。
