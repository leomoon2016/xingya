# 线框：孩子档案管理（添加 / 编辑 / 归档）

任务单 17：归档与恢复；亦含添加孩子、重置 PIN、解锁、用户名密码。

## 目的

家长维护孩子档案；归档后头像墙隐藏、会话失效、数据保留。

## 桌面 ≥1280

```
│ 设置 · 孩子档案                    [+ 添加孩子]            │
│ ┌小米──────────────────────────────────────────────┐      │
│ │ 昵称 头像 年级 | [重置PIN] [用户名密码] [解锁]     │      │
│ │ 改名记录 [查看]（孩子自改审计）                    │      │
│ │ [归档孩子…]                                        │      │
│ └──────────────────────────────────────────────────┘      │
│ □ 显示已归档 → 阿宝 已归档 [恢复]                          │
```

添加表单：昵称 1–24、头像库、年级、PIN（拒弱 PIN）。

## 手机 360×800

列表 → 详情全屏。

## 关键状态

归档确认说明「可恢复、学习数据保留」；恢复后可再 PIN。

## 空态 / 错误

昵称冲突；弱 PIN；跨家庭 404。

## 无障碍

归档/恢复为明确动词；危险区分组。
