# 里程碑与风险

## 11. 里程碑（单人开发，约 19 周）

> 2026-10-21 设计变更（用户已批准，见 [v1.0 变更记录](../06-releases/v1.0/changes.md)）：学习伙伴、呀哈哈发现、AI 工作室与 AI 生成课程全部进入 v1.0，排期由约 13 周调整为约 19 周；AI 工作室的基础能力排在伙伴、呀哈哈、课程之前。

| 周 | 里程碑 | 交付与完成标准 |
| --- | --- | --- |
| 第 0 周起 | ICP 备案（并行） | 立即提交主域名与 CDN 子域名备案（1–3 周）；未完成前不能在大陆服务器上用域名对外提供服务 |
| W1–2 | 骨架与发布流水线 | 单仓库结构、模块边界检查、平台层（事务/幂等/错误/Clock/调度器/OSS 客户端）、0001 迁移、CI 五个阶段、服务器 bootstrap（含 Piper 与声音模型安装）、OSS 桶与 CDN 配置、Nginx HTTPS 配置就绪（备案完成前通过 SSH 端口转发访问验证）、备份与告警脚本、`/health` 部署成功 |
| W3–4 | 家庭、账号、登录 | 注册码注册、家长登录/邀请/找回密码/邮箱验证、孩子档案、家庭设备与头像墙、PIN 与锁定、孩子密码登录、会话管理与远程下线、管理员 TOTP 登录与后台外壳、邮件发件箱 |
| W5 | AI 工作室基础 | `ai_jobs` 任务执行器（2 并发、本机进程 1 个、心跳与重试）、图像/TTS/LLM/OCR 适配器与桩、素材库（OSS 私有/公开前缀、签名 URL、哈希命名）、费用预估与月度预算、提示词禁止词表、后台任务页 |
| W6–7 | 词库与课程管理 | 词与义项、课程/草稿/版本、模板注册（4 个模板定义）、表单编辑器、自动检查 K1–K12、学生视角试玩、审核、发布任务（Piper 一次性进程 + 复制到 `pub/`）、版本历史、示例课程导入、装扮后台 |
| W8 | 星星、商店、现实奖励 | 账本（星星 + 碎片）与余额缓存（学习结算调用的发放接口先于学习完成）、6 种星星来源与 3 种碎片来源、对账任务、商店与穿戴、奖励清单、兑换冻结/批准/拒绝/撤回、家长手动奖励 |
| W9–10 | 学习 | 课程开放规则、关卡路线图、作答（plays）：可见部分下发、选项打乱、逐题反馈、完成结算；9 种题型；间隔复习（义项与错题）；连续天数；PWA 与 CDN 素材缓存 |
| W11–12 | 学习伙伴 + AI 伙伴设计 | 档位与阶段、领养（星星或碎片）、营地扩建、学习陪伴经验与升级、关键帧动画与动效模板播放器、互动；后台伙伴设计流程（4 候选 → 阶段图与关键帧 → 动效 → 声音与台词 → 审核发布） |
| W13–14 | 呀哈哈发现 + 投放规则 | 结算时放置藏匿点、揭晓、图鉴与套组/里程碑奖励、全局设置、款式上限与库存；投放规则表单、重叠检查、自动开始/结束/暂停、审计；AI 一句话填写规则 + 大白话复述 + 影响估算；款式 AI 设计；统计页 |
| W15 | AI 生成课程 | 资料上传与文本抽取/OCR、AI 分析清单、按模板生成草稿与统一画风配图、“让 AI 重写这一题”、费用预估与预算拦截 |
| W16 | 家长管控、报告、周报 | 时长与时段、心跳、服务端强制、加时、审批收件箱、夜间汇总（含碎片与呀哈哈）、家长报告页、周报邮件与退订 |
| W17–18 | 社交与呀哈哈队长 | 排行榜三种范围、赠送、家庭内与跨家庭消息、好友家庭、举报/屏蔽、管理员举报处理；呀哈哈队长聊天、过滤、配额、全站开关 |
| W19 | 缓冲与验收 | 全部 e2e 通过、性能测量、恢复演练、无障碍检查、首发课程审阅与发布、上线检查清单（S1–S10） |

进度不足时的削减顺序（从先砍起）：全站排行榜 → 跨家庭消息 → 好友家庭（整块跨家庭功能）→ AI 一句话填写规则（保留表单）→ AI 生成课程（保留手工表单编辑与示例导入）→ 呀哈哈队长聊天推迟到上线后第一个迭代。学习、星星、学习伙伴、呀哈哈发现（表单规则）、管控、报告、AI 工作室基础与伙伴/款式设计不削减。

## 12. 风险

| # | 风险 | 影响 | 应对 |
| --- | --- | --- | --- |
| R1 | ICP 备案未按时完成（主域名与 CDN 域名） | 无法以域名上线、素材无法经 CDN 提供 | 第 0 周立即提交；备案期间用 SSH 端口转发在家庭内部试用，素材临时用 OSS 签名 URL；W19 前未完成则推迟公开上线 |
| R2 | 2 GB 内存不足（MySQL + Node + Piper 一次性进程） | OOM、服务中断 | 构建在 CI；Piper 只在发布任务中以独立 cgroup（≤ 350 MB）运行且同一时刻最多 1 个；内存预算与 systemd `MemoryMax`；swap；内存告警；必要时升配到 4 GB（仅改规格，无架构变化） |
| R3 | 首发课程不够 | 孩子没内容可学 | 示例课程导入 + AI 生成课程；W15 前至少用表单完成一年级 2 个单元；AI 生成被削减时仍可手工制作 |
| R4 | 奖励收敛后孩子积极性下降 | 使用天数下降 | 商店首发 ≥ 30 件原创物品；连续天数里程碑；上线 2 周观察使用数据后在后台调整价格、伙伴档位与发现概率（无需发版） |
| R5 | AI 输出不当 | 儿童安全事件 | 提示词 + 双向过滤 + 配额 + 家长可关 + 全站开关；上线前跑过滤用例集；过滤命中进家长报告 |
| R6 | 单人排期滑动（范围扩大到 11 个模块） | 延期 | W19 缓冲；[§11](#11-里程碑单人开发约-19-周) 削减顺序 |
| R7 | 素材版权：旧美术来源不明、AI 图像可能近似现有角色 | 开放给其他家庭时侵权 | 不迁移旧美术；装扮初始数据 `artSource` 必填；AI 提示词禁止词表 + 自动追加禁止项；所有 AI 形象人工审核；素材记录提示词可追溯 |
| R8 | Piper 个别单词发音不准 | 学错发音 | 审核时抽听全部新词；可在后台为词上传真人录音替换 `audio_asset_id`（词的音频列允许更新）；家长发现问题通过邮件反馈 |
| R9 | 周报邮件进垃圾箱（QQ/163） | 家长收不到 | 使用国内邮件推送服务、配置 SPF/DKIM/DMARC；家长中心同样可看报告 |
| R10 | iOS Safari PWA 的录音/音频限制 | 跟读不可用 | 录音与播放都由用户手势触发；不可用时降级为“听一听再读”；WebKit 纳入 e2e |
| R11 | 单机数据丢失 | 丢失学习记录 | 每日备份 + OSS 加密副本 + 恢复演练；RPO 24 小时可接受（家庭规模） |
| R12 | 开放后跨家庭互动被滥用 | 儿童安全与合规 | 默认关闭、好友码线下交换、只能预设短语、举报 48 小时处理、可停用家庭；开放注册前完成合规评估（Q4） |
| R13 | AI 费用失控 | 超支 | 任务入队前预估并预留；月度硬上限由数据库保证；80% 用量告警；聊天另有每日配额 |
| R14 | AI 生成的课程有错误（答案错、干扰项不当） | 孩子学错 | 自动检查 K1–K12 + 人工审核 + 学生视角试玩；已发布版本可随时发新版本修正 |
| R15 | 提示词注入（上传资料中夹带指令） | 生成不当内容 | 资料文本只作为数据传入、与系统指令分隔；输出只接受 Zod 模式内的 JSON；全部人工审核 |
| R16 | 投放规则配置错误导致奖励过量 | 经济失衡 | 服务端与数据库双重边界、重叠提示、影响估算、可暂停、审计；全局每日上限兜底 |
