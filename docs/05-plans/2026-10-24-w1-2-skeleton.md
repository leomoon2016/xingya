> **2026-10-30 PostgreSQL**：脚手架与集成测试目标库改为 PostgreSQL 16；驱动 `pg`；备份 `pg_dump`；队列抢占 `FOR UPDATE SKIP LOCKED`（ADR 0023 / 0024）。下列任务中若仍出现历史 MySQL 字样，以本注记为准。


> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 本机与一次性环境可启动 `apps/api` + `apps/web` + `apps/admin`，跑通平台层 / 迁移 / seeds / CI 四阶段与部署脚本；`/api/v1/health` 在发布包部署后返回新版本（备案前经 SSH 端口转发验收）。

**Architecture:** pnpm monorepo 三个应用共享 `packages/contracts` 与 `packages/ui`；单进程 Fastify 服务 + Kysely/PostgreSQL 16；平台层（事务、幂等、错误、Clock、调度器、OSS）先于业务；`apps/admin` 独立构建与 CSP（ADR 0015）；发布目录 `releases/<ts-version>/{api,web,admin,seeds}`，`xingya migrate` → `roles.sql` → `seeds:apply` → 切 `current`。

**Tech Stack:** Node ≥24、pnpm、TypeScript strict、Fastify 5、Kysely、Zod、Vitest、Playwright、React 19 + Vite、PostgreSQL 16、Nginx、systemd、ali-oss / 本地目录桩、dependency-cruiser。

**Spec:** [.scratch/m1-skeleton/spec.md](../../.scratch/m1-skeleton/spec.md)（任务单 01–09）；对照 [docs/02-solution/overview.md](../02-solution/overview.md)、[roadmap W1–2](../02-solution/roadmap.md)、[ADR 0015](../adr/0015-admin-app-and-seeds.md)、[docs/04-ui-design/tokens](../04-ui-design/tokens/)、[deployment §9](../02-solution/deployment.md)。

## Global Constraints

- Node `engines.node` ≥ 24；包管理 pnpm；TypeScript `strict`；所有文档 Markdown。
- 仓库不提交密钥；生产凭据只在服务器 `/etc/xingya/secrets.env`（0600）；示例配置仅占位值。
- DATETIME 一律 UTC；连接 `TimeZone=UTC`；业务时间经可注入 `Clock`。
- 模块只能 import 对方 `index.ts`；`repo.ts` 只触本模块表；跨模块写在同一事务用 `…InTx`（overview §3.4）。
- 孩子端构建产物不得含后台路由名、后台组件名或 `/api/v1/admin` 字符串（ADR 0015）。
- 写请求：需登录写带 `X-Client-Request-Id`（小写 UUID v4）并写幂等表；未登录写同样要求该头（防 CSRF），校验 `Origin` 为本站源，不开放 CORS；请求体 Zod 严格模式、≤ 64 KB。
- 错误体 `{error:{code,message,details?,traceId}}`；`message` 可展示中文；未预期 → `500 INTERNAL` 不泄堆栈。
- 本地 git only：实现中频繁 commit，不 amend、不 push（除非用户要求）。

## Review Focus

1. **空/脏 PostgreSQL：** `xingya migrate` 在空库一次成功、二次无变化；被改过的已应用迁移文件因 checksum 拒绝继续——Task 2 集成测试。
2. **死锁重试与回滚：** 事务封装遇 PostgreSQL SQLSTATE `40P01` / `55P03` 整事务最多重试 2 次；失败全回滚——Task 2。
3. **幂等并发：** 同 `X-Client-Request-Id` 并发 10 次只执行一次；同 ID 不同体 → `409 IDEMPOTENCY_KEY_REUSED`；业务 4xx 不占用该 ID——Task 2 并发测试。
4. **孩子端掺后台字符串：** 故意在 web 引入 `/api/v1/admin` 时 CI 检查失败——Task 5 反例。
5. **健康检查失败自动回滚：** 故意部署坏包时 `deploy.sh` 切回上一发布——Task 8 一次性环境测试。
