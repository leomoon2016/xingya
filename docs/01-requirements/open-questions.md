## 13. 待决问题（每项附推荐答案）

| # | 问题 | 推荐 |
| --- | --- | --- |
| Q1 | **ICP 备案用哪个域名、以谁的名义？**（上线阻塞项，备案需 1–3 周） | **已决定（用户 2026-10-21）**：用户个人名义注册一个新的 `.cn` 或 `.com` 域名，与这台 ECS 一起在阿里云 ICP 代备案系统**立即**提交；上线后 30 日内完成公安联网备案 |
| Q2 | 呀哈哈队长（AI 聊天）与 AI 工作室的文本生成用哪家 LLM？ | 国内厂商的 OpenAI 兼容接口（推荐阿里云百炼通义千问的轻量模型），避免儿童数据出境、延迟低；接口地址与模型名在配置里，可随时切换 |
| Q3 | 邮件服务用哪家？ | 阿里云邮件推送（DirectMail）SMTP，用备案域名做发信域并配置 SPF/DKIM/DMARC，对国内邮箱送达率最好 |
| Q4 | 何时从“邀请码注册”切到“开放注册”，开放前需要哪些合规工作？ | 首发后至少 3 个月保持邀请码模式，只邀请线下认识的家庭；开放前完成：隐私政策与儿童个人信息保护规则法务审阅、替换全部 `legacy-family` 素材、评估跨家庭互动是否需要做互联网信息服务安全评估 |
| Q5 | 学习伙伴档位的价格与门槛？ | **已默认，可调整**：初级 20 星 / 40 碎片 / 门槛 0；中级 50 / 100 / 100；高级 100 / 200 / 300；稀有 200 / 400 / 600（门槛 = 历史累计学习星）。后台 `pet_tiers` 修改 |
| Q6 | 一次作答多久过期？ | **已默认，可调整**：2 小时；过期后完成返回 `409 PLAY_EXPIRED`，未完成作答 7 天后清理。系统设置 `learning.play_ttl_minutes`（30–720，数据库 CHECK） |
| Q7 | 通关发多少碎片、多久发一次？ | **已默认，可调整**：碎片数 = 本次星级（1–3），同一关每个本地日最多一次（`companion.fragment_pass_scope = per_level_per_day`）；完成当日复习 2 片；每个呀哈哈 1 片（后两项为用户指定） |
| Q8 | 伙伴等级曲线、阶段与解锁动作？ | **已默认，可调整**：最高 30 级；L→L+1 需 `5 + (L−1)` 经验；阶段幼苗 1 级 / 探险 5 级 / 守护 12 级 / 星耀 20 级；解锁动作依次为 呼吸待机+开心跳 / 欢呼跳 / 开心挥手 / 欢呼转圈。按档位在后台修改 |
| Q9 | 只有一个系统管理员时，谁来审核？ | **已决定（用户 2026-10-21）**：允许提交人自己审核，**不强制**学生视角试玩（试玩为可选项），自审记入审计；有第二个管理员后把系统设置 `content.allow_self_review` 改为 `false`，即“提交人不能审核自己的提交” |
| Q10 | 营地格数与扩建价格？ | **已默认，可调整**：基础 3 格；扩建 3 次，价格 30 / 60 / 120 星（`companion.den_base_slots`、`companion.den_slot_prices`） |
| Q11 | 呀哈哈稀有度权重？（概率 20%、每日 3 个为用户指定默认） | **已默认，可调整**：普通 100 / 少见 30 / 稀有 10 / 传说 2（`discovery.rarity_weights`） |
| Q12 | 呀哈哈奖励星多少？是否算学习星？ | **已默认，可调整**：集齐一套 +5 星（每套可设 1–50）；累计 10 / 30 / 100 个 +3 / +5 / +10 星（`discovery.milestone_bonus`）。奖励星可花，但**不算学习星**（不计排行、伙伴经验、领养门槛） |
| Q13 | 每月 AI 预算多少？聊天费用算不算？ | **已默认，可调整**：每月 ¥200（`studio.default_monthly_cap_fen = 20000`），后台可改当月上限。**（第 10 部分修订）** 呀哈哈队长现在是儿童 AI 角色，聊天费用**计入**全站预算并计入其角色预算（默认 ¥30/月，见 Q19、Q25）；原“不计入”作废 |
| Q14 | 素材与资料的限制？ | **已默认，可调整**：图片 webp ≤ 300 KB、音频 MP3 ≤ 200 KB、动画清单 ≤ 64 KB；资料单个 ≤ 20 MB（docx/pptx 解压总量 ≤ 100 MB、条目 ≤ 2000，抽取线程堆 ≤ 128 MB、超时 60 秒）；草稿素材签名 URL 有效 10 分钟；扫描版 PDF（无文字层）首发不支持，提示改传照片。这几项是技术上限（数据库 CHECK 与存储成本），**不做成后台设置**，调整需改迁移 |
| Q15 | 图像生成、OCR、LLM 用哪家？ | 推荐全部用阿里云：百炼（通义千问做课程分析与规则填写、通义万相做图像）、阿里云文字识别 OCR；数据不出境、同一账单、与 OSS 同地域。适配器可替换；语音默认本机 Piper（无费用） |
| Q16 | 课程模板 ID 与自然拼读适用年级？ | **已默认，可调整**：`word-quest`、`sentence-dialogue`、`picture-book`、`phonics`；自然拼读适用 1–3 年级，其余 1–6 年级（1–2 年级无拼写）。模板定义在仓库 `seeds/course-templates/`，调整模板 = 改仓库并发版（模板是结构而非运营参数） |
| Q17 | 伙伴与呀哈哈的声音怎么做？用哪个声音模型？ | **已默认，可调整**：Piper 中文 `zh_CN-huayan-medium` 与英文 `en_US-amy-medium` 两个模型，ffmpeg 按 `voice_pitch`（0.5–2.0）变调，设计时一次生成为静态素材；系统设置 `studio.voices` 可换模型（新模型需先装到服务器 `/opt/xingya/piper/voices`） |
| Q18 | 作答中有题没答能不能完成？ | **已默认，可调整**：不能，全部作答后才可完成（`409 PLAY_INCOMPLETE`）；跟读题可直接点“继续”（记 `done:false`）。避免“空答也能通关领奖励”的漏洞 |
| Q19 | 7 个默认 AI 角色的月度预算与工具？ | **已默认，可调整**：课程设计师 ¥60、美术设计师 ¥70、配音师 ¥5、活动策划 ¥10、质检员 ¥20、运营分析师 ¥5、呀哈哈队长 ¥30，合计 = 全站默认 ¥200；工具白名单见 [需求 §4.10.3](modules/agents.md#4103-ai-角色)。后台“AI 角色”页修改（保存为角色新版本）；服务端保证每个角色预算 ≤ 全站当月上限 |
| Q20 | 角色执行器的步数与超时？ | **已默认，可调整**：工具循环最多 20 步（用户指定上限，数据库 CHECK ≤ 20）、呀哈哈队长 3 步、流水线最多 6 步；单次模型调用 60 秒、工具 30 秒、整次运行 10 分钟；儿童单次模型调用 20 秒、整次 25 秒；输出不合格自动修正 1 次。系统设置 `agents.limits`（数据库 CHECK 限定范围） |
| Q21 | Skill 导入包的限制？ | **已默认（技术上限，不做后台设置）**：ZIP ≤ 5 MB、解压后 ≤ 20 MB、≤ 100 个文件、SKILL.md ≤ 64 KB、参考资料 ≤ 20 项且单项 ≤ 256 KB；脚本只作为惰性文本保存，永不执行。调整需改代码 |
| Q22 | 运营分析师的聚合最小分组？ | **已默认，可调整**：少于 5 个孩子的分组不显示（`agents.stats_min_group`，数据库 CHECK 3–50），保证“系统管理员不能查看家庭学习数据” |
| Q23 | 只有一个管理员时，面向孩子的技能/角色的“单独儿童安全审核”谁来做？ | **已决定（用户 2026-10-21）**：与 Q9 一致，`content.allow_self_review = true` 时允许同一人完成常规审核与安全审核；不强制试玩，但面向孩子的技能/角色发布前由系统**自动**跑儿童安全测试集（`seeds/safety/tests/`），不通过不能发布；有第二个管理员后改为 `false` |
| Q24 | 每个后台页面的一句话框默认交给哪个角色？ | **已默认，可调整**：课程 → 课程设计师；伙伴、呀哈哈款式 → 美术设计师；投放规则 → 活动策划；技能库、角色 → 质检员；任务历史、统计 → 运营分析师（系统设置 `agents.page_routes`）；输入中 `@角色` 优先 |
| Q25 | 呀哈哈队长的预算用完怎么办？ | **已默认，可调整**：返回 `503 AI_BUDGET_EXHAUSTED`，孩子端显示“呀哈哈队长这个月有点累了，下个月见”，不计入当日条数；管理员可在后台调高角色预算或当月全站上限 |
