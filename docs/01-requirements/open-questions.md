## 13. 待决问题（每项附推荐答案）

| # | 问题 | 推荐 |
| --- | --- | --- |
| Q1 | **ICP 备案用哪个域名、以谁的名义？**（上线阻塞项，备案需 1–3 周） | **已决定（用户 2026-10-21）**：用户个人名义注册一个新的 `.cn` 或 `.com` 域名，与这台 ECS 一起在阿里云 ICP 代备案系统**立即**提交；上线后 30 日内完成公安联网备案 |
| Q2 | 呀哈哈队长（AI 聊天）与 AI 工作室的文本生成用哪家 LLM？ | **已决定（用户 2026-10-22）**：聊天 / 视觉 / 图像模型**分别可配置**（后台“模型配置”，最多 20 条，每种用途一个默认），默认全部用阿里云百炼（聊天 `qwen-plus`，OpenAI 兼容接口）；API Key 由系统管理员在后台录入、加密保存，不进文档与仓库（[ADR 0022](../adr/0022-llm-vision-image-providers.md)） |
| Q3 | 邮件服务用哪家？ | **已决定（用户 2026-10-22）**：阿里云邮件推送（DirectMail）SMTP；**需要已备案的域名**，域名推迟到上线前选定，列入上线检查清单（[部署 §9.5](../02-solution/deployment.md#95-上线检查清单)）；SMTP 凭据放 `secrets.env`（ADR 0022） |
| Q4 | 何时从“邀请码注册”切到“开放注册”，开放前需要哪些合规工作？ | **已关闭（用户 2026-10-22）**：**永久只用邀请码注册**，不做开放注册，因此不需要开放注册的合规工作，也删除“开放前替换旧素材 / 马里奥素材”这一项；系统设置 `registration.mode` 删除。注册码签发时填了邮箱即绑定该邮箱 |
| Q5 | 伙伴档位的价格与门槛？ | **已决定（用户 2026-10-22）**（照旧系统）：初级 20 星 / 80 碎片、中级 50 / 160、高级 100 / 320、稀有 250 / 800、唯一 600 / 2000（全站同时一人）；部分种类单独定价（[ADR 0021](../adr/0021-nintendo-pets-seed.md)）；领养门槛全站一个 `companion.unlock_stars`，默认 0。后台可改 |
| Q6 | 一次作答多久过期？ | **已决定（用户 2026-10-22）**（照旧系统）：**不过期**；同一关同时只有一次未完成作答，再次开始即恢复，可“重新开始”放弃。删除 `learning.play_ttl_minutes` 与 `PLAY_EXPIRED` |
| Q7 | 通关发多少碎片、多久发一次？ | **已决定（用户 2026-10-22）**（照旧系统）：通关**不发**碎片；每次作答每张关卡学习卡第一次展示发 1–3 片（服务端随机）；完成当日复习 2 片、每个呀哈哈家族成员 1 片（用户指定）。⚠ 看卡即得是被动发放，见 [ADR 0020](../adr/0020-revert-to-old-system.md) R15 |
| Q8 | 伙伴等级曲线、阶段与解锁动作？ | **已决定（用户 2026-10-22）**：最高 100 级（用户 2026-10-22 逐项决定）；曲线照旧 `2 + ⌊(L−1)/10⌋ + ⌊(L−1)²/200⌋`（到 100 级共 2191 经验），阶段幼苗 1 / 探险 20 / 守护 50 / 星耀 100，成长装扮叠加层（围巾、徽章、光环）照旧；动作名称无旧系统对应，保持默认。经验来自学习星（含单词星）；**已决定（用户 2026-10-22，Q36 / ADR 0020 §8 第 4 点）**：保留自动经验，不做花星星升级 |
| Q9 | 只有一个系统管理员时，谁来审核？ | **已决定（用户 2026-10-21）**：允许提交人自己审核，**不强制**孩子视角试玩（试玩为可选项），自审记入审计；有第二个系统管理员后把系统设置 `content.allow_self_review` 改为 `false`，即“提交人不能审核自己的提交” |
| Q10 | 营地格数与扩建价格？ | **已决定（用户 2026-10-22）**（照旧系统）：基础 3 格；扩建 5 次，价格 10 / 20 / 100 / 200 / 500 星 |
| Q11 | 呀哈哈家族稀有度权重？（概率 20%、每日 3 个为用户指定默认） | **已决定（用户 2026-10-22）**（照旧系统，与默认相同）：普通 100 / 少见 30 / 稀有 10 / 传说 2 |
| Q12 | 呀哈哈家族发现奖励（奖励星）多少？是否算学习星？ | **已决定（用户 2026-10-22）**（照旧系统）：**不发奖励星**；集齐套组只点亮图鉴徽记。删除 `discovery_bonus` 与 `discovery.milestone_bonus`；另恢复单元首次全 3 星级必得、收藏上限 1000 |
| Q13 | 每月 AI 预算多少？聊天费用算不算？ | **已决定（用户 2026-10-21）**：每月 ¥200（`studio.default_monthly_cap_fen = 20000`），后台可改当月上限。**（第 10 部分修订）** 呀哈哈队长现在是儿童 AI 角色，聊天费用**计入**全站预算并计入其角色预算（默认 ¥30/月，见 Q19、Q25）；原“不计入”作废 |
| Q14 | 素材与资料的限制？ | **已决定（用户 2026-10-22）**（无旧系统对应，保持默认）：图片 webp ≤ 300 KB、音频 MP3 ≤ 200 KB、动画清单 ≤ 64 KB；资料单个 ≤ 20 MB（docx/pptx 解压总量 ≤ 100 MB、条目 ≤ 2000，抽取线程堆 ≤ 128 MB、超时 60 秒）；草稿素材签名 URL 有效 10 分钟。**扫描版 PDF 现在支持**：逐页交给视觉模型识字（Q15）。这几项是技术上限（数据库 CHECK 或代码常量） |
| Q15 | 图像生成、OCR、LLM 用哪家？ | **已决定（用户 2026-10-22）**：**不用 OCR 服务**——视觉大模型识字（默认百炼 `qwen-vl-max`），图像大模型生成（默认百炼通义万相 `wanx2.1-t2i-turbo`），聊天默认 `qwen-plus`；三者分别可配置、默认都是阿里云百炼；Key 是机密，加密存库（ADR 0022）。语音默认本机 Piper（无费用） |
| Q16 | 课程模板 ID 与自然拼读适用年级？ | **已决定（用户 2026-10-22）**（无旧系统对应，保持默认）：`word-quest`、`sentence-dialogue`、`picture-book`、`phonics`；自然拼读适用 1–3 年级，其余 1–6 年级；1–2 年级无拼写、无阅读理解（照旧系统）。模板定义在仓库 `seeds/course-templates/` |
| Q17 | 伙伴与呀哈哈家族的声音怎么做？用哪个声音模型？ | **已决定（用户 2026-10-22）**（照旧系统）：后台“语音设置”页分中文 / 英文设置 Piper 模型、speaker、语速、噪声、句间停顿，可存为命名预设并试听（`studio.voices`）；首发模型 `zh_CN-huayan-medium`、`en_US-amy-medium`，ffmpeg 变调；仍在设计 / 发布时一次生成（ADR 0010） |
| Q18 | 作答中有题没答能不能完成？ | **已决定（用户 2026-10-21）**：不能，全部作答后才可完成（`409 PLAY_INCOMPLETE`）；跟读题可直接点“继续”（记 `done:false`）。避免“空答也能通关领奖励”的漏洞 |
| Q19 | 7 个默认 AI 角色的月度预算与工具？ | **已决定（用户 2026-10-21）**：课程设计师 ¥60、美术设计师 ¥70、配音师 ¥5、活动策划 ¥10、质检员 ¥20、运营分析师 ¥5、呀哈哈队长 ¥30，合计 = 全站默认 ¥200；工具白名单见 [需求 §4.10.3](modules/agents.md#4103-ai-角色)。后台“AI 角色”页修改（保存为角色新版本）；服务端保证每个角色预算 ≤ 全站当月上限 |
| Q20 | 角色执行器的步数与超时？ | **已决定（用户 2026-10-22）**（无旧系统对应，保持默认）：工具循环最多 20 步（用户指定上限，数据库 CHECK ≤ 20）、呀哈哈队长 3 步、流水线最多 6 步；单次模型调用 60 秒、工具 30 秒、整次运行 10 分钟；儿童单次模型调用 20 秒、整次 25 秒；输出不合格自动修正 1 次。系统设置 `agents.limits`（数据库 CHECK 限定范围） |
| Q21 | Skill 导入包的限制？ | **已决定（用户 2026-10-22）**（无旧系统对应，保持默认；技术上限，不做后台设置）：ZIP ≤ 5 MB、解压后 ≤ 20 MB、≤ 100 个文件、SKILL.md ≤ 64 KB、参考资料 ≤ 20 项且单项 ≤ 256 KB；脚本只作为惰性文本保存，永不执行。调整需改代码 |
| Q22 | 运营分析师的聚合最小分组？ | **已决定（用户 2026-10-22）**（无旧系统对应，保持默认）：少于 5 个孩子的分组不显示（`agents.stats_min_group`，数据库 CHECK 3–50），保证“系统管理员不能查看家庭学习数据” |
| Q23 | 只有一个系统管理员时，面向孩子的技能/角色的“单独儿童安全审核”谁来做？ | **已决定（用户 2026-10-21）**：与 Q9 一致，`content.allow_self_review = true` 时允许同一人完成常规审核与安全审核；不强制试玩，但面向孩子的技能/角色发布前由系统**自动**跑儿童安全测试集（`seeds/safety/tests/`），不通过不能发布；有第二个系统管理员后改为 `false` |
| Q24 | 每个后台页面的一句话框默认交给哪个角色？ | **已决定（用户 2026-10-22）**（无旧系统对应，保持默认）：课程 → 课程设计师；伙伴、呀哈哈家族款式 → 美术设计师；投放规则 → 活动策划；技能库、角色 → 质检员；任务历史、统计 → 运营分析师（系统设置 `agents.page_routes`）；输入中 `@角色` 优先 |
| Q25 | 呀哈哈队长的预算用完怎么办？ | **已决定（用户 2026-10-22）**（无旧系统对应，保持默认）：返回 `503 AI_BUDGET_EXHAUSTED`，孩子端显示“呀哈哈队长这个月有点累了，下个月见”，不计入当日条数；系统管理员可在后台调高角色预算或当月全站上限 |
| Q26 | 每个单元几个关卡？ | **已决定（用户 2026-10-22）**（无旧系统对应，保持默认）：3–6 关（用户给出的范围作为默认；系统设置 `content.unit_levels = {min:3, max:6}`，数据库 CHECK 1 ≤ min ≤ max ≤ 12；模板可用 `levelsPerUnit` 在此范围内再收窄；自动检查 K13）。单元数不设上限，每门课至少 1 个单元 |
| Q27 | 模板按课程还是按单元选？ | **已决定（用户 2026-10-22）**（无旧系统对应，保持默认）：按课程——一门课程（一册）使用一个模板，所有单元结构相同（`courses.template_id` 不变）。若以后需要同一门课程里混合单词课、对话课、绘本课，可改为单元级模板（给 `units` 加 `template_id`，需要新的迁移），首发不做 |
| Q28 | 关卡在单元之间移动、或单元改名（换 `unit_key`）时进度怎么办？ | **已决定（用户 2026-10-22）**（无旧系统对应，保持默认）：进度按 `(课程, unit_key, level_key)` 记录，移动或改名视为新关卡/新单元，旧进度保留但不迁移；后台发布前提示“以下已发布关卡/单元将不再显示”。如需迁移，以后增加一次性的运维迁移命令 |
| Q29 | 孩子端面向什么屏幕与方向？最小宽度与断点？ | **已决定（用户 2026-10-22）**：孩子端以平板和电脑横屏为主，手机竖屏完整可用但布局更紧凑，不锁定方向；家长中心响应式、适配手机；后台桌面优先（≥ 1280 px），不做手机优化。**已决定（用户 2026-10-22）**（无旧系统对应，保持默认）：断点紧凑 `< 768 px`、平板 `768–1279 px`、桌面 `≥ 1280 px`；最小支持宽度 360 px；触控目标 ≥ 44×44 px；e2e 视口 1024×768 / 1280×800 / 360×800。见 [nfr §8.4](nfr.md#84-设备与屏幕) |
| Q30 | 要不要积分？规则怎么定？ | **已决定（用户 2026-10-22）**：积分完全照旧系统，不新增任何上限（[ADR 0017](../adr/0017-points-currency.md)）：同一账本第三币种，0.01 为单位；关内听发音每次作答每个目标 +0.1（无上限、无冷却）；单词本听发音每个发音每天 +0.1、每天 ≤ 10、间隔 5 秒；复习答对每条每天 +1、每天 ≤ 30；跟随伙伴按等级附赠（1 级每星 0.10 → 100 级每星 1.00，按作答开始时等级）；10 积分换 1 颗星星（一次 1–1000 颗，换来的是奖励星）。随之**复习不再发星星**（原规格自定的“复习完成 2 星”删除；用户指定的“完成当日复习 2 片碎片”保留），学习星 = 通关 + 连续里程碑。**后续**：① **已决定（用户 2026-10-22）**：单词本照旧系统进入 v1.0（Q32、[ADR 0019](../adr/0019-wordbook-as-old-system.md)），单词本听发音积分规则随之生效（每个发音每天 +0.1、每天 ≤ 10、间隔 5 秒；考试中不发）；② **已决定（用户 2026-10-22）**：复习积分上限保持每天 30，虽然每天最多复习 20 条、实际达不到，不做改动；③ **已决定（用户 2026-10-22）**：伙伴最高等级改为 100（与旧系统一致），附赠比例可达每星 1.00（见 Q8） |
| Q31 | 正式系统是否继续使用马里奥（游戏搭档）？ | **已决定（用户 2026-10-22，已知版权、ICP 备案审核与下架风险）**：一直使用，与旧系统一致（[ADR 0018](../adr/0018-mario-game-partner.md)）：学习首页“当前任务”卡片按单元轮换（金币探险 / 林克 · 宝箱冒险 / 帽子与月亮 / 马里奥赛车），关内进度条与结算页小卡片按关卡主题；只做展示，不能领养、无经验、无奖励，与伙伴和呀哈哈队长并存；第三方 IP 规则增加这一具名例外；素材固定复用旧系统 `mario.svg`、`link.svg`，放在 `seeds/partners/`，代码只认主题 ID，可不改代码替换；AI 工作室仍不得生成任天堂角色 |
| Q32 | 单词本做不做？怎么做？ | **已决定（用户 2026-10-22）**：“单词本需要和老系统一样实现”，进入 v1.0（[ADR 0019](../adr/0019-wordbook-as-old-system.md)）：孩子手动添加词条（≤ 2000 条，同词唯一，删除后保留学习状态），可让呀哈哈队长生成解释（预览后保存）；学习 / 闯关 / 考试（5 词 / 5 词 10 题 / 10 词 20 题，或自选 1–50 词，每词 2 题）；单词星每词每模式只记最高单位，每 5 个新增单位 1 颗；闯关附赠伙伴积分；每学会 5 词必得 1 个呀哈哈，闯关 / 考试 ≥ 80% 按 20%、每天 2 个随机得；考试中内容隐藏、编辑与 AI 关闭；听发音积分照 Q30；家长中心没有单词本页面；与间隔复习互不关联。排期 +1 周。冲突处理见 ADR 0019 C1–C11（安全规则优先的只有 C6：保存前过滤个人信息）。**已决定（用户 2026-10-22）**：单词星**算学习星**（推翻 C11：计入排行、伙伴经验与领养门槛）；完成一轮单词本**算学习日**；列表每页 20 条、不提供收藏按钮（照旧系统） |
| Q33 | 新星级规则下 1 星级几乎不会出现，是否接受？ | **已决定（用户 2026-10-22）**：星级改按**错题数**——错 0 题 3 星级、错 1 题 2 星级、错 ≥ 2 题 1 星级；**没有未通过、没有 80% 通过线**，每次完成都通关（取代原百分比规则与此前的 80% 通过线；单词本闯关 / 考试仍按 ADR 0019 的百分比）。数据库 `attempts.stars` 生成列已改，`attempts.passed` 已删除（[ADR 0020 §3](../adr/0020-revert-to-old-system.md#3-星级用户-2026-10-22-决定同日后续决定取代百分比规则)） |
| Q34 | 伙伴退订、赠送与全站唯一档（盘点 S-3）是否全部恢复？ | **已决定（用户 2026-10-22）**：全部保留——退订返还实付的一半、赠送、全站唯一档；受赠的伙伴不能退订（防绕过赠星上限）；不删表不删列（[ADR 0020 §8](../adr/0020-revert-to-old-system.md#8-原待确认的点全部已决定用户-2026-10-22) 第 1 点） |
