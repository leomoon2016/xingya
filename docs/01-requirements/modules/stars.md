# 星星（stars）· 需求

> 本文由已确认的《星芽学园全新系统设计规格》（2026-10-21，提交 6b463ed）拆分而来；章节编号沿用原规格，便于交叉引用（编号与文件的对应见 [docs/README.md](../../README.md)）。
> 2026-10-21 设计变更（用户已批准，见 [v1.0 变更记录](../../06-releases/v1.0/changes.md)）：账本改名为 `ledger` 并增加 `currency`，碎片作为第二币种记入同一本只追加账本（[ADR 0011](../../adr/0011-fragments-second-currency.md)）；新增星星来源“发现奖励”与支出“领养伙伴/扩建营地”；商店只卖装扮，伙伴移到 [companion](companion.md)。

> 2026-10-22 用户决定（[ADR 0017](../../adr/0017-points-currency.md)，Q30）：恢复旧系统的**积分**（第三币种，同一账本），规则与旧系统完全一致；10 积分换 1 颗星星；复习不再发星星（改发积分）。

职责：只追加账本（星星、碎片与积分）与余额缓存、发放与扣除、商店装扮购买与穿戴、家长定义的现实奖励与兑换审批。

## 4.1.8 星星来源（仅此 8 种）
| 来源 | 流水 kind | 数量 | 算“学习星”（排行、伙伴经验、领养门槛） |
| --- | --- | --- | --- |
| 首次通过或星级提高 | `level_pass` | 1–3（差额） | 是 |
| 连续天数里程碑 | `streak` | 3 / 7 / 20 | 是 |
| 呀哈哈家族发现奖励（集齐套组、累计里程碑） | `discovery_bonus` | 1–50 | 否 |
| 家长手动奖励 | `parent_award` | 1–50 / 次，只能加 | 否 |
| 收到赠送 | `gift_in` | 1–20 | 否 |
| 积分换星（10 积分 = 1 颗） | `point_convert` | 1–1000 / 次 | 否 |
| 单词闯关进步奖励（ADR 0019） | `word_challenge` | 1–30 / 轮（每 5 个新增进度单位 1 颗） | 否 |
| 单词考试进步奖励（ADR 0019） | `word_exam` | 1–20 / 轮 | 否 |

前两种来源统称**学习星**；其余六种统称**奖励星**：可以花，但不计入排行、伙伴经验和领养门槛（见 [GLOSSARY.md](../../../GLOSSARY.md)）。

复习不发星星（旧系统规则；复习答对发积分，完成当日复习发碎片）。看卡片、登录、聊天等被动行为不产生任何流水；点喇叭听发音只发积分（见 §4.1.9），不发星星。星星支出：`purchase`（装扮）、`pet_adopt`（用星星领养伙伴）、`den_expand`（扩建营地）、`gift_out`、`redeem_hold`（冻结）、`redeem_release`（释放）、`redeem_debit`（批准扣除）。

碎片来源与用途见 [companion 需求 §4.6.2](companion.md#462-碎片第二种货币)：只来自 `level_pass`、`review_day`、`discovery`，只用于 `pet_adopt`。

## 4.1.9 积分（与旧系统完全一致）
积分以 0.01 为单位记账（界面显示两位小数），不设余额上限以外的任何新上限。

| 来源 | 流水 kind | 数量 | 次数与上限 |
| --- | --- | --- | --- |
| 关内听发音：点题目、选项、对话、短文、跟读标准音的喇叭 | `level_listen` | +0.1 | 同一次作答中每个发音目标一次；无每日上限、无冷却 |
| 单词本听发音：单词、英文释义、每条短语、每条例句 | `word_listen` | +0.1 | 每个发音每个本地日一次；每天最多 10 积分；两次得分至少间隔 5 秒 |
| 复习答对 | `review_correct` | +1 / 题 | 每个复习条目每个本地日一次；每天最多 30 积分 |
| 伙伴附赠 | `pet_bonus` | 本次通关新得星数 × 每星比例 | 每次闯关结算或单词闯关结算一次（ADR 0019）；按开始作答时跟随伙伴的等级：1 级每星 0.10 积分，线性升到 100 级每星 1.00 积分（节点与公式见 ADR 0017）；默认最高 100 级 = 每星 1.00 |

- 用途只有**换星**：`POST /points/conversions {stars}`，10 积分 = 1 颗星星，一次 1–1000 颗，积分不足 → `409 INSUFFICIENT_POINTS`；换来的星星是奖励星。积分不能直接购买装扮、兑换现实奖励、赠送，家长不能发放。
- 关内听发音：目标必须属于这次作答的可见部分并带音频；作答已结束 → `409 PLAY_FINISHED`；已得过 → 200 `{awarded: false}`（“本轮已获得过发音积分啦”）；孩子端关闭声音时不上报。
- 单词本：v1.0 **包含**单词本（用户 2026-10-22 决定，[ADR 0019](../../adr/0019-wordbook-as-old-system.md)），`word_listen` 照上表生效：`POST /wordbook/listen`，发音键是归一化后的发音文本；考试中不发；关声音时不上报。
- 孩子端“积分”页：余额、今日复习积分（x / 30）、今日单词本听读积分（x / 10）、最近流水、换星按钮。家长中心流水页同样显示积分流水。

## 4.2.1 账本与余额
- `ledger` 只追加：每行 `currency`（`star` / `fragment` / `point`；积分以 0.01 为单位）、`kind`、`delta`（正负号由 kind 决定，CHECK 约束）、`balance_after ≥ 0`（该币种余额）、`source_key`（同一孩子同一币种唯一，业务级幂等）、`local_date`。数据库 CHECK 规定每个币种允许哪些 kind、每个 kind 的数量范围。
- **可用余额 = 该孩子该币种全部流水 `SUM(delta)`**。`balances`（主键 `(child_id, currency)`）是同一事务内维护的缓存，同时充当行锁；每晚对账（[§3.6](../../02-solution/overview.md#36-后台任务进程内调度器单实例)）。没有任何“直接改余额”的接口或 SQL。
- 一个操作同时涉及多个币种时（例如通关同时发星星、碎片与伙伴附赠积分，换星同时扣积分加星星），按固定顺序 `star` → `fragment` → `point` 加锁（[§4.5.2](../nfr.md)）。
- “冻结中”= 该孩子待审批兑换的价格之和（`redemptions.status='pending'`）。孩子界面显示“可用 N 颗，冻结 M 颗”，以及碎片与积分余额。

## 4.2.2 商店与装扮
- 装扮（`head`/`body`/`accessory` 三个槽位）由系统管理员在后台维护：ID、名称、价格（1–1000）、图片（素材库）、上架/下架；初始数据来自仓库 `seeds/shop/`。图片必须原创或已授权（提示词禁止词表同样适用于上传的名称与描述）。
- 购买 `POST /shop/purchases {itemId, expectedPrice}`：服务端读取**当前**价格；与 `expectedPrice` 不同 → `409 PRICE_CHANGED`（返回新价格，孩子确认后重试）；已下架 → `404`；已拥有 → `409 ALREADY_OWNED`；余额不足 → `409 INSUFFICIENT_STARS`。成功则同一事务写 `purchase` 流水（`source_key = purchase:{itemId}`）与 `child_items`。
- 每件物品每个孩子只能买一次；无退货、无转赠。下架物品不再出售，已拥有的仍可穿戴。
- 穿戴：`PUT /me/equipment {slot, itemId | null}`；每个槽位最多一件（唯一键）。伙伴不在商店里，见 [companion 需求](companion.md)。

## 4.2.3 现实奖励兑换
- 家长维护本家庭的奖励清单（标题 ≤40 字、星价 1–2000、启用/停用，乐观锁）。
- 孩子申请 → 冻结；家长批准 → 扣除；拒绝 → 释放；孩子可撤回待审批申请 → 释放。每个孩子最多 3 个待审批申请。
- 申请时同样做价格复核（`expectedPrice`）；申请单保存标题与价格快照，之后家长改价不影响已申请的单。
- 只能用星星兑换，碎片不能兑换。

## 验收要点
- 星星只有表中 6 种来源、碎片只有 3 种来源、积分只有 §4.1.9 的 4 种来源；看卡片、登录、聊天不产生任何流水，点喇叭只产生 `level_listen` 积分流水（集成测试遍历这些接口后核对账本行数）；复习结算不写任何星星流水。
- 积分：同一次作答同一发音目标只得一次 0.1；复习答对每个条目每天一次、每天最多 30 积分（第 31 题起不再发）；伙伴附赠 = 星数 × 比例（1 级 0.10、30 级 0.27、100 级 1.00）；换星 10 : 1、1–1000 颗、不足返回 `INSUFFICIENT_POINTS`，换来的星星不计学习星；同一请求 ID 重放只换一次。
- 账本只追加：应用数据库账号对 `ledger` 的 UPDATE/DELETE 被拒（[附录 A](../../03-design/data-model.md#附录-a-数据库验证结果)）；任一孩子任一币种 `SUM(delta)` = `balances.balance` = 最后一行 `balance_after`，夜间对账差异为 0。
- 同一 `source_key` 并发或重放只入账一次；余额不足时购买、领养、赠送、兑换均被拒且不写任何流水。
- 购买时价格已变 → `409 PRICE_CHANGED`，孩子确认新价格后重试成功；同一装扮只能买一次；同一槽位只能穿一件。
- 兑换：申请冻结、批准扣除、拒绝或撤回释放，三者之后“可用 + 冻结”与流水一致；每个孩子最多 3 个待审批申请；碎片不能用于兑换。
- 通关同时发星星、碎片与积分时按“星星行 → 碎片行 → 积分行”加锁，并发测试无死锁。
