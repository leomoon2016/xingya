## 4.4.4 呀哈哈队长（AI 聊天）
- 所有页面右下角浮动入口，孩子与家长都可用（管理端不提供）。
- 对话只存在于浏览器内存（React 状态，不写 localStorage），刷新、注销、换人即清空。每次请求带最近 ≤10 轮（≤20 条）上下文，单条用户输入 ≤ 200 字，总长 ≤ 4000 字。
- 服务端只存元数据（时间、主体、角色版本、模型、状态、字符数、token 数、费用、过滤命中类别、耗时），保留 90 天；不存任何对话文本。**没有聊天记忆**：不写 AI 运行记录（数据库禁止儿童角色进入 `agent_runs`）。
- 流程：全站开关 → 孩子配额（`ai_daily_limit`，默认 20，0 = 关闭）/ 家长固定 100 条 → `checkAccess('chat')`（孩子）→ 在 `child_controls` 行锁内统计当日用量并插入 `pending` 记录（请求 ID 唯一，重放 → `409 CHAT_DUPLICATE_REQUEST`）→ 输入过滤（命中则不预留、不调用模型）→ 预留本条的预算（全站 + 呀哈哈队长角色预算；不足 → `503 AI_BUDGET_EXHAUSTED`，记录为 `error`，不计入配额，Q25）→ 由角色执行器同步运行（单次模型调用 20 秒、整次 25 秒、最多 3 步、最多 300 token，`agents.limits`）→ 输出过滤 → 更新记录并结算费用 → 返回。
- 过滤：仓库 `seeds/safety/` 中维护的分类词表（随发布包部署）（色情、暴力、自伤、仇恨、政治、脏话）+ 规则（网址、电话号码、身份证号、QQ/微信号、具体住址模式）。输入命中：不调用 LLM，返回呀哈哈队长的友好引导语；自伤类命中返回“请马上告诉爸爸妈妈或信任的大人”；输出命中：替换为安全回复。命中都计入配额并在家长报告中按类别计数。配额统计当日状态为 `pending`、`ok`、`input_blocked`、`output_blocked` 的记录；`error`、`timeout` 不计入。
- 提示词 = 系统守则（仓库 `seeds/safety/agent-guard.md`，不可关闭）+ 角色说明 + 已发布的儿童技能（数据库版本化，需儿童安全审核）。角色说明与 `child-safety` 技能的要点：你是“呀哈哈队长”，一个友善的小树灵，带领呀哈哈家族，对象是 6–12 岁孩子；用简短中文或简单英语回答，鼓励学英语；不询问也不记录姓名、学校、住址、电话等个人信息；不提供链接；拒绝不适合儿童的话题并建议问家长；不假装是真人；不给医疗/法律建议。发给 LLM 的内容不含昵称、家庭信息等身份数据。
- 唯一工具 `child.learned_words`：只读当前登录孩子已学的词（最多 50 个），孩子 ID 来自会话，模型无法指定其他孩子；家长聊天时不可用。
- 模型名来自系统设置 `ai.model`，必须属于服务器配置中的允许列表；系统管理员可在后台切换。全站开关 `ai.enabled` 关闭后 10 秒内生效（设置缓存 10 秒），入口隐藏、请求返回 `503 AI_DISABLED`。

## 验收要点
- 服务器上不保存任何对话文本（数据库与日志检查：只有元数据）；刷新、注销、换人后对话清空。
- 孩子每日配额（默认 20，0 = 关闭）与家长 100 条在并发请求下不超额；`error`/`timeout` 不计入配额；同一请求 ID 重放 → `409 CHAT_DUPLICATE_REQUEST`。
- 过滤用例集（各类别输入与输出、网址、电话、证件号、QQ/微信号、住址）全部命中；自伤类返回求助引导；命中按类别计入家长报告。
- 发给 LLM 的内容不含昵称、家庭名等身份信息（请求桩断言）。
- 关闭全站开关后 10 秒内入口隐藏、请求返回 `503 AI_DISABLED`；时长用完或时段外返回 `403`。
- 全站或角色预算不足时返回 `503 AI_BUDGET_EXHAUSTED` 且不计入配额；呀哈哈队长没有已发布版本时入口隐藏（`503 AI_DISABLED`）。
- `child.learned_words` 只返回本孩子的词（构造他人 ID 无效）；`agent_runs` 中没有儿童角色记录。
