## 4.1.2 课程开放、单元与关卡解锁
- 课程开放规则（唯一规则，由 controls 判断）：
  `open(child, course) = course.status = 'active' AND course.current_version_id IS NOT NULL AND ( override = 'open' OR (override 不存在 AND course.grade = child.grade) )`，
  其中 `override` 是 `course_overrides` 中该孩子该课程的记录；`closed` 即关闭。
- 开放以**年级 / 课程**为单位（家长不能按单元开放或关闭）；课程开放后，单元与关卡按下面的顺序解锁。
- 孩子看到的是课程的**当前已发布版本**（`courses.current_version_id`）。单元用跨版本稳定的 `unit_key`、关卡用单元内稳定的 `level_key` 标识；关卡进度按 `(孩子, 课程, unit_key, level_key)`、单元进度按 `(孩子, 课程, unit_key)` 记录，课程改版不丢进度。
- **单元解锁**：第一个单元总是解锁；第 N+1 个单元在第 N 个单元**完成**（当前版本中该单元全部关卡都已通过）后解锁——即单元 N 最后一关通过时，单元 N+1 第一关解锁。单元一旦完成就记下首次完成时间（`unit_progress.first_completed_at`），之后新版本给单元 N 增加关卡也不会把单元 N+1 重新锁上（新增的关卡照常可玩）。
- **关卡解锁**（在已解锁的单元内）：单元第一关随单元解锁；之后每一关在“同一单元内前一关（按当前版本顺序）已通过”或“本关已有通过记录”时解锁。新版本中途插入的关卡不会把已通过的后续关卡重新锁上；新版本删掉的关卡或单元不再显示，但历史记录保留。
- 单元进度（每次结算时在同一事务内更新）：关卡数、已通过关卡数、3 星级关卡数、首次完成时间、首次全 3 星级时间；首次全 3 星级通关时把触发条件“单元首次全 3 星级通关”传给呀哈哈发现（每个孩子每个单元只触发一次）。
- 孩子年级改变后，旧年级课程不再默认开放，但已有进度保留；家长可用 `open` 覆盖重新开放。
- **孩子自选课程**（旧系统顶栏年级 / 课程下拉，ADR 0020）：孩子可在**当前对自己开放**的课程之间切换，选择保存在 `children.current_course_id`（`PUT /child/me {currentCourseId}`），各课程进度分别保存；选择未开放的课程 → `403 COURSE_CLOSED`。家长的开放 / 关闭规则不变。

## 4.1.3 题型（10 种）
| 类型 | 代码 | 呈现 | 作答 | 计分 |
| --- | --- | --- | --- | --- |
| 看图选词 | `pick_image` | 图片 | 从 3–4 个词选项中选一个 | 是 |
| 听音选词 | `listen_choose` | 播放标准音（可重复） | 从 3–4 个词选项中选一个 | 是 |
| 拼写 | `spell` | 图片 + 中文提示；**提交前不播放单词发音**（旧系统；六年级课程可在草稿中设 `audioHint: true`） | 键入或点选字母拼出单词 | 是：去首尾空格、大小写不敏感、`’`/`'` 视为同一字符，与标准答案或可接受答案之一完全相同 |
| 跟读 | `read_aloud` | 播放标准音（词或短句） | 录音 → 依次回放“标准音 / 我的录音”自我对比 | **否**：无自动评分；不计入正确率；录音只在浏览器内存，离开题目即丢弃，从不上传 |
| 情景对话 | `dialogue_choose` | 情景图 + 1–3 句对话（可播放） | 为空缺的一句从 3–4 个选项中选择 | 是 |
| 排序 | `order` | 3–6 个打乱的词块或句子 | 拖动/点选排成正确顺序 | 是：整个顺序完全正确才算对 |
| 填空 | `cloze` | 一句话，一处空缺 | 从 3–4 个选项中选一个（首发不做自由键入） | 是 |
| 阅读理解 | `reading_choose` | 绘本页（图 + 句 + 音频）后的问题 | 从 3–4 个选项中选一个 | 是 |
| 听辨 | `listen_discriminate` | 播放一个音（字母音或词） | 从 2–4 个发音相近的选项中选出听到的那个 | 是 |
| 听音选图 | `listen_pick_image` | 播放标准音（可重复） | 从 3–4 个“图片 + 中文”选项中选出听到的词（旧系统，ADR 0020） | 是 |

- 麦克风不可用或孩子拒绝授权时，跟读题显示“听一听再大声读”并可直接继续；记录 `{done:false}`，不影响通过。
- **每次下发都重新打乱选项顺序**（排序题打乱词块顺序）；选项在课程里有稳定的选项 ID，但**下发给孩子端的是本次作答专用的随机令牌**（每次作答重新生成，映射只存在服务端 `plays.items`），因此记住“o1 总是对的”或从词块 ID 推出顺序都不可能；可见部分也不下发义项 ID 等可反查答案的字段。判分时服务端把令牌映射回选项 ID，只看所选选项或提交的顺序。
- 1–2 年级课程不得含 `spell` 与 `reading_choose`（旧系统规则，ADR 0020；由模板与自动检查保证，见 [课程模型](../../03-design/course-model.md)）；绘本课在 1–2 年级改为听读 + 跟读 + 听音选图。
- **两步作答**（旧系统）：孩子先点选选项（可改选），再点“确认答案”才提交；只记第一次确认。
- **选项喇叭**：看图选词、情景对话、填空、阅读理解的英文选项各有一个喇叭，点喇叭只朗读、不选中；听音类题（`listen_choose`、`listen_pick_image`、`listen_discriminate`）**不给选项喇叭**——⚠ 否则等于把答案读给孩子听（安全 / 公平规则优先，ADR 0020 R3）。
- **答后显示**（旧系统）：每题提交后随反馈显示听力原文、中文意思、例句翻译与解析（`question_answers.reveal` 与 `explanation`），作答前从不下发。
- **题目来源**：每题可记来源（如“一年级上册 第 12 页”，`questions.source`），只在后台与审核中显示。
- 每关 5–8 题，其中至少 4 道计分题；每个模板规定本模板可用的题型组合（见 [studio 需求 §4.8.3](studio.md#483-课程模板首发-4-个)）。

## 4.1.3a 学习卡
旧系统每关都必须先有学习卡（“每关需要学习卡和 1–50 道题目”），ADR 0020 照旧恢复：
- **关卡学习卡**：每关至少 1 张、最多 50 张，作答开始时先逐张翻看，再进入题目。卡片种类：
  - 单词卡（`word`）：单词、中文释义、拼音（语文以后用）、例句与例句翻译、插图、发音；
  - 句子卡（`sentence`）：句子、中文、插图、发音；
  - 字母卡（`letter`）：大写、小写、字母音、例词（≤ 50 个）；
  - 拼读卡（`phonics`）：“分开听，再拼读”的音块与整词发音。
- **拓展卡**（附加听读）：挂在单元上而不是关卡上，单元页“拓展听读”入口打开，对应教材第 N 页的补充听读，不计星、不计分。
- 学习卡**不计分、不进复习**；点卡片上的喇叭可得听发音积分（与题目相同：每次作答每个目标 +0.1）。
- **碎片**：每次作答中每张关卡学习卡**第一次展示**时发 1–3 片碎片（随机数由服务端用加密随机数生成，客户端上报 `POST /plays/:id/cards/:cardKey/seen`），每张卡每次作答只发一次（`source_key = card:{playId}:{cardKey}`）；拓展卡不发碎片。这是旧系统规则（Q7，用户 2026-10-22 决定照旧），**通关不再发碎片**。

## 4.1.4 判分、通过与星级
- 计分题数 `S`（4–8）、答对数 `C`；正确率 `accuracy = floor(C×100/S)`。跟读题不进入 `S`。
- 通过：`C×100 ≥ S×80`。星级（**已决定，用户 2026-10-22**）：`C = S` → 3 星级；`C = S − 1` 且通过 → 2 星级；其余通过 → 1 星级；未通过 → 0 星级。
  （例：5 题对 4 题 = 80% → 2 星级；8 题对 7 题 = 87% → 2 星级；4 题对 3 题 = 75% → 未通过；8 题对 6 题 = 75% → 未通过。）
- ⚠ 每关 4–8 道计分题时，错 2 题的正确率最高是 6/8 = 75%，所以 **1 星级实际不会出现**；这是新规则的直接结果，见开放问题 Q33。
- **只算每题第一次作答**：逐题反馈后再改答案不影响判分（见 §4.1.5）。
- 发星：`awarded = max(0, 本次星级 − 该关历史最佳星级)`，1 个星级 = 1 颗星。首次 3 星级一次拿 3 颗星星；之后从 1 星级提到 3 星级补 2 颗；重玩不提高不发。
- 碎片：通关**不发**碎片；碎片来自学习卡首次展示（§4.1.3a）、完成当日复习与呀哈哈（[开放问题](../open-questions.md) Q7，已决定照旧）。
- 未通过时结算页显示“一起再练一练吧”与“再试一次”按钮（旧系统）。
- 伙伴经验：本次实际发放的“学习星”（通关差额 + 隐藏奖励）每颗给跟随伙伴 +1 经验（见 [companion 需求](companion.md)）。
- 数据库用生成列再算一遍（`attempts.accuracy_pct/stars/passed`），与代码规则不一致时插入失败，保证两处一致。

## 4.1.5 作答（play）：只下发可见部分、逐题反馈、完成一次结算
- **开始**：`POST /levels/:levelId/plays`（请求头带客户端请求 ID）。服务端检查课程开放、关卡解锁、`checkAccess('start')`，在 `plays` 中记录本次下发的题目与选项顺序以及此刻跟随伙伴的等级（`companion_level`，伙伴附赠积分用），返回本关学习卡与题目的**孩子可见部分**（题干、选项 ID 与文字/图片、资源 URL），**不含答案与解析**。同一请求 ID 重放返回同一次作答。**同一关已有未完成的作答时，直接返回那一次作答及已答进度**（200，旧系统“继续上次”），不新开。
- **逐题作答**：`POST /plays/:id/answers {questionId, response}` 返回 `{correct, correctOptionId 或标准答案, explanation, reveal}`，客户端据此即时反馈（答对 600 ms 自动下一题，答错停留看解释）。**每题只记录第一次作答**；对同一题再次提交返回第一次的结果，不改判分。跟读题提交 `{done:true|false}`，不返回对错。
- **听发音积分**：作答进行中点喇叭播放题目、选项、对话、短文或跟读标准音时，客户端上报 `POST /plays/:id/listen {target}`；服务端校验目标属于本次作答的可见部分并带音频，每个目标每次作答发一次 0.1 积分（`level_listen`，无每日上限、无冷却，与旧系统一致）；已得过返回 `{awarded:false}`，作答已结束返回 `409 PLAY_FINISHED`。复习作答同样适用。
- **完成**：`POST /plays/:id/finish`。全部题目都有作答后才可完成（否则 `409 PLAY_INCOMPLETE`）。服务端在一个事务内写闯关记录（`attempts`，每次作答最多一条）、更新最佳星级、写星星流水、结算隐藏奖励（§4.1.5a）、给跟随伙伴加经验并按其开始作答时的等级附赠积分（`pet_bonus`，只在本次新得星数（含隐藏奖励）> 0 时）、复习入队、更新秘密路线的发现条件，并决定本关 3 个藏匿点的内容（见 [discovery 需求](discovery.md)），返回结算结果与藏匿点。重复完成返回第一次的结果。
- 作答**不过期**（旧系统，Q6 已决定照旧）：未完成的作答一直保留，再次开始同一关时继续；孩子可以点“重新开始”放弃（`POST /plays/:id/abandon`，状态记为 abandoned）后新开一次。时长用完的宽限见 [controls 需求](controls.md)。
- **版本**：作答固定在开始时的课程版本上；系统管理员在作答过程中发布新版本，不影响这次作答（已发布版本不可修改，旧版本数据永远可用）。下一次开始使用新版本。
- 客户端在内存中保留当前作答 ID；网络失败时重试同一个请求（同一请求 ID），不会重复记录。

## 4.1.5a 隐藏奖励与秘密路线（旧系统，ADR 0020）
**隐藏奖励**
- 课程草稿可给关卡设隐藏奖励（`levels.hidden_reward`）：`double`（本次新得星星翻倍）或 `fixed`（宝箱 +20 星）；每个单元最多 2 关（自动检查）。孩子端事先看不到，结算时揭晓。
- 每个孩子每关只领一次：第一次结算且本次星级 > 0 时领取；`double` 的数量 = 本次 `level_pass` 差额（0–3；为 0 时也算已领，与旧系统一致），`fixed` = 20。星星 kind `hidden_reward`，**算学习星**，同样给伙伴加经验与附赠积分。

**秘密路线**（与马里奥游戏搭档主题一致）
| 路线 | 出现条件（单元内） | 入场费 | 题目 | 奖励 |
| --- | --- | --- | --- | --- |
| 金币小径 `coins` | 任一关达到 3 星级 | 2 星 | 单元第 1 关的前 3 道计分题 | 4 星 |
| 赛车捷径 `kart` | 通过 ≥ 3 关 | 5 星 | 单元第 2 关的前 3 道计分题 | 10 星 |
| 月亮秘境 `moon` | 单元复习累计答对 ≥ 5 题 | 10 星 | 单元第 3 关的前 3 道计分题 | 20 星 |

- 条件满足时路线出现在闯关地图上（`secret_routes.discovered_at`）。第一次进入付入场费（`secret_entry`，奖励星支出），之后重试免费。
- 作答 `kind = secret`，同样只下发可见部分、逐题反馈。**3 题全对才算通过**（⚠ 旧系统是 3 题对 2 题；通过线 80% 是用户逐项决定，个别规则优先，ADR 0020 R2）。
- 第一次通过时一次性得 2 倍入场费（`secret_reward`，**算学习星**），并附赠伙伴积分；之后再通过不再得奖励。单元关卡不足 3 关时，缺的路线不出现。

## 4.1.6 间隔复习
- 复习条目两类：**义项**（首次通过某关时，该关考查的全部义项进入）和**错题**（任何一次闯关中答错、且没有关联义项的计分题进入，绑定到不可变的题目行；有义项的错题让该义项条目重置到盒 1）。跟读题从不进入。同一孩子同一义项/题目只有一条（唯一键）。
- 复习进度绑定**共享词库的义项**（如 `en.bat.animal`），因此不同课程考到同一个义项共用一条复习条目。
- 盒与间隔：盒 1–6 对应 1、2、4、7、15、30 天。新条目进入盒 1，到期日 = 本地今天 + 1。
- 复习作答：答对 → 盒 +1（最高 6，在 6 盒答对仍为 6），到期日 = 今天 + 新盒间隔；答错 → 回到盒 1，到期日 = 今天 + 1，`lapses + 1`。
- 复习入口显示“今日到期数”= `due_date ≤ 今天` 的条目数。每天最多复习 20 条：`POST /review/plays` 生成一次复习作答，含 `min(到期数, 20 − 今日已复习数)` 条，按 `due_date`、`box`、`id` 升序；超出部分仍保持到期，自然顺延到第二天。
- 义项条目的题目由服务端现场生成：义项有图出“看图选词”，否则出“听音选词”；干扰项从同学科、同年级已发布义项中确定性选出并记录在作答里。错题条目重放原题（不可变题目行）。复习作答同样只下发可见部分、逐题反馈、`POST /plays/:id/finish` 结算。
- 结算时服务端只对“此刻仍到期且属于该孩子”的条目判分（另一台设备已复习过的条目忽略），一次最多 20 条且不超过当日剩余额度。
- **今日复习完成**：某次结算后满足 `今日已复习数 ≥ 20` 或 `剩余到期数 = 0`，且当天开始时有到期条目，则这次记录 `completes_day = 1`（数据库唯一键保证每天最多一次），发 2 片碎片（不发星星）。当天没有到期条目不算完成、不发碎片。
- **复习积分**（旧系统规则，ADR 0017）：每次复习结算，答对的条目每条 +1 积分（`review_correct`），同一条目同一本地日只发一次，每天最多 30 积分；与是否“今日复习完成”无关。复习不发星星、不给伙伴经验、不附赠积分。
- 中途退出复习不结算，不留复习记录（未完成的复习作答保留，下次进入复习时继续）。
- 复习条目记录来源课程与单元（`origin_course_id`、`origin_unit_key`），用于月亮秘境的“单元复习累计答对”。
- **复习入口**（旧系统）：学习首页“轻松复习小站”卡片与星星小铺的“复习积分”卡都可进入复习。

## 4.1.7 连续学习天数
- “学习日”= 本地日期内**通过至少一关**（任何一次 `passed=1` 的闯关，含重玩）、**完成当日复习**，**或完成一轮单词本**（学习、闯关或考试；用户 2026-10-22 决定）。
- 当前连续天数 = 截至今天（或昨天，若今天尚未学习）的连续学习日数。
- 里程碑：连续段长度达到 3、7、30 天时各发一次：3 天 +3 星、7 天 +7 星、30 天 +20 星；`source_key = streak:{milestone}:{连续段起始日期}`，同一连续段每个里程碑只发一次；断开后重新开始的连续段可再次获得。30 天之后不再有新里程碑。
- 连续天数也是投放规则中“课程设定规则”的一种触发条件（见 [discovery 需求](discovery.md)）。
- 不惩罚断签，不设补签。

## 4.1.8a 游戏搭档（马里奥、林克；ADR 0018）
- 与旧系统一致：学习首页“当前任务”区显示游戏搭档卡片，按单元序号轮换主题 `['coins','treasure','moon','kart'][(单元序号 − 1) mod 4]`（马里奥 · 金币探险 / 林克 · 宝箱冒险 / 奥德赛 · 帽子与月亮 / 马里奥赛车 · 快乐出发），说明文字“答完一题，和搭档前进一步”。
- 关内进度条（探险小路）与通关结算页的小卡片使用该关的主题：默认按关卡在单元内的序号轮换 `['coins','kart','moon','treasure'][(序号 − 1) mod 4]`。
- 游戏搭档只做展示：不能领养、不获得经验、不产生星星、碎片或积分；与跟随伙伴并存（跟随伙伴照常显示在它自己的位置）。主题名称、图片来自 `seeds/partners/partners.json`，代码只认主题 ID。

## 4.1.8b 单词本（与旧系统一致；ADR 0019）
旧行为与出处见 [ADR 0019](../../adr/0019-wordbook-as-old-system.md)；界面流程见 [flows/child/wordbook.md](../../04-ui-design/flows/child/wordbook.md)。

**词条**
- 孩子在“我的单词”里手动添加词条。字段：单词或短语（1–80 字符）、中文解释、英文解释（各 ≤ 2000）、短语与双语例句（各 ≤ 10 条，每条英文、中文各 1–500）、我的备注（≤ 2000）、“这个单词我已经熟悉”。
- 每个孩子最多 2000 条（`409 WORDBOOK_FULL`）。同一个词归一化（NFKC → 去首尾空白 → 合并空白 → 小写）后只能有一条（`409 WORD_DUPLICATE`）。
- 编辑带 `version` 乐观锁（`409 VERSION_CONFLICT`）。删除是硬删除，但词身份（学习状态、首次学会、最高单位）保留，以后重新添加时继续沿用。
- 列表可按单词、释义、备注搜索；可按学习状态筛选（已掌握 / 待巩固 / 未学习）；按最近更新排序，分页。
- 孩子写的文字保存前先经过呀哈哈队长的输入过滤，命中个人信息 → `400 TEXT_BLOCKED`。这些文字只有孩子本人可见。
- **AI 解释**：`POST /wordbook/explain {word}` 由呀哈哈队长的儿童技能 `word-explain` 生成，只发送单词和年级，返回结构化预览。孩子确认后，像普通编辑一样保存，标记 `explanation_source = ai`。
  - 计入 AI 预算和该孩子当天的聊天次数。
  - 家长关闭呀哈哈队长时返回 `403 CHAT_DISABLED_FOR_CHILD`；全站关闭 AI 时返回 `503 AI_DISABLED`；考试中返回 `409 WORD_EXAM_LOCKED`。
- 不提供“收藏到单词本”按钮（与旧系统 2026-10-20 之后一致）。

**一轮学习（学习 / 闯关 / 考试）**
- 默认选词：学习和闯关 5 个词，考试 10 个词，未掌握的词排在前面；也可以自己选 1–50 个词。可出题的词必须只含英文字母、空格、撇号或连字符，并且有中文解释，否则列入 `excluded` 并说明原因。
- 每个词 2 题。第 1 题看词选中文。第 2 题：三年级及以上是拼写（按归一化比较）；否则开声音时听音选词，关声音时看中文选英文（`sound` 由客户端在开始时带上）。
- 每题最多 3 个干扰项，来自自己的其他词条，以及已开放课程当前版本的义项；词义不能重复。
- 题目、答案和设置都快照在 `word_tasks.snapshot`，只保存在服务端；下发的题目不含答案。
- **学习**：先看学习卡（左页认词、右页用词；“上一页”只能回看），再做小测，逐题反馈，不发星星。
- **闯关**：逐题反馈。100% / ≥ 80% / ≥ 60% 分别记 3 / 2 / 1 个单位。
- **考试**：题目打乱，交卷前不反馈，可以跳题，交卷时提示未答题。100% / ≥ 80% 分别记 2 / 1 个单位。
- 考试进行中：单词本只返回词形；编辑、删除和 AI 解释返回 `409 WORD_EXAM_LOCKED`；呀哈哈队长聊天返回 `409 WORD_EXAM_AI_RESTRICTED`。
- 每个孩子同时只有一轮进行中（数据库唯一键），进入单词本时恢复这一轮。“退出本轮”直接放弃，不发奖励。推进请求带 `expectedRevision`，不一致 → `409 VERSION_CONFLICT`。
- **结算**（幂等，重复请求返回第一次的结果）：
  - 每个词 2 题全对 → 已掌握，并在第一次时写入 `first_passed_at`；否则 → 待巩固。
  - 闯关和考试：这一轮的单位应用到本轮每个词，每个词每种模式只保留最高单位。新增单位加上该模式的余量，每满 5 个单位发 1 颗星星（`word_challenge` / `word_exam`，**学习星**，用户 2026-10-22 决定：计入排行、伙伴经验与领养门槛），余数留到下次。
  - 闯关得星时，按开始这一轮时的跟随伙伴等级附赠积分（`petbonus:word:{taskId}`）。
- **呀哈哈**：
  - 里程碑：首次学会的词每满 5 个，必得 1 个藏匿点；放不下时记为待领取，之后补发。
  - 随机：只在闯关或考试 ≥ 80% 时判定，按系统设置 `wordbook.random` 抽取（默认 20%，每天 2 个，每轮最多 1 个）；同一天同一模式只要有一个词判定过，本轮就不判定。
  - 两种都受呀哈哈全局每日上限（10）与款式库存约束，在结算页点开揭晓，得 1 片碎片。
- **听发音**：可以点读单词、英文释义、短语和例句的英文，以及闯关或学习中带发音的题目和选项（考试中不发）。每个发音每个本地日 +0.1 积分，每天 ≤ 10 积分，两次得分至少间隔 5 秒（ADR 0017）。关声音时客户端不上报。
- **发音来源**：优先使用词库中同一个词的已发布音频，否则用浏览器朗读；服务端不实时合成。
- 单词本不进入间隔复习；完成一轮单词本算“学习日”（§4.1.7）；家长中心没有单词本页面，只在流水和图鉴中看到结果。

## 验收要点
- 开始作答的响应中不含任何答案、可接受答案或解析字段（接口测试 + 数据库 CHECK）。
- 同一题第二次作答不改变判分；重复完成只产生一条闯关记录、一次发星、一次发碎片、一次伙伴附赠积分。
- 听发音：同一次作答同一目标第二次上报不再发积分；不属于本次作答的目标返回 400；作答结束后上报返回 `409 PLAY_FINISHED`。
- 复习：结算不写星星流水；答对 N 条得 N 积分（同一条目当天第二次答对不再发）；完成当日复习只发 2 片碎片。
- 游戏搭档：第 1–4 单元的首页卡片依次为金币探险、宝箱冒险、帽子与月亮、马里奥赛车，第 5 单元回到金币探险；结算页显示该关主题。
- 作答中途发布新版本，原作答仍可完成并按旧版本判分。
- 单词本：同一孩子添加 `Apple` 与 ` apple` → 第二次 `409 WORD_DUPLICATE`；删除后重新添加，学习状态保留；第 2001 条 → `409 WORDBOOK_FULL`。
- 单词闯关 10 题答对 8 题：每个词记 2 个单位；连续两轮共 20 个新单位 → 4 颗 `word_challenge` 星，余量 0；再玩同一组词同样的分数不再得星。
- 考试进行中，单词本列表不含释义，编辑与 AI 解释返回 `409 WORD_EXAM_LOCKED`，聊天返回 `409 WORD_EXAM_AI_RESTRICTED`；交卷后恢复。
- 首次学会第 5 个词时放置 1 个单词本里程碑藏匿点；当天全局上限已满时记为待领取，次日调用 reconcile 时补发，并且只发一次。
- 单词本听发音：同一句例句当天第二次点读不再得分；5 秒内连点只有第一次得分；当天第 101 个发音不再得分。
- 两次开始同一关（先放弃前一次），选项顺序不同（统计测试：20 次中至少出现 2 种顺序）。
- 星级：5 题对 4 题 → 2 星级；5 题全对 → 3 星级；4 题对 3 题 → 未通过（数据库生成列与代码一致）。
- 未完成的作答第二天再开始同一关，返回同一个作答 ID 与已答进度；不存在 `PLAY_EXPIRED`。
- 同一次作答同一张学习卡上报两次，只发一次碎片（1–3 片）；通关不写碎片流水。
- 隐藏奖励关第一次 2 星级结算：`double` 得 +2 星（共 4 星）；第二次结算不再得隐藏奖励。
- 金币小径：单元任一关 3 星级后出现；第一次进入扣 2 星，3 题对 2 题不通过，重试免费，3 题全对得 4 星（学习星），第二次通过不再得。
- 1–2 年级课程草稿含 `reading_choose` → 自动检查不通过。
