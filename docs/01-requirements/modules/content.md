# 课程内容（content）· 需求

> 本文由已确认的《星芽学园全新系统设计规格》（2026-10-21，提交 6b463ed）拆分而来；章节编号沿用原规格，便于交叉引用（编号与文件的对应见 [docs/README.md](../../README.md)）。
> 2026-10-21 设计变更（用户已批准，见 [v1.0 变更记录](../../06-releases/v1.0/changes.md)）：课程从“仓库里的课程包”改为**数据库中的版本化课程**；新增共享词库；题目拆为孩子可见部分与答案部分。取代 [ADR 0003](../../adr/0003-content-as-code-build-time-tts.md)，见 [ADR 0008](../../adr/0008-db-versioned-courses-word-bank.md)。

职责：共享词库（词、义项）、课程与课程版本、草稿的整个编辑生命周期（表单编辑、自动检查、审核、发布）、题型判分器、课程模板注册（读取仓库中的模板定义）。AI 生成课程草稿由 studio 提供能力、由 content 拥有结果，见 [studio 需求 §4.8](studio.md)。

## 4.1.1 内容结构
- 层级：年级（1–6）> 课程（属于一个学科、一个年级、一个模板）> 课程版本 > 关卡（版本内有序）> 题目（每关 5–8 道）。
- **共享词库**：`words`（拼写形式，稳定 ID 如 `en.apple`）+ `word_senses`（义项，稳定 ID 如 `en.bat.animal`，以词 ID 为前缀）。复习进度绑定义项。词文本与义项释义发布后不可修改（数据库列级授权）；勘误 = 把旧义项退役并新建义项。图片、音标、标准音可以更新。
- 课程、`level_key`、`question_key` 使用稳定 ID；进度与复习跨版本保持。

## 4.1.1a 课程生命周期
| 状态 | 含义 | 谁能改 |
| --- | --- | --- |
| 草稿 `draft` | 系统管理员用表单编辑（不暴露原始 JSON）；可让 AI 重写某一题；每次修改后自动检查重新运行 | 系统管理员 |
| 审核中 `in_review` | 自动检查全部通过才可提交；审核人可用“孩子视角试玩”逐关走查（可选，不强制） | 只读；退回则回到草稿 |
| 发布中 `publishing` | 后台任务生成音频（Piper 一次性进程）并把素材复制到公开 CDN 前缀 | 只读 |
| 已发布 `published` | 写入新的课程版本（不可修改），课程当前版本切换到它 | **不可修改**；再编辑 = 基于它新建草稿 |
| 已放弃 `discarded` | 草稿作废 | — |

- 每门课同时最多一份未完成草稿（数据库唯一键）。
- 已发布版本、其关卡、题目与答案对应用账号只允许插入，不允许修改或删除（[roles.sql](../../../db/roles.sql)）。
- 正在进行的作答在它开始时的版本上完成；新的作答使用当前版本。
- 课程可整体退役（`retired`）：孩子不再看到，历史记录仍可关联。
- 只有一位系统管理员时，提交人与审核人可以是同一人（`已默认，可调整`，开放问题 Q9）。

## 4.1.1b 题目存储：孩子可见部分与答案部分分开
- `questions.visible`：题干、选项（带选项 ID）、资源 ID——作答前只下发这一部分；数据库 CHECK 拒绝其中出现 `answer`、`accept`、`explanation`、`correct`、`correctOptionId` 字段。
- `question_answers`：正确选项 ID / 标准答案 / 可接受答案 / 正确顺序、解析。只有判分器在服务端读取，作答后才返回给客户端。

## 4.1.1c 仓库里还保留什么（`seeds/` 内置数据，ADR 0015）
- `seeds/course-templates/`：课程模板定义（关卡顺序、题型组合、每关题数、适用年级），随发布包部署、api 启动时读取，版本化。
- `seeds/samples/english/grade-1/`：少量示例课程，用 `xingya course:import` 导入为**草稿**（再走审核与发布）。
- `seeds/shop/`（装扮初始数据）、`seeds/phrases/`（预设短语/表情）、`seeds/safety/`（聊天过滤词表与 AI 提示词禁止项）、`seeds/avatars/`（孩子头像）。
- 没有课程包、没有构建期音频，部署时不导入课程；部署步骤 `xingya seeds:apply` 只补齐缺失的装扮初始数据与默认技能、角色挂载（见 `seeds/README.md`）。

> 课程文档结构、模板与自动检查规则见 [课程模型](../../03-design/course-model.md)。

## 验收要点
- 已发布题目、答案、关卡、版本：应用账号 UPDATE/DELETE 被拒（数据库验证）。
- 修改已发布课程 → 生成新草稿 → 发布后 `version_no + 1`，旧版本数据不变。
- 自动检查未通过的草稿无法提交审核（接口 + 数据库 CHECK）。
