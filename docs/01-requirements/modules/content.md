# 课程内容（content）· 需求

> 本文由已确认的《星芽学园全新系统设计规格》（2026-10-21，提交 6b463ed）拆分而来；章节编号沿用原规格，便于交叉引用（编号与文件的对应见 [docs/README.md](../../README.md)）。


职责：在内存中只读提供当前课程包：年级、课程、关卡、词、题目、商店物品、头像、预设短语/表情、安全词表；题型判分器。

## 4.1.1 内容结构
- 层级：年级（1–6）> 课程（属于一个学科、一个年级）> 关卡（课程内有序）> 题目（每关 5–8 道）。
- 每个词有稳定 ID（如 `en.apple`、同形异义用后缀 `en.bat-animal`）。ID 一经发布永不改义、永不复用；内容修订通过“退役 + 新 ID”或允许的拼写勘误（[§7.4](../../03-design/content-pack.md) 规则 C6）完成。课程、关卡、题目同样使用稳定 ID。
- 内容表对应用只读；课程包删除的条目在导入时标记 `retired=1`，历史记录仍可关联。
> 课程包的目录、JSON 结构、构建与校验规则见 [课程包格式](../../03-design/content-pack.md)。
