# Skill 管理与 AI 角色（studio）· 需求

> 本文为 2026-10-21 用户追加的第 10 部分（用户已批准，见 [v1.0 变更记录](../../06-releases/v1.0/changes.md)），对应设计规格 §4.10。功能归属 **studio 模块**（不新增业务模块）；设计见 [Skill 与 AI 角色 · 模块设计](../../03-design/modules/agents.md)，决策见 [ADR 0014](../../adr/0014-skills-and-agent-roles.md)。管理端功能只有系统管理员可用；面向孩子的只有“呀哈哈队长”。

职责：技能（Skill）库与版本、AI 角色与其技能配置、角色执行器（工具循环）、多角色流水线、一句话任务框、任务历史与快捷任务、角色级预算。

## 4.10.0 一句话说明
- **技能** = 一个版本化的“提示词包”：何时使用、怎么做（步骤）、输入输出格式、能用哪些内置工具、参考资料、推荐模型。**技能里没有可执行代码**。
- **AI 角色** = 有名字和头像的“员工”：挂载若干技能、限定可用工具、模型与月度预算、服务对象（系统管理员 / 孩子 / 家长）。
- 原来的 AI 课程生成、伙伴设计、款式设计、规则填写流程，**全部改为由角色 + 技能执行**（见 §4.10.6）。
- AI 只产出**草稿**；发布永远需要系统管理员在界面上确认；每一步都有记录。

## 4.10.1 技能（Skill）
| 字段 | 说明 |
| --- | --- |
| 标识 `skill_key` | 小写短横线，如 `course-generate`；创建后不可改，永不复用 |
| 服务对象 | `admin` / `child` / `parent`，创建后不可改；只能挂到同一服务对象的角色上（数据库保证） |
| 名称、何时使用 | 何时使用 ≤ 1024 字，用于角色在多个技能中挑选 |
| 指令 | 提示词与步骤（Markdown，≤ 64 KB） |
| 输入 / 输出模式 | JSON Schema；**输出模式必须是 object**，运行结果不通过校验即视为失败（可自动修正 1 次，`已默认，可调整`，Q20） |
| 内置工具白名单 | 只能从系统内置工具目录中选（§4.10.7）；最多 20 个 |
| 参考资料 | 最多 20 项：文本片段或素材库图片 |
| 默认参数 | 可被角色覆盖的参数（如每关题数、故事长度） |
| 推荐模型 | 留空 = 用角色或系统设置的模型 |

- **版本**：每次编辑保存 = 一个新版本（`draft`）；已保存版本的内容不可改（数据库列级授权）。版本状态：草稿 → 审核中 → 已发布 → 已退役。技能有一个“当前版本”，供“跟随最新发布”的角色使用。
- **回滚**：把当前版本指回任意一个较早的已发布版本（记审计）；不复制、不改历史。
- **面向孩子或家长的技能需要单独的儿童安全审核**：除常规审核外，还要通过儿童安全检查（儿童安全测试集全部通过 + 审核人勾选清单），数据库要求记录安全审核人与时间才能发布。只有一位系统管理员时允许同一人完成两次审核（见 Q9、Q23）。
- **强制规则不可关闭**：运行时在所有技能之前自动加入“儿童安全 + 不得模仿现有 IP”的系统守则（仓库 `seeds/safety/agent-guard.md`，随 api 发布）；任何技能、角色、参数都不能移除或覆盖它。
- **系统技能 `child-safety`**：面向孩子的角色必须挂载，且不能停用（数据库保证不能停用；发布与运行时校验必须挂载）。
- **导入 / 导出**：兼容 SKILL.md 文件夹格式（ZIP）。
  - `SKILL.md` 的 frontmatter `name` → 标识，`description` → 何时使用，正文 → 指令；
  - `references/` 下的文本 → 参考资料；`schemas/input.json`、`schemas/output.json` → 输入输出模式（缺少时用默认 `{reply: string}` 输出模式并标出待补）；
  - 可选 `xingya.json`：服务对象、工具白名单、默认参数、推荐模型；
  - **脚本与任何可执行文件永不执行**：`scripts/` 与 `.py/.sh/.js/.ts/.exe` 等文件不会成为工具，只作为“惰性文本”保存在参考资料里并在导入报告中列出；未知工具名一律拒绝；
  - 导入结果一律是**草稿**，需要审核发布；导出生成同样结构的 ZIP（含 `xingya.json`）。
  - 导入包限制：ZIP ≤ 5 MB、解压后 ≤ 20 MB、文件 ≤ 100 个、单个文本 ≤ 256 KB（`已默认，可调整`，Q21；技术上限，不做后台设置）。

## 4.10.2 技能库后台（`apps/admin` 的 skills 页面）
- 列表：标识、名称、服务对象、当前版本、状态（启用/停用）、近 30 天调用次数、成功率、平均费用与耗时。
- 新建 / 导入 / 编辑（表单 + Markdown 编辑器；不显示原始 JSON 以外的内部字段）；每次保存产生新版本，可对比任意两个版本。
- **试运行台**：选技能版本（含草稿）→ 填样例输入（或选保存的样例）→ 运行 → 显示输出、是否通过输出模式校验、每一步的工具调用、费用与耗时。试运行同样先显示预估费用、计入预算。
- 发布（审核）、回滚、启用 / 停用（停用后所有角色跳过该技能；系统技能不能停用）。
- 技能侧角色白名单：列出允许挂载本技能的角色；撤销后不能再挂载，运行时跳过（历史记录保留）。
- 所有操作写审计。

## 4.10.3 AI 角色
| 字段 | 说明 |
| --- | --- |
| 名称、头像、角色说明 | 角色说明作为系统提示词中的“角色段” |
| 挂载的技能 | 见 §4.10.4 |
| 允许的工具 | 角色级白名单；实际可用 = 角色白名单 ∩ 技能白名单 ∩ 该服务对象的工具目录 |
| 模型 | 留空 = 该用途的默认模型配置（`ai_providers`，ADR 0022）；可指定某一条配置的显示名 |
| 月度预算 | 在全站 AI 预算之内；运行时同时预留全站与角色预算，任一不足都不能开始 |
| 服务对象 | `admin` / `child` / `parent`，创建后不可改 |

**默认角色（迁移写入，v1 为草稿，挂载默认技能后由系统管理员审核发布）**——全部 `已默认，可调整`（Q19）：

| 角色 | 标识 | 服务对象 | 默认技能 | 主要工具 | 月度预算 |
| --- | --- | --- | --- | --- | --- |
| 课程设计师 | `course-designer` | 系统管理员 | 资料分析、按模板生成课程、重写一题 | 读资料、查词库、读模板、写课程草稿 | ¥60 |
| 美术设计师 | `art-designer` | 系统管理员 | 伙伴设计、呀哈哈家族款式设计、课程配图 | 图像生成、素材检索、写伙伴/款式设计草稿、给草稿配图 | ¥70 |
| 配音师 | `voice-artist` | 系统管理员 | 伙伴台词与声音、呀哈哈家族叫声、课程对话配音 | 本机语音合成（Piper）、写伙伴/款式声音、给课程对话分配声音 | ¥5 |
| 活动策划 | `event-planner` | 系统管理员 | 一句话填写投放规则、活动方案 | 读规则与款式、写规则草稿、影响估算 | ¥10 |
| 质检员 | `qa-reviewer` | 系统管理员 | 内容质检（自动检查解读、儿童安全、原创性） | 读草稿、运行 K 规则、写质检报告 | ¥20 |
| 运营分析师 | `ops-analyst` | 系统管理员 | 运营报告 | **只读聚合**统计（分组少于 5 个孩子不显示，Q22）、任务与费用汇总 | ¥5 |
| 呀哈哈队长 | `yahaha-captain` | 孩子（家长也可与之聊天） | 儿童安全（系统，必挂）、英语陪练、讲故事、答疑、单词解释（`word-explain`，单词本“AI 生成解释”，ADR 0019） | 只读“本孩子已学的词” | ¥30 |

- 角色预算合计默认等于全站默认上限 ¥200（Q13 修订、Q19）。
- 呀哈哈队长：
  - 是**唯一**面向孩子的角色；只能挂载服务对象为“孩子”的技能；儿童安全技能必挂；
  - 唯一的工具 `child.learned_words` 只返回**当前登录孩子**已学的词（义项文本与中文释义，最多 50 个），孩子 ID 来自会话而不是模型参数，因此**不能读取其他孩子的数据**；家长与之聊天时该工具不可用；
  - **没有聊天记忆**：服务器不保存对话文本，上下文只在浏览器内存中（规则见 [chat 需求](chat.md)）；
  - 其余聊天规则（配额、过滤、开关、元数据保留 90 天）不变。
  - 单词解释技能 `word-explain`（ADR 0019）：输入只有 `{word, grade}`（单词作为数据，不是指令），输出固定结构 `{meaningZh, meaningEn, phrases[≤10], examples[≤10]}`（释义 ≤ 2000、每条英文和中文各 ≤ 500），不用工具；同样经过输入和输出过滤，计入孩子当天聊天次数和角色预算，结果只作为预览返回给单词本，不保存。考试进行中、家长关闭呀哈哈队长或全站关闭 AI 时不可用。
- 运营分析师不能看到任何单个孩子或家庭的数据，只能看全站聚合（满足“系统管理员不能查看家庭学习数据”）。

## 4.10.4 角色的技能配置（用户要求）
- **挂载 / 卸下**技能；只有技能侧白名单里列出的角色才能挂载（数据库保证），且服务对象必须一致。
- **版本策略**：每个挂载可**固定某个版本**，或**跟随技能的当前发布版本**。
- **角色级参数覆盖**：只能覆盖技能 `default_params` 中已有的键，类型须一致。
- **优先级 / 顺序**：1 最先；指令冲突时数字小的优先；系统守则永远在所有技能之前。
- 以上配置**随角色一起版本化**：任何改动都保存为角色的新版本（草稿），审核发布后生效；可回滚到旧版本；全部写审计。面向孩子的角色版本同样需要单独的儿童安全审核。

## 4.10.5 便捷功能
- **一句话框**：每个后台页面顶部一个输入框，默认路由到该页面的角色（如课程页 → 课程设计师、规则页 → 活动策划；映射在系统设置 `agents.page_routes`，Q24）；回车后显示“将由 X 执行、预计 ¥Y”，确认才开始。
- **@角色**：在一句话里写 `@美术设计师` 指定角色；写多个 `@` 按顺序组成流水线。
- **多角色流水线**：如 课程设计师 → 美术设计师 → 配音师 → 质检员 → **系统管理员审核**；每一步显示进度、状态、费用、耗时；任一步失败流水线停止，可从失败步重试；最多 6 步（Q20）。默认流水线：整课（4 步）、伙伴（美术 → 配音 → 质检）、款式（同伙伴）、活动（活动策划 → 质检）。
- **任务历史**：全部运行可按角色、页面、状态筛选；可查看每一步；**克隆并重跑**（可改一句话与参数，重新预估费用）。
- **快捷任务**：把常用的一句话 + 角色或流水线 + 参数保存在页面上，一键运行（仍需确认费用）。
- **AI 只写草稿**：工具目录中**没有任何发布、上架、生效、删除类工具**；发布、上架、规则生效都只能由系统管理员在界面上点击确认。每一步（选技能、模型调用、工具调用、校验、安全检查）都写入运行记录。

## 4.10.6 原有 AI 流程改由角色执行
| 原流程 | 现在由 | 说明 |
| --- | --- | --- |
| 课程：资料分析 → 按模板生成 → 重写一题（§4.8） | 课程设计师（+ 美术设计师配图、配音师试听、质检员） | 草稿、自动检查、审核、发布规则不变 |
| 伙伴设计（§4.6.6） | 美术设计师 → 配音师 → 质检员 | 4 张候选、阶段图、关键帧、声音；审核上架不变 |
| 呀哈哈家族款式设计（§4.7.4） | 美术设计师 → 配音师 → 质检员 | 同上 |
| 一句话填写投放规则（§4.7.6） | 活动策划 | 仍只填固定结构；复述由服务器模板生成；系统管理员确认才生效 |
| 发布时生成课程音频 | 系统任务（不是 AI 角色） | 确定性任务，复用配音师生成的试听音频（同一文本与声音的哈希相同） |
| 资料文本抽取 / 视觉模型识字 | 系统任务 | 不用专门的 OCR 服务，图片与扫描页交给视觉模型（ADR 0022） |
| 呀哈哈队长聊天（§4.4.4） | 呀哈哈队长（儿童角色） | 同步执行，不进队列、不保存对话 |

## 4.10.7 架构要点（详见设计）
- 角色执行器在 **studio 模块**中，管理端运行走现有 MySQL 任务队列（任务类型 `agent_run`，遵守 2 并发 / 本机进程 1 个的槽位）；呀哈哈队长聊天在请求内同步执行。
- 工具循环**最多 20 步**（`agents.limits.max_steps`，数据库限制 ≤ 20）；儿童聊天最多 3 步；每次模型调用、每个工具、整次运行都有超时（Q20）。
- 内置工具由各业务模块向 studio 注册（依赖倒置）；工具声明服务对象、只读或写草稿、输入模式；孩子工具只能读当前会话孩子的数据。
- 费用：运行前预估上限；同一事务内预留全站预算与角色预算；结束按实际结算（实际 ≤ 预估，超出预估时立即停止）。

## 验收要点
- 已发布技能版本、角色版本及其技能挂载不能被修改（数据库授权验证）；编辑只产生新版本；回滚后运行使用回滚到的版本。
- 不在技能侧白名单中的角色、服务对象不同的角色都无法挂载该技能（数据库外键验证）。
- 面向孩子的技能与角色未经儿童安全审核无法发布（数据库 CHECK 验证）；`child-safety` 不能停用；未挂载它的儿童角色无法发布或运行。
- 导入含脚本的 SKILL.md 包：脚本只以惰性文本出现在导入报告与参考资料中，任何路径都不会执行（测试断言没有子进程被创建）；未知工具名被拒绝。
- 输出不符合技能输出模式的运行失败且不写任何草稿；第 21 步之前强制结束；超时生效。
- 工具目录中不存在发布类工具；AI 运行结束后所有产物都是草稿，孩子端不可见。
- 呀哈哈队长的工具只能返回当前孩子的已学词（用另一个孩子的 ID 构造参数无效）；服务器上没有任何对话文本（数据库与日志检查）。
- 角色预算或全站预算不足时运行不能开始；同时运行时“预留 + 已花费”不超过任一上限（数据库验证）。
- 流水线每一步的进度、费用可见；失败步可重试；克隆重跑与快捷任务都需重新确认预估费用。
