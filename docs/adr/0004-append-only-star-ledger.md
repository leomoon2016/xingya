# ADR 0004：星星账本只追加

- 状态：已接受（由 ADR 0011、0017、0020 修订）

> 2026-10-22 修订（ADR 0020）：家长可以扣星（`parent_deduct`，必须写原因，不能扣到负数或扣冻结部分）；纠错仍只能追加新流水。累计奖励另有只追加的 `reward_ledger`。

> 2026-10-21 修订：增加第二种货币“碎片”，账本表改名为 `ledger`（带 `currency` 列），余额表改名为 `balances`；只追加原则不变。见 [ADR 0011](0011-fragments-second-currency.md)。
- 日期：2026-10-21
- 依据：《星芽学园全新系统设计规格》（已由用户逐节确认）

## 背景
旧系统多币种、多张领取表，奖励缺陷集中。

## 决策
（原文）只有星星一种货币；账本只追加，余额 = 流水之和；余额表为同事务维护的缓存并每晚对账；应用数据库账号对账本没有 UPDATE/DELETE 权限（已实测）；每条流水有业务幂等键 `source_key`；所有写请求带客户端请求 ID。

## 后果
余额可审计、可验证；纠错只能追加新流水（~~家长手动奖励只加不减~~ → 2026-10-22 起家长可带原因扣星，仍是追加一条负数流水）。

## 未采用的方案
可编辑余额字段；数据库触发器（授权更简单直接）。
