# ADR 0004：星星账本只追加

- 状态：已接受
- 日期：2026-10-21
- 依据：《星芽学园全新系统设计规格》（已由用户逐节确认）

## 背景
旧系统多币种、多张领取表，奖励缺陷集中。

## 决策
只有星星一种货币；`star_ledger` 只追加，余额 = 流水之和；`star_balances` 为同事务维护的缓存并每晚对账；应用数据库账号对账本没有 UPDATE/DELETE 权限（已实测）；每条流水有业务幂等键 `source_key`；所有写请求带客户端请求 ID。

## 后果
余额可审计、可验证；纠错只能追加新流水（家长手动奖励只加不减）。

## 未采用的方案
可编辑余额字段；数据库触发器（授权更简单直接）。
