# ADR 0010：素材放 OSS + CDN，发布时一次性运行 Piper

- 状态：已接受（取代 ADR 0003 的“构建期生成发音”部分）
- 日期：2026-10-21
- 依据：2026-10-21 设计变更（用户已批准，见 [v1.0 变更记录](../06-releases/v1.0/changes.md)）

## 背景
课程改为在线发布后，音频不能再在 CI 中生成；AI 生成的图片、动画与上传资料也需要存储，ECS 磁盘与带宽有限。

## 决策
- 素材与资料存阿里云 OSS 私有桶：`draft/`（未审核，10 分钟签名 URL）、`materials/`（上传资料，仅后台）、`pub/`（已发布，经 CDN）、`xingya/db/`（备份）；文件按内容哈希命名，`immutable` 缓存；RAM 子账号最小权限；CDN 域名需 ICP 备案；CSP 与 CORS 只放行本站与 CDN。
- 发布课程时由工作室任务**一次性**为缺少音频的词、句子运行 Piper（`systemd-run --user --scope -p MemoryMax=350M`，用户服务需 `loginctl enable-linger xingya`），结果上传 `pub/` 并写回 `assets`；运行时不提供语音合成。真人录音可替换同一素材。

## 后果
ECS 只承载 API 与页面；音频生成集中在发布时，发布耗时随缺少音频的条目数增加；增加 OSS/CDN 费用与备案前置依赖（路线图 W0）。

## 未采用的方案
继续 CI 生成（与在线发布矛盾）；在线 TTS（延迟与内存）；文件放 ECS 本地磁盘（容量与带宽）。
