# ADR 0020：回归老系统总规则——未逐项决定的旧功能一律照旧

- 状态：已接受（修订 PRD 旧系统对照表、[scope](../06-releases/v1.0/scope.md) 非目标、ADR 0011、0012、0017、0019 C11；由 ADR 0021、0022 补充）
- 日期：2026-10-22
- 依据：用户决定（2026-10-22）——设计缺口盘点（[2026-10-22 设计缺口盘点](../reviews/2026-10-22-设计缺口盘点.md)）中决定来源为“用户整体接受建议 / 已默认 / 规格自定 / 未提及”的旧功能，**一律回到旧系统的行为**；包括盘点 §3 中全部标 ⟲ 的事项。见 [v1.0 变更记录](../06-releases/v1.0/changes.md)、[开放问题](../01-requirements/open-questions.md)

## 背景
2026-10-21 的规格把旧系统（`learning-platform`）128 项功能中的 86 项“重设计”或“放弃”，但只有 30 项是用户逐项明确的；另有 16 项新文档根本没提（盘点 §1.13）。用户 2026-10-22 决定：凡不是逐项决定的，一律照旧。

旧行为全部只读核对 `/workspace/learning-platform/code` 的源代码与 `doc/`，没有读取 `code/.local`、`data`、部署配置或任何凭据文件。

## 决策

### 1. 总规则与映射原则
1. **逐项决定的规则优先**，照旧不推翻：通过线 80%、学习星 / 奖励星两个术语、积分（ADR 0017）、马里奥游戏搭档（ADR 0018）、伙伴最高 100 级、复习积分每天 30、单元层（ADR 0016）、全部作答后才能完成（Q18）、星级（本 ADR §3）、单词星算学习星（§5）、不迁移旧数据（§4）、家庭为根与邀请码注册、PIN 头像墙、赠星每天 ≤ 20、周榜只算学习星、发布时一次性 Piper（2026-10-21 变更，用户已批准）、呀哈哈碎片与发现概率 20% / 每天 3 个。
2. **其余一律照旧**。旧系统里系统管理员为**自己家**做的事（加减星、核销、看学习全览）落到**家长中心**；为**全站**做的事（课程、宠物、呀哈哈、语音、模型、资料）落到**系统管理后台**。
3. **硬性安全与隐私规则优先于旧行为**（儿童个人信息、跨家庭交流、答案不下发、密钥不进仓库、系统管理员看不到家庭数据）。每一处这样的例外都列在 §7，并标“⚠ 安全 / 隐私优先”。

### 3. 星级（用户 2026-10-22 决定）
- 全对 = 3 星级；**只错 1 题且正确率 ≥ 80%** = 2 星级；其余 ≥ 80% = 1 星级；< 80% = 0（未通过）。
- `attempts.stars` 生成列：`CASE WHEN c = s THEN 3 WHEN c × 100 < s × 80 THEN 0 WHEN c = s − 1 THEN 2 ELSE 1 END`（c = 答对数，s = 计分题数）。
- 例：4/5 = 80% → 2；7/8 = 87% → 2；3/4 = 75% → 0；5/5 → 3；6/8 = 75% → 0。
- ⚠ 在 4–8 道计分题下，错 2 题时正确率最高 6/8 = 75% < 80%，所以 **1 星级实际不会出现**（只有以后允许 ≥ 10 道计分题才会出现）。这是新规则的直接结果，记为[开放问题 Q33](../01-requirements/open-questions.md)。
- 旧系统拼写 / 阅读题的 60% 星级阈值与每关可配阈值（L5）**不恢复**：被本条用户决定覆盖。

### 4. 不迁移旧孩子数据（用户 2026-10-22 决定）
所有孩子从零开始：不导入星星、积分、碎片、宠物、呀哈哈与进度；不设开账 kind。旧课程内容不是孩子数据，按 §2 L1 转成草稿。

### 5. 单词星算学习星（用户 2026-10-22 决定）
推翻 ADR 0019 C11 与 Q32 的默认：`word_challenge` / `word_exam` 计入排行、伙伴经验与领养门槛；使用单词本（完成一轮学习、闯关或考试）算一个“学习日”。见 [ADR 0019](0019-wordbook-as-old-system.md)。

### 8. 仍需用户确认的点（不阻塞开发，默认按上文）
1. **S-3 的范围**：盘点建议只恢复“改名、亲密度”，总规则把**退订、赠送、唯一档**也一并恢复了（旧系统大部分宠物缺陷出自这三项）。默认恢复；如不要，删掉 `pet_gifts`、`site_unique` 与 `pet_refund` 即可。
2. **顶栏呀哈哈显示“N / 1000”（旧）还是“N / 款式总数”**：默认照旧显示“N / 收藏上限”。
3. **1 星级不会出现**（§3）：是否接受，或把 2 星级改为“错 1–2 题且 ≥ 80%”。
4. **伙伴升级方式**（S-1）：旧系统是花星星升级；用户在单词星决定中写明“计入伙伴经验”，因此保留“学习星加经验、曲线照旧”。若要回到花星星升级，需改表结构。
