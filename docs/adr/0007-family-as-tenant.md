# ADR 0007：以家庭为租户

- 状态：已接受
- 日期：2026-10-21
- 依据：《星芽学园全新系统设计规格》（已由用户逐节确认）

## 背景
旧系统管理员与家长是两套账号，低龄孩子用账号密码登录困难；以后要开放给更多家庭。

## 决策
家庭是根：首个家长注册即建家庭，可邀请其他家长（权限相同）；孩子档案由家长创建，在家庭设备上用头像 + 4 位 PIN 登录；所有业务数据带 `family_id`，并用 `(family_id, child_id)` 复合外键保证不会跨家庭；系统管理员是独立运维账号，不属于任何家庭；无计费、无机构。

## 后果
租户隔离在数据库层可证明；暂不支持一个孩子属于多个家庭。

## 未采用的方案
机构/班级模型（超出需求）；共享单一管理员账号。
