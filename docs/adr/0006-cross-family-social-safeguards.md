# ADR 0006：跨家庭社交带安全护栏

- 状态：已接受
- 日期：2026-10-21
- 依据：《星芽学园全新系统设计规格》（已由用户逐节确认）

## 背景
用户希望孩子之间有排行、赠送与消息，并在以后开放给更多家庭；儿童安全是首要约束。

## 决策
跨家庭功能默认关闭，由家长开启；好友关系以家庭为单位，用线下交换的好友码发起、对方家长批准；跨家庭只能发预设短语与表情（接口与数据库 CHECK 双重限制）；赠送每人每天 ≤20 颗；排行只算学习所得，全站榜只显示昵称与头像，可退出；家长可读孩子全部消息；任何消息可举报/屏蔽，由系统管理员处理。

## 后果
社交价值保留且风险可控；功能与举报处理有一定工作量，进度不足时可按顺序削减。

## 未采用的方案
完全取消社交；开放自由文本。
