# ADR 0003：内容即代码，构建期生成发音

- 状态：已被 ADR 0008、0010 取代（2026-10-21）

> 本决策已失效：课程改为入库并版本化（[ADR 0008](0008-db-versioned-courses-word-bank.md)），音频改为发布时生成并放 OSS + CDN（[ADR 0010](0010-oss-cdn-publish-time-piper.md)）。以下原文仅作历史记录。
- 日期：2026-10-21
- 依据：《星芽学园全新系统设计规格》（已由用户逐节确认）

## 背景
旧系统在后台编辑原始 JSON、启动补丁升级内容，并在 2 GB 主机上实时合成语音。

## 决策
课程、词、题目、商店物品放在仓库 `content/`，由 CI 校验（规则 C1–C13）并组装成课程包；Piper 在 CI 中离线生成音频（按内容哈希命名、可被真人录音覆盖）；部署时导入只读内容表，Nginx 静态提供图片与音频；线上不提供内容编辑。

## 后果
内容变更可审阅、可回滚；运行时无语音服务；改内容需要走一次发布。

## 未采用的方案
后台在线编辑（双写与一致性问题）；在线 TTS 服务（延迟与内存压力）。
