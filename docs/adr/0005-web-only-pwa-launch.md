# ADR 0005：首发只做 Web（可安装 PWA）

- 状态：已接受
- 日期：2026-10-21
- 依据：《星芽学园全新系统设计规格》（已由用户逐节确认）

## 背景
三端并行（Web + 小程序 + iOS）估算约 32 周，超出单人能力。

## 决策
首发 React 19 + Vite 的可安装 PWA；缓存应用外壳与当前课程资源；不做离线提交队列；小程序与苹果应用以后复用同一 API（会话表支持 Bearer 令牌）。

## 后果
13 周可交付（2026-10-21 设计变更加入学习伙伴、呀哈哈发现与 AI 工作室后，总工期调整为约 19 周；第 10 部分“Skill 管理与 AI 角色”再 +1.5 周，约 20.5 周，见[路线图](../02-solution/roadmap.md)）；iOS Safari 的 PWA 录音/音频限制需降级处理。

## 未采用的方案
同时做小程序与原生应用。
