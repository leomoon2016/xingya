# ADR 0011：引入碎片作为第二种货币

- 状态：已接受（修订 ADR 0004）
- 日期：2026-10-21
- 依据：2026-10-21 设计变更（用户已批准，见 [v1.0 变更记录](../06-releases/v1.0/changes.md)）

## 背景
伙伴需要一种只能靠学习和发现获得、不能购买装扮的货币，避免与星星经济混用。

## 决策
- 账本表改名为 `ledger`，增加 `currency`（star / fragment）；余额表 `balances` 主键 `(child_id, currency)`；仍然只追加、余额 = 流水之和、每晚对账。
- 碎片来源只有：每关每天首次通过按星级发放、今日复习完成 2 片、每个呀哈哈家族成员 1 片；支出只有领养伙伴、扩建营地。CHECK 限定每种币种允许的 kind 与 delta 范围（已实测：碎片不能购买装扮、不能由家长奖励）。
- 星星新增来源 `discovery_bonus`（图鉴套组与里程碑奖励）；“学习星”（level_pass / review_day / streak）用于领养门槛与排行榜。
- 锁顺序固定：幂等 → 余额（星星再碎片）→ 业务行 → `ai_budget_months`。

## 后果
两种货币共享同一套审计与幂等机制；界面需要清楚区分两种余额。

## 未采用的方案
只用星星（伙伴价格会挤压装扮与现实奖励）；单独的碎片表（重复实现账本）。
