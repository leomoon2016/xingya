# ADR 0018：正式系统一直使用马里奥（游戏搭档）

- 状态：已接受（第三方 IP 规则的具名例外；修订 PRD 旧系统对照表“游戏搭档：放弃”与 roadmap R7）
- 日期：2026-10-22
- 依据：用户决定（2026-10-22）：“正式系统一直用马里奥”；用户已被告知版权、ICP 备案审核与下架风险后作出选择。见 [开放问题 Q31](../01-requirements/open-questions.md)、[v1.0 变更记录](../06-releases/v1.0/changes.md)

## 背景
旧系统（`learning-platform`，只读核对 `code/src/GameBuddy.jsx`、`StudentHome.jsx`、`Learning.jsx`、`AdventureTrail.jsx`、`CharacterArt.jsx`）在孩子端用马里奥和林克做**游戏搭档**：

- 学习首页“当前任务”区的搭档卡片，按单元轮换：`['coins','treasure','moon','kart'][(单元序号 − 1) mod 4]`，即第 1 单元“马里奥 · 金币探险”、第 2 单元“林克 · 宝箱冒险”、第 3 单元“奥德赛 · 帽子与月亮”（戴帽子的马里奥）、第 4 单元“马里奥赛车 · 快乐出发”。
- 关内进度条（探险小路）使用该关的搭档主题；通关结算页“探险完成啦！”上显示同一主题的小卡片。关卡的主题默认按关卡序号轮换 `['coins','kart','moon','treasure'][(关卡序号 − 1) mod 4]`。
- 卡片说明文字：“答完一题，和搭档前进一步”。
- 旧素材：`public/assets/companions/mario.svg`、`link.svg`。

原规格以“第三方 IP 风险”放弃了游戏搭档，并规定“全部原创形象”。

## 决策
1. **恢复游戏搭档，位置与轮换规则照旧**（见上）。新增术语“游戏搭档”（[GLOSSARY.md](../../GLOSSARY.md)）。
2. **与伙伴、呀哈哈队长并存，互不替代**：
   - 游戏搭档只是展示：不能领养、不在营地、不获得经验、不产生任何奖励（星星、碎片、积分都与它无关），也不说话、不聊天。
   - 伙伴 / 跟随伙伴仍是 AI 工作室设计的原创角色（[companion](../01-requirements/modules/companion.md)）；伙伴附赠积分只看跟随伙伴（ADR 0017）。
   - 呀哈哈队长仍是唯一面向孩子的 AI 角色，原创固定形象。
   - 同一页面上，游戏搭档卡片在“当前任务”/结算区，跟随伙伴在它自己的位置（旧系统同样两者并存）。
3. **第三方 IP 规则的具名例外**：只有马里奥（含戴帽子与赛车两种画面）和林克，以**固定的复用旧素材**出现在游戏搭档卡片、关内进度条主题与结算页卡片中。其他任何地方（头像、装扮、伙伴、呀哈哈家族、AI 角色头像、课程插图）仍然必须原创或已授权。
4. **AI 工作室仍然不得生成任天堂角色**：图像提示词禁止词表与自动追加的“不得模仿现有角色”保持不变（`seeds/safety/prompt-blocklist` 必须列入马里奥、林克、塞尔达、耀西、酷霸王、任天堂等中英文名称）；美术设计师角色不能产出或修改游戏搭档素材；游戏搭档只用仓库里的固定文件。
5. **素材位置**：按“复用的旧素材一律放在 `seeds/`”的约定，放在 `seeds/partners/`（`mario.svg`、`link.svg` 与 `partners.json` 主题清单），api 启动时读取 `partners.json`（不入库），图片由 `xingya seeds:apply` 上传到 OSS 公开前缀 `pub/partners/`（只上传缺失或内容变化的文件）；代码只认主题 ID（`coins`/`treasure`/`moon`/`kart`），不写死角色名或文件名。

## 风险
| 风险 | 说明 | 缓解 |
| --- | --- | --- |
| 著作权、商标 | 马里奥、林克为任天堂所有；家庭自用风险低，开放给其他家庭（对外提供服务）时风险上升 | 只用固定素材、不做商业宣传、不在名称或域名中使用；用户已知情 |
| ICP 备案 / 内容审核 | 备案审核或平台巡检可能要求移除第三方形象 | 按下行“投诉下架”的路径随时替换（可选：预先准备一套原创图）。注册永久只用邀请码（用户 2026-10-22），原“开放注册前替换”一项取消 |
| 投诉下架 | 权利人投诉后需要立即撤下 | 角色只存在于 `seeds/partners/` 与 OSS：**不改代码**：紧急时运维直接把 OSS `pub/partners/` 下同名文件换成原创图并刷新 CDN，立即生效；随后在 `seeds/partners/` 中替换图片与 `partners.json` 里的名称、说明文字，随下一次部署固化。主题 ID 不变，代码与数据库都不受影响 |

## 后果
- 孩子端恢复旧系统熟悉的搭档卡片；内容规则从“全部原创”改为“全部原创，游戏搭档的固定素材除外”。
- 原创性检查（质检员、提示词禁止词表）不变；`seeds/partners/` 不经过 AI 工作室，也不进入 AI 审核流程。

## 未采用的方案
- 由 AI 工作室生成“近似马里奥”的原创搭档：违反提示词规则，且仍有近似侵权风险。
- ~~把马里奥做成可领养的伙伴~~：2026-10-22 用户按回归老系统总规则恢复了旧宠物集（含马里奥），见 [ADR 0021](0021-nintendo-pets-seed.md)；游戏搭档与可领养的马里奥宠物并存，素材分别在 `seeds/partners/` 与 `seeds/pets/`。
