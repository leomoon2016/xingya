- 日期：2026-10-30
- 状态：设计完成（草案 schema 已改写并在本机 PostgreSQL 16.9 验证可应用）
- 授权：用户 BO W（消息 t90u）按代理推荐一次做完，中途不确认
- 相关 ADR：[0023](../../adr/0023-postgres-local-only-ssh-tunnel.md)、[0024](../../adr/0024-studio-postgres-job-queue.md)（分别取代 0002、0009）

## 1. 意图

在**尚未部署任何环境**的前提下，把数据库引擎从 MySQL 8.4 换成 PostgreSQL 16。业务意图、表数量（约 82）、租户模型、只追加账本、邀请制、模块化单体与其余栈不变；只重表达 MySQL 专有机制。

**不做**线上数据迁移（无 MySQL→PG dump 转换、无双写）。

## 2. 锁定决策

| # | 决策 |

| 1 | PostgreSQL **16**（非 17、非 MySQL） |

## 3. 类型映射

| MySQL 8.4 | PostgreSQL 16 |
| --- | --- |
| `BIGINT UNSIGNED` / `INT UNSIGNED` / `TINYINT UNSIGNED` | `BIGINT` / `INTEGER` / `SMALLINT`（非负由 CHECK 保证） |
| `TINYINT(1)` | `BOOLEAN` |
| `DATETIME(3)` | `TIMESTAMPTZ(3)` |
| `JSON` | `JSONB` |
| `ENUM('a','b')` | `TEXT` + `CHECK (col IN ('a','b'))` |
| `BINARY(n)` / `VARBINARY(n)` | `BYTEA` |
| `AUTO_INCREMENT` | `GENERATED BY DEFAULT AS IDENTITY` |
| `ON UPDATE CURRENT_TIMESTAMP(3)` | 删除；应用写 `updated_at` |
| `REGEXP_LIKE(x,'pat','c')` | `x ~ 'pat'` |
| `JSON_TYPE` / `JSON_LENGTH` / `JSON_EXTRACT` | `jsonb_typeof` / `jsonb_array_length` / `->` `->>` |
| `ENGINE=InnoDB` / `COLLATE utf8mb4_*` | 删除（库 `LC_COLLATE=C`） |
| `GET_LOCK` / 生成列槽位抢占 | `pg_try_advisory_lock`（调度互斥）+ `FOR UPDATE SKIP LOCKED`（队列）+ 唯一槽位兜底 |
| `mysqldump` | `pg_dump` |
| `mysql2` | `pg` |

## 4. 队列重设计（ADR 0024）

- **抢占**：`SELECT … FROM ai_jobs WHERE status='queued' ORDER BY queued_at FOR UPDATE SKIP LOCKED LIMIT 1`，再在同一事务分配 `running_slot`（1 或 2）并置 `running`。
- **并发兜底**：保留 `running_slot` 唯一（最多 2 个 running）与生成列 `local_slot` 唯一（`needs_local` 的 running 最多 1 个）。
- **调度器互斥**（部署切换双进程）：`pg_try_advisory_lock(hashtext('xingya:job:'||name))` 取代 `GET_LOCK`。
- **预算**：`ai_budget_months` / `agent_budget_months` CHECK 与预留/结算事务意图不变。
- **心跳 / 重试**：仍 15s 心跳、2 分钟无心跳中断、最多 3 次。

## 5. 连接与安全

- `listen_addresses = ''` 或仅 localhost；优先 Unix socket。
- `pg_hba.conf`：仅 `local` / `host … 127.0.0.1/32`（及 `::1/128`）对 `xingya_app` / `xingya_migrator`；拒绝其余。
- 角色：`xingya_app`、`xingya_migrator`（LOGIN）+ `xingya_app_role` / `xingya_migrator_role`（NOLOGIN，授权载体）。
- 运维：`ssh -L 5433:/var/run/postgresql/.s.PGSQL.5432`（或配置的 socket 路径）后本机连 `127.0.0.1:5433`。
- 应用连接串：`host=/var/run/postgresql`（socket）或 `127.0.0.1`，`TimeZone=UTC`。

## 6. 角色与授权

见 `db/roles.sql`：只追加表 `SELECT,INSERT`；列级 `UPDATE`；可删表含 sessions/tokens 等。意图与 MySQL 版一致，语法改为 PostgreSQL `GRANT`。

## 7. 验证

- `db/verify/verify.mjs`：用 `pg` 连临时 PostgreSQL 16，应用 `0001_init.sql` + `roles.sql`，检查表数=82、授权覆盖、关键 CHECK/唯一/槽位。
- 环境变量：`PGHOST`（socket 目录或 host）、`PGPORT`、`PGUSER`（超级用户，默认 postgres）、可选 `PGDATABASE`（维护库，默认 postgres）。
- 本机验证记录见 `db/verify/result.txt`。

## 8. 部署 / 备份 / CI

| 项 | 原（MySQL） | 新（PostgreSQL 16） |
| --- | --- | --- |
| 安装 | MySQL 8.4 | PostgreSQL 16 |
| 内存 | `innodb_buffer_pool_size=256M` | `shared_buffers=128MB`、`work_mem=4MB`、`maintenance_work_mem=64MB`、`effective_cache_size=512MB`、`max_connections=40`（2GB 机与 Node+Nginx+Piper 共存的保守值） |
| 备份 | `mysqldump --single-transaction … \| gzip` | `pg_dump -Fc` 或 `pg_dump \| gzip`；age 加密 + OSS；14 天 |
| CI | `mysql:8.4` service | `postgres:16` service |
| 健康告警 | mysql 服务名 | postgresql 服务名 |
