# ui —— 共享主题与基础组件

- 主题：由 `docs/04-ui-design/tokens/design-tokens.json`（设计令牌：颜色、字号、间距、圆角、阴影、动效）在构建时生成 CSS 变量与 TypeScript 常量；令牌文件随界面设计一起提交。
- 基础组件：按钮、表单控件、对话框、提示、排版、图标按钮（满足 nfr §8.3 无障碍基线：对比度、触控目标、焦点可见、减少动画）。
- 孩子端与后台共用同一主题，但**只共享无业务的组件**；后台专用组件留在 `apps/admin`，孩子端专用组件留在 `apps/web`，保证孩子端构建不引入后台代码。

**是否上服务器**：否（编译进 web 与 admin）。
