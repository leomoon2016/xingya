# packages —— 共享代码

| 包 | 内容 | 使用方 |
| --- | --- | --- |
| `contracts/` | API 请求/响应 Zod 模式、错误码、共享类型 | api、web |
| `rules/` | 规则常量与纯函数：星级阈值、发星与碎片规则、复习间隔、时长计算、连续天数、伙伴等级曲线、发现概率与上限合并 | api、web（展示）、单元测试 |
| `content-schema/` | 课程文档、课程模板、9 种题型（可见部分与答案部分）的 Zod 模式与自动检查 K 规则 | api（草稿编辑、发布、导入）、web（后台表单）、tools |

**是否上服务器**：否。不单独部署；在构建时被编译进 api 与 web 的产物。
